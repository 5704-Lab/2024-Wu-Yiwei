# FlowEdit 变化影响的联合观测：SVD、频带、解码响应与目标保持

日期：2026-11-17。基于[24源多种子与在线干预实验](FlowEdit增量SVD与空间谱_24源多种子及在线干预_2026-11-17.md)进一步复分析；没有新增 Transformer 或 VAE 推理。

**最有用的组合不是把多个谱数值相加，而是把“更新组织—视觉响应—目标与保持—后续传播”对应起来。** 当前证据最强的是同状态下的“视觉幅度＋视觉方向”：它们可以精确解释与原更新相比的图像偏差。SVD×频带描述变化来源；目标进展×实例保持才接近评价编辑利弊。

本次复分析使用24源、3个局部步、13个干预共936个局部条件，以及12源的完整在线对照。所有统计仍以源图为单位。结果与脚本在[联合分析产物](../experiments/flowedit_delta_spectrum_multi_20261117/outputs/study_v1/joint_analysis/summary.json)和[joint_analysis.py](../experiments/flowedit_delta_spectrum_multi_20261117/joint_analysis.py)。

## 1. 哪些组合回答哪种影响

| 联合观测 | 能回答的问题 | 当前证据与限制 |
|---|---|---|
| 奇异模式×频带×绝对能量 | 更新由哪些通道模式、哪些空间尺度承载，强度多大？ | 精确latent能量账本；没有语义标签 |
| 保留能量×有限解码响应增益 | latent中保留的能量会产生多强的图像变化？ | 当前局部解码可实测；不能只由谱提前知道增益 |
| 图像幅度×图像方向 | 干预是减弱原变化，还是改成另一种变化？ | 可精确分解相对原更新的L2偏差；不自动评价好坏 |
| 空间响应图×相位／源实例配准 | 变化落在哪里，是否发生空间错位？ | 同谱平移反例说明缺少此信息会漏诊；空间参与比例单值不够 |
| 目标事实进展×任务兼容的实例保持×伪影 | 修改是否完成任务、是否多改了内容？ | 当前有在线视觉证据与辅助分数；尚无独立人工认证成功率 |
| 单步扰动×后续传播响应×跨步方向相关 | 这一更新对最终编辑有多大影响，是否被放大或抵消？ | 完整在线对照能观测总体结果；尚未测量完整传播算子 |
| 谱间隙×跨种子子空间稳定性×数值误差 | 这些模式和判断是否稳定可靠？ | 属于解释可信度，不属于语义质量本身 |

## 2. SVD×频带：联合解释“变化从哪里来”

空间×通道展开为

\[
A=\sum_i\sigma_i u_i v_i^\top.
\]

让 (P_b) 是正交傅里叶频带投影，定义联合分量

\[
a_{i,b}=\sigma_i(P_bu_i)v_i^\top,
\qquad E_{i,b}=\|a_{i,b}\|_F^2.
\]

不同 (i,b) 的分量在latent欧氏度量下正交，满足

\[
\sum_bE_{i,b}=\sigma_i^2,\qquad
\sum_iE_{i,b}=\|P_bA\|_F^2,\qquad
\sum_{i,b}E_{i,b}=\|A\|_F^2.
\]

它比“有效秩较低，同时高频较高”两个独立描述更明确：可以指出到底是头部还是尾部模式承载高频。还必须保留绝对总能量，否则极小更新与极大更新可能有相同的归一化表。

主实验末步前4项内部平均包含44.52%的高频，已经否定“主奇异分量等于低频”的解释。联合表能描述更新组织，仍不能把某个格子标成目标、背景或伪影。

## 3. 保留能量×解码响应增益：联合解释“会变多明显”

固定相同前状态 (z)，原更新为 (a)，干预更新为 (a_m)。定义

\[
d=D(z+a)-D(z),\qquad d_m=D(z+a_m)-D(z).
\]

latent能量比例为 (\rho_m=\|a_m\|^2/\|a\|^2)，相对有限响应增益为

\[
\gamma_m=
\frac{\|d_m\|^2/\|a_m\|^2}{\|d\|^2/\|a\|^2}.
\]

于是有精确恒等式

\[
\boxed{\frac{\|d_m\|^2}{\|d\|^2}=\rho_m\gamma_m.}
\]

因此“保留多少latent能量”必须与“这些方向在当前位置经解码后有多强响应”联合解释。这里的增益是有限差分实测量，包括非线性影响；不能未经小幅度核查就叫作Jacobian奇异值。

24源末步平均：

| 干预 | latent保留比例 | 相对有限响应增益 | 图像变化能量比例 |
|---|---:|---:|---:|
| svd4 | 45.95% | 0.986 | 45.06% |
| 同能量scalar4 | 45.95% | 1.129 | 51.80% |
| fft_low | 13.13% | 0.538 | 6.84% |
| 同能量scalar_low | 13.13% | 1.313 | 17.13% |
| fft_high | 60.45% | 1.227 | 73.84% |
| 同能量scalar_high | 60.45% | 1.082 | 65.37% |

各列分别是源均值；恒等式逐例成立，不能把三个均值直接代入相乘。这里测量的是图像变化强度，不是编辑正确程度。低频局部响应弱，也不意味着低频对整条轨迹不重要。

## 4. 图像幅度×图像方向：联合解释“减弱了还是改偏了”

令

\[
q_m=\frac{\|d_m\|}{\|d\|},\qquad
c_m=\frac{\langle d_m,d\rangle}{\|d_m\|\|d\|}.
\]

归一化图像偏差满足

\[
\boxed{
\frac{\|d_m-d\|^2}{\|d\|^2}
=1+q_m^2-2q_mc_m
=\underbrace{(q_m-1)^2}_{\text{幅度差项}}
+\underbrace{2q_m(1-c_m)}_{\text{方向差项}}.
}
\]

这对有限非线性解码同样精确，不要求小扰动；只要求以同一前状态和同一参考变化定义 (d,d_m)，并排除零范数的退化情形。936个实测条件的恒等式最大绝对误差为 (5.38\times10^{-12})。

“方向差”指整张RGB变化向量的差异，不是物体的几何运动方向。相对原FlowEdit变化不同，也不自动意味着更差，因为原更新本身可能含有附带变化。

| 24源末步均值 | 图像幅度比q | 方向余弦c | 相对偏差范数 |
|---|---:|---:|---:|
| svd4 | 0.671 | 0.632 | 0.774 |
| 同能量scalar4 | 0.719 | 0.960 | 0.367 |
| fft_high | 0.859 | 0.844 | 0.534 |
| 同能量scalar_high | 0.808 | 0.981 | 0.258 |
| 平移更新 | 0.906 | 0.109 | 1.275 |
| 通道符号翻转 | 0.912 | 0.149 | 1.249 |

仍然应逐例使用公式，不能把表中的列均值代回求平均偏差。

把24源的幅度差平方与方向差平方分别汇总，svd4的总偏差平方约81.8%来自方向差项；平移更新约99.2%来自方向差项。因此它们与原步的差异主要表现为变化方式改变，而不是仅仅变小。scalar4的方向差较小，但末步存在非线性，仍不是严格按比例缩小图像变化。

## 5. 空间响应×源实例配准：补上“改到了哪里”

空间响应图可以定义为

\[
M_m(p)=\|D(z+a_m)(p)-D(z)(p)\|_2.
\]

它应与源图的物体位置、轮廓、所需属性和保留关系一起检查。对颜色编辑，姿态／轮廓可作为保持对象；对姿态编辑，则不能反过来要求姿态不变。单一全图源差或空间参与比例不具备这种任务适配能力。

循环平移更新可以保持奇异值与傅里叶功率谱，但在固定源实例上改变更新的位置；通道符号翻转也保留谱，却改变冻结VAE解码器接收到的通道组合。当前同谱反例的局部图像方向余弦只有约0.1–0.15，说明谱摘要加“变化强度”仍不足以描述空间／内容配准。

不能仅因空间响应集中就称其精准：集中在错误位置的更新仍可能有害。响应图保留位置信息，目标事实和源关系观测负责判断这些位置上的变化是否合理。

## 6. 目标进展×源实例保持：联合解释“是完成任务还是少改了”

12源完整在线分支的源等权平均如下：

| 分支 | 辅助目标余弦差增益 | 相对源图RGB RMS | 源图特征余弦 |
|---|---:|---:|---:|
| full | 0.08846 | 0.13194 | 0.86429 |
| svd4 | 0.05848 | 0.10987 | 0.90779 |
| scalar4 | 0.07603 | 0.10177 | 0.88409 |
| fft_low | 0.00291 | 0.04385 | 0.98950 |
| fft_high | 0.00139 | 0.03270 | 0.99051 |

仅看源差或源特征相似，单频带分支很容易被排在前面；结合目标进展及实际图像，会看到大量欠编辑。皇冠没有换成礼帽、车辆没有换成SUV、男孩没有换成机器人，均不能因源保持好就判为更好的编辑。

这些指标也不是完整的质量真值：RGB源差包含合法修改，嵌入相似允许局部事实错误，SigLIP2对文字、姿态和添加物体未必可靠。因此更合理的联合验收是：

1. 明确的目标事实是否实现；
2. 与任务兼容的源实例事实是否保留；
3. 是否产生额外伪影。

在目标完成度相近时再比较保持，而不是把三个量随意加权成一个总分，或用“目标分／源差”比值直接排名。代理分数很小、源差也很小时，该比值尤其容易误导。

## 7. 若要逐分量解释视觉影响，联合表还要升级为响应矩阵

已有 (E_{i,b}) 只给出latent能量。对于联合分量 (a_{i,b})，小扰动下令

\[
h_{i,b}=J_D(z)a_{i,b},\qquad
G_{(i,b),(j,b')}=\langle h_{i,b},h_{j,b'}\rangle.
\]

则

\[
\left\|J_D\sum_{i,b}a_{i,b}\right\|^2
=\sum_{i,b}\sum_{j,b'}G_{(i,b),(j,b')}.
\]

对角项描述该分量的局部图像响应；非对角项描述图像空间的增强与抵消。latent中正交的分量，经固定解码器映射后并不保证正交，所以只看各分量单独解码后的能量并相加会遗漏交叉项。有限幅度还要另记非线性余项。

若再选择经过任务事实核查的目标响应 (F) 与任务兼容保持描述子 (\Phi)，可为各分量加入

\[
\tau_{i,b}=D(F\circ D)(z)[a_{i,b}],\qquad
\kappa_{i,b}=\|D(\Phi\circ D)(z)[a_{i,b}]\|^2.
\]

其中有符号的 (	au) 表示局部代理朝目标还是远离目标，(kappa) 表示所选保持量的响应。选择哪些事实作为 (F,\Phi) 决定解释是否可信；矩阵分解不能替代这一步语义定义。当前实验**尚未计算完整响应Gram矩阵或逐分量任务梯度**，这里是严格区分对象后的分析方案，不能当作已获得的逐分量语义归因。

## 8. 从单步影响到终点影响还需要时间传播

一个局部增量改变经过后续生成映射 (\Psi_{k\to N}) 才到终点，局部终点响应为

\[
J_{D\circ\Psi_{k\to N}}(z_k)a_{i,b}.
\]

它与直接解码的 (J_D(z_k)a_{i,b}) 不同。多个时间步还存在方向相关与相消，不能把每步能量或影响绝对值相加当作最终编辑影响。完整在线干预观测到了总体行为，但尚未单独识别每个时刻每个模式的传播作用。

## 9. 当前最值得使用的联合指标

按本轮问题的优先顺序：

1. **解释数值更新组织：** 绝对总能量＋SVD×频带联合表＋空间模式图。
2. **解释实际视觉偏差：** 图像幅度比q＋方向余弦c＋幅度／方向偏差分解；同时比较latent保留比例与有限响应增益。
3. **判断编辑利弊：** 目标事实进展＋任务兼容保持＋伪影，辅以等能量整体缩放对照。
4. **解释最终影响：** 当前状态、时间步和后续传播；需要在线干预，不能只看冻结回放。

这些组合里，前两组已经得到本次多样本实测支持；第三组当前主要依赖具体视觉事实和有限代理；第四组只有整体分支结果，仍不足以逐模式归因。把谱值、图像响应和语义评价分清，才能避免把“能量主要在哪里”误写成“正确编辑应该沿哪里”。
