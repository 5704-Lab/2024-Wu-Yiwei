# 扩散与流模型潜空间内部性质：近期工作调研及编辑约束联系

日期：2026-10-28。承接[当前目标](任务相对语义相关性_类别形态许可与源关系保持_方向修订_2026-10-28.md)、[上一轮系统调研](干净状态源图文本联合反馈约束_主流工作与跨学科理论系统调研_2026-10-28.md)与[最新实验](当前干净状态联合语义约束_候选观测与反馈修复实验_2026-10-28.md)。逐项来源、阅读深度和迁移限制见[本轮文献证据表](扩散与流模型内部表征_文献证据与适用边界_2026-10-28.md)。

## 1. 研究判断

**值得继续，但应优先研究原模型内部新的语义观测通道，而不是把潜空间的平滑性、低维性或流形切向直接当成编辑许可。** 近期最贴近目标的发现是：多模态 DiT 的文本侧上下文表征会从图像状态吸收提示未描述的信息；注意力输出空间也有比原始注意力权重更好的概念可读性。这为“从源图读出未编辑事实，并在当前干净状态诊断偏差”提供了新的入口。

没有核查到一项工作已经证明：在冻结原 SD3 Medium、零训练、免反演、无编辑区域掩码、无额外 LLM 和目标参考的条件下，可以可靠区分类别所需形态变化与附带姿态变化，并逐步修复后者。信息存在、可读、可干预、可选择性修复是四个不同命题。本轮只完成文献与本地接口核查，没有新增 GPU 编辑实验，也没有确认新方法有效。

具体优先级是：

1. 原生文本侧上下文与图像侧 attention output 的联合观测，以及不反馈到原生成过程的概念查询。
2. 对上述观测开展当前事实／生成意图区分、源条件校准与选择性因果检验。
3. 在语义读出过关后，用局部几何改善有限步求解与数值稳定性。

## 2. 先区分“潜空间”具体指什么

本文令 $I_x$ 为源图，$x_0=E(I_x)$ 为项目中的源干净潜变量，$y_k$ 为实际 FlowEdit 干净编辑状态，$I_k=D(y_k)$。编辑步记为 $k$，标准化探测噪声时刻记为 $\tau$，网络层记为 $\ell$。

| 空间／量 | 文献常研究的性质 | 对本项目的含义与边界 |
|---|---|---|
| VAE 干净潜变量 $z$ | 重建、压缩、局部尺度与语义纠缠 | 当前 $y_k$ 所在坐标；解码几何不自动带有任务许可 |
| 含噪状态 $q_\tau$ | score、去噪流形、生成 ODE 与密度几何 | 可用于探测 $y_k$，不能替代实际 $D(y_k)$ |
| 图像侧隐藏残差 $H_{\ell,\tau}$ | 对应、概念、局部与全局信息 | 上轮读取的是这类量的降采样版本；不是所有内部空间的代表 |
| 注意力输出 $O_{\ell,\tau}$、文本侧上下文 $C_{\ell,\tau}$ | 概念可定位性、图像特有语义、内部干预 | 本轮最值得增加的观察入口；不能与原始 QK 注意力图混同 |
| 条件 AdaLN 向量 | 条件压缩、高余弦、少数高幅坐标 | 不是图像实例的完整表征；高幅坐标也不是 attention head |
| 重训编码器／适配器后的空间 | 与语义教师对齐、解耦、球面或可逆几何 | 通常属于新模型或新训练条件，不能直接套入冻结原 SD3 |

图像复滤波相位、整体向量方向、头部朝向和扩散时刻是四个不同概念。某篇论文说“direction encodes semantics”，并不意味着它研究了本项目的图像相位，或证明向量方向能区分姿态与形态。

## 3. 最直接的新证据：文本侧并非只保存提示文本

### 3.1 Contextual Reader：提示没写出的事实可能已进入上下文

[Learning to Read the Contextual Tokens in Diffusion Transformers，2026-10-05](https://arxiv.org/html/2610.06844v1)发现，MM-DiT 的文本侧表征包含图像特有的动作、视角、背景和交互信息，即使输入空提示也能包含这些内容。它读取多层文本侧联合注意力输出，通过训练的两层 Q-Former 接入冻结 LLM。主要读出实验是 SD3.5 与 FLUX.2；文中的 SD3 Medium 相关结果包含另行训练的上下文对齐，不能算原冻结 Medium 的直接能力证明。

**与目标的联系：** 未被文本描述的源事实不一定只能从外部视觉模型获得。原模型的图文交互通道可能已经压缩了它们。这比“用目标－源文本向量作为合法变化方向”更接近源实例条件下的观测。

**关键限制：** 读出器监督的是最终生成图像的回答，因而可能读取生成意图和未来结果。对当前 $y_k$ 重加噪后读出的“正面熊”，可能是模型倾向画出的熊，而不是实际 $D(y_k)$ 的朝向。必须专门检验当前事实忠实性。额外读出训练和 LLM 也不符合现有自动方法边界，当前只能借鉴表征入口。

### 3.2 ConceptAttention：换观测空间，比直接换相似度公式更有依据

[ConceptAttention，ICML 2025](https://arxiv.org/html/2502.04320v2)复用原 DiT 参数，构造只读取原图像／提示流的概念查询，发现 attention output 向量比原始交叉注意力权重更适合概念定位。概念旁路不反向改变原图像和提示流，不需额外训练。其证据主要涉及 FLUX 与 SD3.5 上的概念定位和分割，常用单 token 对象概念。

**可以迁移的思想：** 原生注意力输出、同坐标系中的概念－图像比较、只读旁路。**尚未成立的扩展：** 多词姿态／关系读出、跨类别形态的稳健性、源图与当前图的实例对应。分割出“熊”不等于知道“这只熊应该保留源头部朝向”。

本项目可以保留全空间的输出和关系，而不阈值化为区域，不用显著图乘速度，也不向原生成分支注入概念 token。观测旁路中的正常 attention 运算与编辑区域掩码应明确区分；首先核对原始速度逐查询不变。

### 3.3 Contextual Repulsion：这个空间不仅可读，也有因果影响

[On-the-fly Repulsion in the Contextual Space for Rich Diversity in Diffusion Transformers，2026](https://arxiv.org/html/2603.28762v2)直接在 MM-DiT 文本侧注意力输出中施加样本间排斥，增加同提示生成的多样性，不依赖额外模型训练。它提供了内部上下文作为干预通道的证据，且该空间的混合比空间未对齐的图像潜变量混合更有语义连贯性。

但增加多样性可能恰好改变我们要保护的姿态和背景。把排斥换成“全上下文拉回源图”也会带回旧类别。其同提示对齐不能直接迁移到源／目标不同长度、不同内容的文本。真正需要的是：先辨认受保护事实，再只修复相关残差。

### 3.4 寄存器、padding 与 attention sink：不能由权重大小推断语义许可

[Text Template Tokens Are Implicit Semantic Registers，2026-07](https://arxiv.org/html/2607.19139v2)通过因果干预表明，部分模板 token 能吸收图像信息并维持对象身份。但主要机制证据来自 Qwen-Image 系列的聊天模板；不能直接把其 token 位置映射到原 SD3 的 CLIP/T5 padding。

[Padding Tone，NAACL 2025](https://arxiv.org/abs/2501.06751)显示 padding 的作用随架构与训练配置变化。[Attention Sinks in Diffusion Transformers，ICML 2026](https://proceedings.mlr.press/v306/wu26ax.html)则直接在 SD3 做干预，表明高注意力汇聚点具有显著输出影响，但删去部分汇聚点并不必然损害文本一致性评价。两类结果不矛盾：信息承载、因果影响、评价维度及模型架构不同。对本项目，应采用等幅随机干预对照，而不是把高注意力位置或高幅坐标直接定义为编辑位置。

## 4. 语义因素可能存在，但不按词或正交轴简单分开

### 4.1 关系机制可能藏在对象 token 中

[Circuit Mechanisms for Spatial Relation Generation，CVPR 2026](https://arxiv.org/html/2601.06338v2)在受控训练的 PixArt 风格模型中比较文本编码方式。随机 token 编码时可以观察到“位置标记—对象绘制”的分工；换成 T5 后，关系信息与对象语义更紧密融合，删除显式关系词未必消除关系信息。

这给出两个直接启发：

- 不能仅用“文本没出现姿态词”来定义姿态许可，关系可能隐含在类别／对象表征里。
- 不能通过冻结整个对象 token 保姿态，因为它同时包含要改变的类别信息。

该论文采用可控几何对象与专门训练模型，不能照搬头编号。它支持寻找对象内部的关系因素与因果读出，不支持已找到原 SD3 的通用姿态 head。

### 4.2 SAE 文献：可解释不等于选择性可控

[D-Scope，2026-09-30](https://arxiv.org/html/2609.39625v1)把高激活图像 patch 的 SigLIP2 视觉证据与 SAE 特征方向连接起来。对比检索有助于目标区域变化，但论文明确报告区域外保持并未稳定改善，而且干预强度采用逐例扫描择优。其字典来自 SANA-Sprint 与 Nitro-1-PixArt，并使用 SAM3 区域；不能作为当前零训练、无区域掩码方案直接部署。

其值得借鉴的部分是“文本—视觉证据—具体内部方向”三者的连接，以及把目标收益与附带损害分开测量。文本 embedding 本身不是 latent intervention direction；高重建精度也不保证字典覆盖足够的语义因素。

[TIDE，AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/view/37006)、[Emergence and Evolution of Interpretable Concepts，NeurIPS 2025／2026 修订](https://arxiv.org/html/2504.15473v2)进一步提示概念读出依赖噪声时刻和层深。但二者依赖学习的稀疏字典；不能把“早期布局、后期纹理”的生成经验直接等同于 FlowEdit 第几步应该冻结姿态。

[Revelio，ICCV 2025](https://arxiv.org/html/2411.16725v3)还提醒，U-Net 与所研究的 DiT 的局部／全局组织并不相同，部分读出依赖专门训练的分类器。原模型包含信息，不保证均值池化后仍可读，也不保证零训练读出已有。

### 4.3 高余弦和低维不意味着细微因素可忽略

[A Hidden Semantic Bottleneck in Conditional Embeddings，ICLR 2026](https://arxiv.org/html/2602.21596v1)研究条件 AdaLN 向量，发现强坐标幅度集中和高余弦。这是条件调制空间的性质，不是所有图像实例特征的性质。论文中的高幅维度也不是 attention head。

因此全局余弦接近 1，不意味着背景或姿态没有变化；低方差因素可能恰好承载受保护事实。直接用最大方差方向作为“语义允许空间”，会把统计显著性误当成任务必要性。这个风险与上轮小头部转动被总体合法形态能量掩盖的实验一致。

## 5. 表征对齐和新型编码器提供什么，不能提供什么

[REPA](https://arxiv.org/abs/2410.06940)、[REPA-E](https://arxiv.org/abs/2504.10483)和[iREPA](https://arxiv.org/html/2512.10794v1)说明，生成表征可以通过外部视觉教师和训练改善。iREPA 尤其强调空间结构，不能只看全局识别能力。但本项目已经测过中心化关系矩阵；再次中心化旧 8×8 特征不能算新的方法突破。真正增量应是尚未检验的原生 O/C 通道、保留的空间分辨率和关系因素检验。

[Learning Representations to Guide Pixel Diffusion Transformers，2026-10-09](https://arxiv.org/abs/2610.12978)进一步区分表征质量与生成利用率：更好识别的表示不必然带来更好生成，语义也可能在后续合成中损失。其 Representation Guidance 通过训练瓶颈和调整 flow-matching 目标主动利用表征；它不是冻结 SD3 的即插即用控制。对我们，相应教训是分别验证“读得出”和“修得对”。

[RAE](https://arxiv.org/abs/2510.11690)、[Scaling T2I RAEs](https://arxiv.org/abs/2601.16208)及[SVG](https://arxiv.org/abs/2510.15301)通过新的编码／解码或语义－细节结构改善潜空间。它们说明原 VAE 并非天然最适合语义控制，却不意味着能将其编码器接到原 SD3 速度场上运行。新潜变量尺度、维数和分布需要相应训练。

[Semantic Latent Alignment with Invertible Bi-Lipschitz Adapters，2026-10-15](https://arxiv.org/html/2610.21332v1)看似最接近“保留 VAE 只改坐标”，但仍训练适配器和相应流模型。若 $w=A(z)$，一致的旧模型坐标变换应满足

$$v_A(w,t)=J_A(z)v(z,t),\qquad D_A(w)=D(A^{-1}(w)).$$

仅替换状态坐标、继续调用原速度，通常不一致。可逆变换能改变条件数，不能凭空产生新的可辨识语义。Bi-Lipschitz 界保证尺度失真受限，也不等于允许类别形态而禁止姿态。

## 6. 几何工作与目标的真正交点

### 6.1 数据流形有效性与任务合法性必须分开

[Be Tangential to Manifold，2026 修订](https://arxiv.org/html/2510.05509v3)用 score Jacobian 相关谱区分切向和法向，减少离开数据流形的引导。但正确形态变化和错误转头都可能是自然图像流形中的切向运动。其分析对象也是含噪分布，不是直接对干净 $y_k$ 给出语义判据；RF 速度 Jacobian 不能未经时刻和参数化换算当 score Jacobian。

本项目可以把此类几何用于减少伪影或控制数值步长；不能用它代替源实例关系。**不恢复已降级的 score 奇异谱主约束路线。**

### 6.2 几何异常可诊断部分坏图，但正常几何也会产生错误编辑

[Geometric Decoupling，ICML 2026](https://arxiv.org/html/2604.18804v1)研究生成映射的局部尺度、主方向一致性与高频响应，包含 SD3.5 Medium／FLUX 的结构异常分析。它提供有限差分与低秩诊断思路，但与“生成了一张正常却朝向错误的黑熊”不是同一个问题。其高频能量也不是本项目的复滤波相位。

### 6.3 普通拉回度量不自动变成有意义的语义距离

[Spacetime of Diffusion Models，ICLR 2026](https://arxiv.org/html/2505.17517v4)指出，对同维可逆 PF-ODE 简单拉回环境欧氏度量，测地线可能只是输出空间直线的坐标表示；扩散统计几何应认真处理时刻与条件分布。

这个结论不能扩大为“所有 VAE 拉回度量无用”：低维 VAE 解码器并非同维双射。但它确实提醒我们，$J_D^TJ_D$ 主要表示解码响应尺度，不能自行表达“保持朝向、允许耳形变化”。语义类型必须先进入观测定义。

### 6.4 不能把标题中的低维、等变、黎曼一概迁移

- [Geometry-Aware Image Flow Matching](https://arxiv.org/abs/2605.25294)研究整体向量范数／方向及球面建模，需要相应训练；整体向量方向不是头部朝向或图像相位。
- [Equivariant Latent Alignment](https://arxiv.org/abs/2605.30705)针对已知变换群训练对齐。启发是：保留姿态观测的等变性，同时追求对合法形态的稳健性。对姿态完全不变的特征反而看不见转头错误；一般类别形态也未必构成群作用。
- [Disentangled Representation Learning via Flow Matching](https://arxiv.org/abs/2602.05214)通过因素条件训练得到解耦，不是证明原预训练 SD3 已按该方式解耦。
- [Quadratic Geometry of Flow Matching](https://arxiv.org/abs/2603.10785)的核心是训练梯度与 NTK 结构，不能当成推理期任务许可定理。
- [Flow Matching under Noisy Latent Structure](https://arxiv.org/abs/2609.38918)给出含环境噪声的低维生成假设下的统计学习界，不提供受保护语义的划分。
- [Recovering Riemannian Geometry from Diffusion](https://arxiv.org/abs/2601.17166)讨论数学扩散半群；其条件不能因同名而默认适用于神经生成扩散或 rectified flow。

## 7. 与已有失败实验对照后，应该具体改变什么

[上一轮实验](当前干净状态联合语义约束_候选观测与反馈修复实验_2026-10-28.md)已经给出约束：

| 已有结果 | 本轮文献带来的修正 |
|---|---|
| 固定观测条件后，原 patch 与三种自动消元均为合法 40/40、错误拒绝 38/48，背向局部转头均 0/8 | 不再把文本差或小幅速度差当充分合法子空间；优先换到未测的原生 O/C 观测 |
| 完整合法变化能量被自动方向解释仅约 0.065%—4.621% | 局部线性语义方向不能覆盖有限类别路径；先验证有限变化的因素稳健性 |
| 自动局部修正更接近源回退，且 4/4 头部错误未改善参考距离 | 要同时测任务保持与真实修复方向，不能只看可微代理下降 |
| 同源能量排序有信号，跨源阈值却漏检 | 源条件合法变化尺度是独立瓶颈，不能只堆更多通道 |
| 预设文本因素能感知某些趋势，却仍混淆合法形态与姿态 | “问得更详细”不保证读出忠实，需当前事实／意图与跨因素检验 |
| 相机换侧后低层距离的对象排序反转 | 需要对象角色绑定、视角与面积反平衡；保留全空间信息也不能自动消除混杂 |

这些受控源是玩具动物，不能证明真实熊的物种形态已被建模。新文献能提出更合适的观测入口，但不能覆盖这项外推边界。

## 8. 可执行的新假设：原生联合表征上的源锚定关系反馈

以下是本项目提出的研究假设，不是上述论文已经验证的组合方法。

### 8.1 在真正的当前干净状态上建立共同探测

对源和当前状态采用相同 $\tau$、相同噪声 $\epsilon$ 和相同读出条件 $c$：

$$q_x=(1-\tau)x_0+\tau\epsilon,\qquad q_k=(1-\tau)y_k+\tau\epsilon.$$

读取

$$\Psi(y_k;c,\tau)=\{O_{\ell,\tau}(q_k,c),\ C_{\ell,\tau}(q_k,c),\ B_{\ell,\tau}(q_k,c)\}_{\ell\in\mathcal L},$$

其中 $O$ 是图像侧 attention output，$C$ 是文本侧 attention output，$B$ 是可选的只读概念旁路。源用相同定义。共同条件可分别取固定中性条件、源条件、目标条件及空条件，各分支源／当前严格配对；不能直接把不同提示 token 位置逐一相减。

图像侧源参照还应固定使用原图还是 VAE 重建源，并单独量化重建偏差；内部源探测使用 $x_0$，不能把编码／解码误差误判为编辑造成的关系变化。

本地 diffusers 接口已核对：`JointTransformerBlock.attn` 返回的 `[0]`／`[1]` 分别是图像侧／文本侧注意力模块输出；整个 block 返回的 `[0]` 则是完整文本残差，和 attention output 不同。最终 `context_pre_only` block 的文本残差输出可能为 `None`。需记录输出投影、门控与归一化位置，不能因都叫 contextual token 就混合。

现有实验主要 hook block 的图像残差并压到 8×8；因此上述比较确有新增观测，不是更名。但它们能否读出本任务尚待验证。

### 8.2 观测必须具有语义类型，且对合法变化做有限检验

目标接口仍是

$$\bigl(p_E,r_K,u\bigr)=\mathcal O\bigl(\Psi(y_k),\Psi(x_0),I_k,I_x,T_s,T_a\bigr),$$

分别为目标完成证据、未请求语义偏差和不确定性。源与请求决定保护范围；当前状态判断进度和已发生错误。**$\mathcal O$ 仍是待解决接口，不能把它当作已经实现的自由文本解析器。**

首先在明确给定的任务因素上检验：类别变化时，姿态读出对合法耳形／吻形变化稳健；真正转头时必须变化；若任务改成转头，则允许集合随请求改变。不能通过对姿态完全不变来获得所谓稳健性。

自然科学上的参照是视觉伺服中的观测与动作分离、测量学中的校准和干扰因素辨识、控制论中的条件可控性，而不是假定潜空间存在全局独立的“颜色轴”和“姿态轴”。类别形态不是已知群，故不直接取一个全局商空间，也不把正交投影当作语义分离的证明。

### 8.3 事实、意图和因果作用必须分开测试

对候选读出至少做三种交叉试验：

1. **固定干净图、换提示。** 图中朝向不变时，事实读出不能单纯跟随文本。记录其随 $\tau$ 的变化；高噪声可能主要反映生成先验。
2. **固定源、提示及噪声、换当前状态。** 未完成、正确完成、完成但转头应产生不同反馈。读出必须跟随实际 $D(y_k)$，不能只预测剩余生成会发生什么。
3. **对候选内部因素做等幅干预与随机对照。** 评价目标、朝向、背景、对象绑定分别变化多少，不能用文本一致性不降替代源关系正确。

同一源的正常形态扰动与错误姿态反例应参与离线校准；若用到已知合法目标参考，必须另列诊断，不能进入自动推理。自动推理中的内部探测若没通过语义检验，也不能自称合法参考。

### 8.4 通过观测验证后，才构造每步反馈优化

对原 FlowEdit 提议 $d_0$，在可靠语义观测下研究

$$\min_{\|d\|_M\le R_k}\ \frac12\|d-d_0\|_M^2+
\frac{\lambda}{2}\|r_K(y_k)+J_K(y_k)d\|_W^2,$$

并以可靠的任务进度／剩余可达条件保护必要编辑。$M\succ0$ 是数值尺度，$W\succeq0$ 是已验证观测的权重。候选仍需在实际 $D(y_k+d)$ 上有限验收；局部预测不能代替最终语义。

这里必须包含当前残差 $r_K$，仅抑制 $J_Kd$ 无法修复既有错误。也不能用完整源上下文差替代 $r_K$，否则把黑熊拉回棕熊同样能降低残差。

若 $J_E$ 是可靠任务读出的局部 Jacobian，保持任务读出不变时可用于修复的能力可以用

$$\mathcal G_{K\mid E}=J_KM^{-1}J_K^T-
J_KM^{-1}J_E^T(J_EM^{-1}J_E^T)^\dagger J_EM^{-1}J_K^T$$

分析。它等于在 $J_Ed=0$ 子空间中的局部保持可控 Gramian；小特征值表示相应观测残差难以在局部保护任务时修复。**前提是 $E/K$ 已有正确语义类型**，否则只是在分析错误代理的可控性。局部困难也不证明有限路径不存在。

几何工作适合在这里提供尺度预条件、信赖域和线性化误差诊断。例如对观测 $\psi$ 检查

$$e_{\rm lin}(d)=\frac{\|\psi(y_k+d)-\psi(y_k)-J_\psi d\|}{\|J_\psi d\|+\varepsilon}.$$

这样几何服务于已经定义清楚的关系约束，而非自行决定语义许可。高维观测的 Jacobian 仍应采用 JVP/VJP，计算开销和显存必须单独记录。

## 9. 下一阶段的证伪顺序

| 阶段 | 具体比较 | 进入下一阶段的证据 |
|---|---|---|
| 0 接口 | 旧图像残差 H、原生图像 O、文本 C、只读概念 B；只读路径与原速度对齐 | 无干预速度一致，明确层／投影／噪声定义 |
| 1 当前事实 | 同图换文本、同文本换状态、低／中噪声对照 | 读出跟随真实干净状态，能区分形态与两方向转头；不能只用最终生成预测 |
| 2 有限许可 | 纯改色、类别形态、显式转头三任务；视角／对象面积反平衡 | 任务变化时许可相应变化；新源上合法接受与错误拒绝同时成立 |
| 3 因果修复 | 已正确、欠编辑、已转头三种起点，等幅随机、源回退和缩步对照 | 修复朝向且保住合法类别，而不是只降低自身代理 |
| 4 完整轨迹 | 多源、多种子；目标完成、源关系和质量独立评价 | 在相近实际完成程度下减少附带变化，收益不由缩步解释 |

第一阶段用预设可核验因素，只验证表征能力，不宣称自由文本分析已解决。若 O/C/B 仍不能分清合法形态与错误姿态，应暂停完整轨迹调参；若只有训练 Q-Former／SAE／外部 LLM 才能读出，则应报告“当前零训练条件下未获得可靠观测”，不能悄悄改变条件。

本轮对主线的具体推进是：从笼统的“内部特征有语义”，收敛到**原生上下文／注意力输出能否提供忠实于当前干净图、对合法形态稳健而对源关系错误敏感的联合观测**。相位仍用于这一语义许可成立后的结构响应诊断，不恢复为未经语义辨识的独立硬约束。
