# DiT token 文献逐项数学审查：82 条核心方法、贡献、优势与局限

日期：2026-10-22。对应[原调研的 82 个方法／家族编号](DiT_token优化_编辑质量与推理加速_图关系几何概率流_文献调研与总结_2026-10-21.md)。综合推导与候选见[逐步编辑的条件关系与信号观测](逐步图像编辑的条件关系与信号创新_跨学科理论分析与候选方案_2026-10-22.md)。

本文逐项回答：方法操作什么数学对象，贡献在哪，优势与局限是什么，对“棕熊→黑熊而姿态／背景保持”的启发能走多远。82 条包含家族、扩展版本和少量邻近前作，不等于 82 篇独立、原生、免训练 DiT 编辑论文。

公式分为原文直接机制与**统一数学重述**；后者用于分析，不冒充作者原式或完整算法。方法性质以此前核验全文、当前补读的方法／限制段及原始来源为依据；仅核验摘要的支线明确限制结论。未执行作者代码或真实模型实验，不比较跨硬件速度排名。

## 0. 共同数学对象与六项审查标准

写一个块为 $H_{\ell+1}=H_\ell+F_\ell(H_\ell,t,c)$。token、头、层、时间和条件流是不同维度。多模态注意力为：

$$
O=AV,\qquad A=\operatorname{softmax}(QK^\top/\sqrt d).
$$

统一检查：

1. 优化原模型近似误差，还是纠正原模型已有的语义错误？
2. 使用特征相似、当前贡献、动态响应、集合覆盖，还是源身份信息？
3. 保证针对代理、线性算子、计算成本，还是实际编辑语义？
4. 冻结骨干以外是否学习模块、token、LoRA 或蒸馏？
5. 是否依赖参考、反演、mask、用户对应或额外 MLLM？
6. 关系中哪些变化不可见，错误会怎样传播？

一个通用局部式是：

$$
\delta O=(\delta A)V+A\delta V,\qquad
\delta y_{\mathrm{final}}
\approx\Phi\,\delta y+\text{后续累计误差}.
$$

只保留相关性或范数，通常没有包括值方向、误差抵消和后续敏感性。各项“可借鉴”是研究启发，不表示完整方法满足当前约束。

## 1. A01—A05：合并、代表与非对称缩减

### A01. ToMeSD

[原论文](https://arxiv.org/abs/2303.17604)。

**核心机制**：通过二部相似匹配把若干源 token 合到目的 token，处理较短序列后展开。可统一写成 $H'=U F(MH)$；$M$ 压缩，$U$ 传播到原位置。贡献是将无需重训的合并用于扩散推理，并处理扩散结构的实际开销。

**优势**：接口简单，直接减少部分注意力／MLP 计算，展示 token 冗余可被利用。**局限**：$F(MH)\ne MF(H)$，展开不是逆变换；相似毛纹可能位于不同部件。原始主证据是 U-Net Stable Diffusion，不能直接作为 DiT 编辑收益。

**对本目标的意义**：可借鉴代表与对应运算，不能用“可合并”定义“语义可改变”。原模型姿态已错时，忠实近似它仍然错。

### A02. Importance-Based Token Merging

[原论文](https://arxiv.org/abs/2411.16720)。

**核心机制**：以 $I_i=\|\epsilon_c-\epsilon_\varnothing\|_i$ 构造重要池，再选择合并锚和独立重要 token，兼顾重要性与多样性。贡献是把“目的节点应承载哪些内容”加入相似合并。

**优势**：在本来使用双分支 CFG 的模型中可利用已有预测，减少关键内容被不重要节点代表。**局限**：该信号更接近条件敏感性；不完整提示未关注的源细节可能低分。内嵌引导模型未必免费提供无条件分支。

**启发**：锚的资格应包含信息价值和覆盖；对熊的姿态保持还需要与 CFG 显著性不同的观测。

### A03. ToMA

[原论文](https://arxiv.org/abs/2509.10918)、[ICML 正文](https://raw.githubusercontent.com/mlresearch/v267/main/assets/lu25v/lu25v.pdf)。

**核心机制**：用 $F(D)=\sum_i\max_{j\in D}S_{ij}$ 选择有代表性的目的集合，以注意力式矩阵完成合并／展开，再结合局部窗口和映射复用。贡献同时包含集合优化和硬件适配。

**优势**：避免只保留同一前景的重复代表，矩阵实现可降低不规则访存开销。**局限**：次模近似保证属于规定的覆盖目标；$m<N$ 时压缩信息一般不能无损恢复。转置展开近似伪逆需要条件。

**启发**：保持锚应具有互补性。但特征覆盖未必覆盖姿态的弱方向，更不能将次模保证直接称为编辑保持最优。

### A04. DaTMe

[原论文](https://arxiv.org/abs/2610.22370)，近期预印本。

**核心机制**：综合清晰预测时间变化 $|\hat x_0^t-\hat x_0^{t-1}|$ 与空间粗细差 $|\hat x_0-\operatorname{UpDown}\hat x_0|$，区分合并源、目的和保留的结构锚，配合局部匹配。

**优势／贡献**：明确保护未被文字充分关注的轮廓和纹理，超出 CFG 前景显著性。**局限**：清晰预测是模型估计；稳定的错误姿态仍可低动态。伪真值为原模型最终生成，时间推导受采样约定限制。

**启发**：结构价值和时间活跃度必须分开；不能因为熊的背景暂时不动，就推断其已正确。

### A05. AsymRnR

[原论文](https://arxiv.org/abs/2412.11706)。

**核心机制**：分别缩减 Q 和 K/V：

$$
Q'=R_QQ,\quad K'=R_KK,\quad V'=R_KV,\quad
O'=U_Q\operatorname{softmax}(Q'K'^\top/\sqrt d)V'.
$$

**优势／贡献**：承认查询端和上下文端冗余不同，K/V 配对一致，Q 输出再恢复，位置操作与缩减可分开。**局限**：近似误差仍受路由、值和恢复共同影响；主要是视频生成，不能从非对称压缩推出因果解耦。

**启发**：关系图中“被更新的状态”与“提供上下文的节点”应分清，不必一律采用同样权重。

## 2. A06—A14：刷新、缓存、轨迹与参考贡献

### A06. ToCa

[原论文](https://arxiv.org/abs/2410.05317)。

**核心机制**：选择部分 token 真实计算，其他复用缓存；分数结合注意力读取量 $\sum_iA_{ij}$、文字熵、缓存年龄及空间分布。缓存的是模块特征，残差通道与层类型另有调度。

**优势／贡献**：从统一整层复用走向 token 级预算，显式处理信息传播和长期陈旧。**局限**：注意力列和只近似局部读取；不包括值方向和后续敏感性。显式提取注意力可能与高效核冲突。

**启发**：观测也需覆盖和更新历史；其“重要”首先是重算风险，不是源身份价值。

### A07. DuCa

[核验版本](https://arxiv.org/abs/2412.18911)。

**核心机制**：激进的大范围缓存与保守局部更新交替，在误差积累和纠正机会之间折中。选择消融表明，多样刷新／随机刷新在特定预算中可优于一些高分集中刷新。

**优势／贡献**：将刷新策略和缓存粒度联合考虑，指出复杂重要性排序并不总有净收益。**局限**：不能由特定消融推出 token 普遍等价，也不能混用早晚版本的实现描述。

**启发**：保留一组相互重复的高分熊脸 token，可能不如补充背景、边缘和姿态的互补观测。

### A08. TokenCache

[原论文](https://arxiv.org/abs/2409.18523)。

**核心机制**：Cache Predictor 输出输入／时间相关的门控 $\alpha_{\ell i}$，近似模块为 $\alpha F(H)+(1-\alpha)F_{\mathrm{cache}}$；以预测一致性与预算损失学习决策，核验全文还有末层 LoRA 适配。

**优势／贡献**：门控能适应内容，不必固定全样本缓存规则。**局限**：局部误差目标未包含真实实例保持，预测器和适配需要训练；骨干教师冻结不表示系统零训练。

**启发**：如果未来放宽训练约束，它是学习计算风险的参照；当前不能直接移植为无需学习的编辑判别器。

### A09. RAS

[原论文](https://arxiv.org/abs/2502.10389)。

**核心机制**：依据预测噪声统计和跳过次数选择活动 token；活动查询读取当前与缓存上下文：

$$
O_a=\operatorname{softmax}(Q_a[K_a,\tilde K_i]^\top/\sqrt d)
[V_a,\tilde V_i].
$$

**优势／贡献**：减少查询和 token 计算，同时保留全局背景上下文。**局限**：缓存 K/V 过时；复用输出速度后潜状态仍可积分变化，不能称冻结背景。

**启发**：计算位置与图像变化位置不同。当前目标需要观测实际干净状态，而不仅统计哪些 token 被重算。

### A10. CAT Pruning

[原论文](https://arxiv.org/abs/2502.00433)。

**核心机制**：相对历史噪声变化、选择频率／陈旧度与聚簇共同决定 token 更新；未选择节点复用特征。

**优势／贡献**：在变化幅度以外显式加入长期未更新和空间分布，缓解集中重算前景造成背景退化。**局限**：探索／刷新得到计算覆盖，不表示语义范围已识别；低噪声变化可对应错误但稳定的结构。

**启发**：动态指标不能单独判断“该保持哪里”，但可以提示观察器不应长期忽略同一区域。

### A11. SODA

[原论文](https://arxiv.org/abs/2603.07057)。

**核心机制**：离线测量时间、层、模块与缓存／剪枝配置的敏感度，再优化调度与预算。统一看，是在有限计算图上分配误差风险。

**优势／贡献**：把误差非均匀性变为可计算调度问题，不仅依赖经验固定间隔。**局限**：校准场景与新模型／任务的敏感度可不同；优化成本表不是恢复真实编辑语义。

**启发**：先校准观测和修正对目标、结构的响应；不应在未校准保持量时就花力气优化步数。

### A12. ResCa

[作者项目](https://fanghaipeng.github.io/ResCa/)、[正文](https://openaccess.thecvf.com/content/CVPR2026/papers/Fang_ResCa_Residual_Caching_for_Diffusion_Transformers_Acceleration_CVPR_2026_paper.pdf)。

**核心机制**：历史轨迹聚类，每簇一个 proxy token 真实计算，多阶残差用于其他 token 的模拟去噪；稠密步更新历史。

**优势／贡献**：区别“自己的状态＋借用动态变化”与直接复制他人状态，避免静态缓存完全陈旧。**局限**：相似短期残差不能保证改变条件后的未来一致；代理可能跨越不同语义部件。GFLOPs 收益不能原样当作延迟。

**启发**：源实例响应图可以包含动态指纹；但不能把最可预测的簇误称最应保留的实例结构。

### A13. JiT

[原论文](https://arxiv.org/abs/2603.10744)。

**核心机制**：$\dot y=\Pi_k u_\theta(S_k^\top y,t)$，稀疏锚点算速度，插值驱动完整状态；逐阶段激活新 token，并用微流处理转场。

**优势／贡献**：直接把 token 预算接到生成 ODE，重要性用局部速度变化。**局限**：$S_k^\top\Pi_ku=u$ 只保证插值不覆盖锚点；不保证缩减网络等于完整网络。新 token 噪声尺度正确也不自动保证联合分布正确。

**启发**：每步修正须区分观测、状态和速度的空间；稀疏信息的提升算子应有明确误差，而不是默认语义无损。

### A14. ToPi

[原论文](https://arxiv.org/abs/2602.01609)。

**核心机制**：先校准代表层，再按 $I_j=\sum_{\ell,h}\|V_j\|\sum_{i\in\mathrm{target}}A_{ij}$ 等贡献代理剪参考 token，并适应采样过程。

**优势／贡献**：利用参考与输出角色不对称，注意力与内容幅度共同决定贡献。**局限**：向量抵消、位置、后续层未被完整计入；联合注意力子块与只在参考键内 softmax 的行和不能混同。需要校准。

**启发**：关系应同时考虑“连接”与“承载内容”；但高贡献参考也可能携带目标不需要的源外观。

## 3. A15—A22：特征预测、低秩和稀疏边

### A15. TeaCache

[原论文](https://arxiv.org/abs/2411.19108)。

**核心机制**：用时间调制输入的变化估计输出特征变化，重标定并累计到阈值后决定是否重算。其逻辑是以便宜输入统计预测昂贵输出风险。

**优势／贡献**：避免每次先计算完整输出再判断是否可以缓存。**局限**：输入变化与输出变化的映射依模型／阶段，局部统计不能独立识别姿态。主要不是逐 token 语义排序。

**启发**：可设计低成本预警决定何时测量，但低成本代理必须对真实结构误差有独立校准。

### A16. TaylorSeer

[原论文](https://arxiv.org/abs/2503.06923)。

**核心机制**：从历史特征有限差分得到高阶预测，形式类似 $\hat H(t+\delta)=\sum_{r=0}^p\delta^rH^{(r)}(t)/r!$。

**优势／贡献**：相较零阶缓存，允许特征持续演化。**局限**：步长不均、导数估计噪声、转阶段与非平滑响应会破坏外推；预测“正确地继续变化”并不说明变化符合用户意图。

**启发**：历史应帮助估计修正需求与传播，而不是让源锚随当前预测一路漂移。

### A17. SVD-Cache

[原论文](https://arxiv.org/abs/2601.07396)。

**核心机制**：$H=H_{\mathrm{principal}}+H_{\mathrm{residual}}$，主子空间较平滑而进行预测，低能量剩余部分直接复用。

**优势／贡献**：不把所有通道统一视为相同的时间过程。**局限**：SVD 能量由方差定义，微小身份标记可处于低能量残差；主子空间也可能包含不希望的全局光照偏移。分解开销不可忽略。

**启发**：白化与分量建模有价值，但保持语义不能由奇异值大小自动命名。

### A18. PAB

[原论文](https://arxiv.org/abs/2408.12588)。

**核心机制**：分别分析空间、时间、交叉注意力输出的时间变化，设置不同广播／复用区间。

**优势／贡献**：按模块作用和变化规律分配缓存，而非一个间隔覆盖全模型。**局限**：规律受模型和采样设置影响；视频生成的广播保真不提供真实单图身份保持。

**启发**：观测层与刷新时间不宜统一处理，但应先证明它们对当前要修正的偏移敏感。

### A19. Sparse VideoGen

[原论文](https://arxiv.org/abs/2502.01776)。

**核心机制**：识别具有空间或时间稀疏模式的头，用稀疏块和专用核计算重要交互。输出节点通常保留，删的是部分计算边。

**优势／贡献**：将注意力模式与硬件布局结合，减少长视频二次交互。**局限**：头类型和模式是经验近似，长距离细节、对称部件或交互可能依赖未选边。

**启发**：图的边类型有意义；但删计算边不是抑制图像语义耦合的直接证明。

### A20. Sparse VideoGen2

[原论文](https://arxiv.org/abs/2505.18875)。

**核心机制**：语义相似聚簇与排列，使重要交互连续，再用动态预算和稀疏核计算。

**优势／贡献**：避免按原位置分块导致重要 token 分散、计算浪费。**局限**：聚类“语义”是特征相似代理；重排要连同位置身份保持一致。否则 $PAP^\top$ 的置换等价条件不成立。

**启发**：关系选择与计算组织要分开；不能因为聚簇更紧密，就认定更好表达源姿态。

### A21. STA

[原论文](https://arxiv.org/abs/2502.04507)。

**核心机制**：三维滑动窗口注意力与 tile 实现，使邻近时空 token 高效交互。

**优势／贡献**：位置邻域是明确的归纳偏置，硬件友好。**局限**：远距离语义联系被压缩；免训练与激进微调版本不同，速度不能混报。

**启发**：局部边能提供稳定结构观测，但只用局部结构无法保证全局朝向或部件身份。

### A22. SpargeAttention

[原论文](https://arxiv.org/abs/2502.18137)。

**核心机制**：在线块预筛和 softmax 感知跳过，避免计算低贡献块。

**优势／贡献**：以便宜统计估计注意力稀疏性，兼顾核实现。**局限**：这是近似算子，与精确 FlashAttention 不同；范数小的输出误差仍可沿后续敏感方向放大。

**数学辨析**：若仅删去固定注意力行质量 $\epsilon$ 并对余项归一化，V 有界时可得局部误差界；真实筛选还会近似 logit、归一化和精度，不能直接套用最简单界。

## 4. A23—A34：编辑复用、接口改造、路由与量化

### A23. CacheEdit

[ICML 原论文](https://proceedings.mlr.press/v306/yu26e.html)。

**核心机制**：比较编辑轮、采样步和网络层的激活；首步深层差异早于明显 latent 差异，据此识别不变 token 并复用缓存。

**优势／贡献**：直接研究多轮编辑冗余与一致性，观察的是指令已进入网络后的状态。**局限**：跨轮历史与区域判别是前提；激活差小不等于细粒度目标无需改，当前流程有内部区域化。

**启发**：保持观测的时刻和层要基于信号可见性，不能只看最终 latent 幅度。

### A24. SpotEdit

[原论文](https://arxiv.org/abs/2512.22323)。

**核心机制**：用早期清晰预测与源图的感知差识别保持 token，减少其重算，融合上下文 K/V，并最终源 latent 替换。

**优势／贡献**：把效率与直接保持结合，超出普通缓存的近似保真。**局限**：区域判错会漏改；回填 latent 不等于 RGB 区域严格不变，解码感受野仍传播。内部二值路由不满足严格无区域 mask。

**启发**：可以借鉴源创新闭环，不能把“早期稳定”作为正确语义真值。

### A25. AnchorCache

[核验 v3](https://arxiv.org/abs/2608.21229v3)。

**核心机制**：通过静态文字锚与注意力布局，使参考分支不再接收随步变化的状态，从而精确复用 K/V；再用教师强制与 on-policy 蒸馏恢复质量。

**优势／贡献**：将“可缓存”与“有指令条件”之间的结构冲突明确化。**局限**：精确是改造后结构内的精确，不是与原全注意力模型等价；质量恢复需要训练。

**启发**：干扰如何进入关系必须按计算图追踪，而不是凭输入图像固定就假定中间源特征固定。

### A26. HiLo-Token

[原论文](https://arxiv.org/abs/2606.13898)。

**核心机制**：全局低频表示、高频区域 token 和膨胀编辑 mask 内完整 token 联合输入，配合后训练与蒸馏。

**优势／贡献**：遮挡条件下不单靠相关匹配，仍保留远处高频上下文；直接服务编辑延迟。**局限**：用户 mask、学习后的接口和任务专门化是关键。高频不是普遍身份标签。

**启发**：保留信息需兼顾低频组织和细节，不能只保留文字关注处。

### A27. DyDiT

[原论文](https://arxiv.org/abs/2410.03456)。

**核心机制**：时间相关动态宽度与空间 token 动态计算，通过学习路由适应不同冗余。

**优势／贡献**：将 token、通道和时间共同纳入预算。**局限**：路由与模型适配需要训练；被学习保留的是生成性能所需计算，不是源姿态信息。

**启发**：证明了统一计算可被打破，但不构成当前冻结模型的直接解法。

### A28. DyDiT++

[原论文](https://arxiv.org/abs/2504.06803)。

**核心机制**：扩展动态计算与适配到更多扩散／流模型和任务配置。

**优势／贡献**：研究动态计算在更大骨干和更广设置中的可扩展性。**局限**：额外训练仍是条件；不能将不同模型的动态策略当作一个固定免训练门控。

**启发**：可作为若允许学习时的效率参照；本轮重点应先确定“保持什么”，再决定如何动态分配计算。

### A29. DDiT

[原论文](https://arxiv.org/abs/2602.16968)。

**核心机制**：根据 latent 演化动态选 patch 大小，早期可用较粗 token，后期恢复细粒度；新增接口和 LoRA 蒸馏使模型支持这些 patch。

**优势／贡献**：从输入分词粒度减少计算，调度本身可免训练。**局限**：支持不同 patch 的模型需要适配，粗 token 会丢细节；调度免训练不等于整个方法免训练。

**启发**：多尺度观测有价值，但粗尺度的姿态正确不代表细尺度身份已保留。

### A30. LESA

[原论文](https://arxiv.org/abs/2602.20497)。

**核心机制**：按去噪阶段使用学习式特征预测专家，包括 KAN 类函数拟合。

**优势／贡献**：不要求一个预测规律适用全部阶段。**局限**：专家学习和迁移误差需要数据；函数逼近定理并不提供有限网络的准确误差或语义保证。

**启发**：阶段差异必须处理，但不能用一个预测器名称代替对早期结构和晚期纹理的实际辨识。

### A31. ViDiT-Q

[原论文](https://arxiv.org/abs/2406.02540)。

**核心机制**：针对 token、通道、CFG 和时间上的分布变化采用动态量化／通道平衡及混合精度。

**优势／贡献**：识别 DiT 激活分布不同于 U-Net，改善低比特质量。**局限**：PTQ 仍需校准；量化误差小不表示原编辑正确。通道重标定对特征相似性观测也会产生坐标影响。

**启发**：比较相关性前必须明确特征尺度与数值精度，不能把量化异常看成语义漂移。

### A32. Q-VDiT

[原论文](https://arxiv.org/abs/2505.22167)。

**核心机制**：token-aware 量化误差估计／补偿与时间保持蒸馏。

**优势／贡献**：不只在权重维度看量化，考虑超长视频 token 与时间误差。**局限**：补偿与蒸馏有学习；校准目标是原模型一致性，而非源实例语义。

**启发**：误差应按维度和传播分配；不能据“token aware”推断已经识别编辑因果关系。

### A33. S²Q-VDiT

[原论文](https://arxiv.org/abs/2508.04016)。

**核心机制**：Hessian 感知选择校准数据，以注意力引导 token 级蒸馏权重。

**优势／贡献**：同时优化样本和 token 的校准价值，避免长序列下均匀损失稀释关键误差。**局限**：Hessian 敏感性依给定损失；该损失没有定义姿态／背景应不变。PTQ 中的优化不能称完全无需学习。

**启发**：测量设计和观测选择同样重要，但保持损失本身必须先可信。

### A34. Elastic Token Compression

[原始摘要](https://arxiv.org/abs/2608.29281)。

**核心机制**：按 Hilbert 顺序切分并汇聚连通内容区域，Region Token Interface 微调以支持可变预算。

**优势／贡献**：代表节点保留连通几何，不像纯相似合并把远处分散位置混为一组。**局限**：依赖像素空间模型和接口学习；连通性不等于对象身份或语义一致。

**证据限度／启发**：本项只使用已核验的原始摘要，不外推完整实现；可借鉴关系的空间组织，不能直接迁移全部速度结论。

## 5. E01—E10：直接编辑、源特征和注意力控制

### E01. DiT4Edit

[原论文](https://arxiv.org/abs/2411.03286)。

**核心机制**：在 PixArt 上结合 DPM-Solver 反演、特征／注意力控制和 patch merging。源轨迹信息参与目标编辑，合并降低部分计算。

**优势／贡献**：早期直接探索 Transformer 扩散编辑与效率，不局限于 U-Net 控制迁移。**局限**：高阶反演仍是数值近似，不能因求解器阶数提高就认定精确源恢复；特征共享与压缩也会阻碍必要变化。

**启发**：应分开核对反演误差、源控制和 token 近似，不能把它们的总收益归于一种关系表达。

### E02. Stable Flow

[原论文](https://arxiv.org/abs/2411.14430)。

**核心机制**：用干预／消融定位 vital layers，在重要层共享源特征，兼顾源保持与目标可编辑性。

**优势／贡献**：把层作用转为可测的生成敏感性，减少无差别注入。**局限**：生成对某层敏感不代表该层只编码姿态；层选择和任务类型相关，真实图像还需源特征获取。

**启发**：关系观测应从有实际辨识力的层提取，而不是先验指定“浅层保结构、深层改语义”。

### E03. FreeFlux

[原论文](https://arxiv.org/abs/2503.16153)。

**核心机制**：对 RoPE 移除／位移干预，观察各层对位置和内容的依赖，再按任务设计 K/V 注入。

**数学意义**：图像 logit 含 $q_i^\top R(p_i-p_j)k_j$ 类相对位置作用。相同特征值与不同位置可产生不同路由。

**优势／贡献**：反对固定层语义划分，有直接编辑策略。**局限**：位置干预的输出敏感性不是完整语义分离；源特征注入仍可能复制不该保留的外观，真实图像与反演还有差距。

**启发**：内容相关图必须明确坐标；观察器可利用位置，但不能把位置保留用于所有编辑。

### E04. QK-Edit

[核验版本](https://arxiv.org/abs/2610.17829)。

**核心机制**：分析多模态联合注意力，使用源视觉 Q/K 的选择性注入控制路由，目标 V 等内容路径仍发挥作用。

**优势／贡献**：保留部分结构路由而不复制全部源内容，并保持与高效注意力接口的兼容性。**局限**：$A$ 相同而 $V$ 不同仍可改变输出；Q/K 已受上游文字和调制影响。真实图像的源轨迹通常来自反演。

**启发**：路由是可观察对象，但不等于姿态真值；应与固定坐标信号联合验证。

### E05. KV-Edit

[原论文](https://arxiv.org/abs/2502.17363)。

**核心机制**：仅对编辑区域计算查询，读取前景／背景完整 K/V，背景由源状态保持；删除任务需处理旧对象语义残留，另有免反演变体。

**优势／贡献**：将背景保持变成直接状态约束，同时利用上下文生成编辑区。**局限**：需要区域信息；背景特征可含前景语义；固定 latent 后的 RGB 仍受解码 Jacobian 跨位置影响。

**启发**：观测背景和注入背景是不同操作。对严格无 mask 情况，只借鉴源锚与污染分析，不照搬区域冻结。

### E06. HeadRouter

[原论文](https://arxiv.org/abs/2411.15034)。

**核心机制**：比较不同条件下头表示差异，路由注意力头，再通过图像／文字双 token 精炼维持目标语义。

**优势／贡献**：利用头的功能异质性，比统一注入更灵活。**局限**：头变化可能来自姿态、光照或公共条件；“与编辑不同”不能自动表示“任务必需”。多个头还存在冗余和协同。

**启发**：重要性应区分条件响应与源保持，不应把最大变化头当作唯一编辑解释。

### E07. ReFlex

[原论文](https://arxiv.org/abs/2507.01496)。

**核心机制**：提取中间步源特征，对 I2I、I2T 交互作适配，注入残差；局部编辑利用注意力区域混合。

**优势／贡献**：区分可迁移结构与易泄漏外观，处理源信息过强导致不可编辑的问题。**局限**：内部 mask 不满足严格设置；中间步特征仍由源条件塑造，适配不能保证完全分离。

**启发**：保持量应有允许变化的模型，不能只把源特征距离压到零。

### E08. FIA-Edit

[原论文](https://arxiv.org/abs/2511.12151)。

**核心机制**：在免反演 FlowEdit 中，让源／目标特征发生频域交互，并在注意力中注入源信息，可概括为 $\mathcal F^{-1}\Gamma(\mathcal F f_s,\mathcal F f_a)$ 与特征共享。

**优势／贡献**：直接在当前研究骨干的查询／速度计算中增加源信息，不必先生成完整反演轨迹。**局限**：频率成分不自动等于结构或语义；源注入仍有保持／编辑权衡。不能将评测 mask 混为推理依赖。

**启发**：源信号可以在每步参与编辑；新候选需要比“某频带是结构”更明确的不变性假设。

### E09. ColorCtrl

[原论文](https://arxiv.org/abs/2508.09131)。

**核心机制**：保持源图像内部关系，非编辑区域用源视觉 V 保色，目标词控制支持指定颜色变化。

**优势／贡献**：直接研究附带颜色变化，区分结构路由、视觉颜色内容与文字引导。**局限**：依赖内部区域；颜色、光照、材质不是完全独立，路由相同也不保证所有几何相同。

**启发**：最接近熊毛色案例的编辑证据之一；可借鉴观测类型分工，但不能把完整流程称为无 mask。

### E10. DCAG

[原论文](https://arxiv.org/abs/2602.18022)。

**核心机制**：分解 K/V 为共享偏置与 token 差异，再分别调节路由与聚合通道。

**优势／贡献**：把单一引导强度扩展成两个有算子含义的控制维度。**局限**：对所有键相同的 logit 位移被 softmax 消去；对模态子组的偏置、RoPE 前后的偏置不同。二维参数仍不等于语义解耦。

**启发**：先消除无效规范方向再谈相关性；对观测中心化有帮助，但生成通道不能无条件删均值。

## 6. E11—E18：扩展上下文、身份参考、对应与条件接口

### E11. Add-it

[原论文](https://arxiv.org/abs/2411.07232)。

**核心机制**：源图、目标图和文字 token 加权扩展注意力，结合结构转移与主体区域融合。

**优势／贡献**：源上下文帮助插入物体，同时允许阴影／反射等合理附带结果。**局限**：原图注意力过强会阻碍插入，完整流程有 SAM-2 区域精炼与真实图像反演等前提。

**启发**：“无关区域不改”不能被解释为所有邻近像素严格不动，任务必要后果需要保留。

### E12. Personalize Anything

[原论文](https://arxiv.org/abs/2503.12590)。

**核心机制**：用参考主体的去噪 token 替换／约束目标 token，结合早期注入、后期正则和局部扰动支持主体定制。

**优势／贡献**：直接利用参考的细粒度实例信息，不只依赖类别词。**局限**：参考主体、区域及位置关系是输入前提；强替换可能复制姿态，局部扰动也会改变细节。

**启发**：真实身份保持需要比类别显著性更丰富的视觉通道，不能由一个高分 token 自动获得。

### E13. LazyDrag

[原论文](https://arxiv.org/abs/2509.12203)。

**核心机制**：用户拖拽给出显式对应图，注意力按对应传播，减少隐式匹配的漂移。

**优势／贡献**：把“源位置应到哪里”从估计问题转为约束输入，直接改善移动／形变控制。**局限**：反演、用户点／区域与对应质量是条件；二维对应未完整确定三维可见性。

**启发**：固定坐标与随任务移动的对应是两类不同约束。熊毛色案例可以先固定，换姿态任务则不能沿用。

### E14. ContextDrag

[原论文](https://arxiv.org/abs/2512.08477)。

**核心机制**：在上下文编辑器中利用清晰源 token，重编码目标位置并屏蔽重叠冲突信息。

**优势／贡献**：避免仅注入清晰参考而位置不一致造成纹理／语义混乱。**局限**：有用户拖拽与注意力 mask；源、目标重叠与遮挡仍复杂。

**启发**：关系匹配不能忽略位置的规范，删除冲突边的效果不能自动推广为无区域条件。

### E15. AttnRouter

[原论文](https://arxiv.org/abs/2605.01480)。

**核心机制**：同次 forward 中把清晰源流 K/V 按比例混入噪声流，按编辑类别选择注入强度、层和时段。

**优势／贡献**：利用已有源条件流，不必重复生成独立中性源轨迹；类别化处理保持强度。**局限**：oracle 类别与 CLIP 自动分类不同；离线网格搜索有成本；加法编辑中额外源偏置可能有害。

**启发**：同一条件下获取保持观测比混合两种提示更清楚；不能假设所有任务都该增加源信息。

### E16. OminiControl

[原论文](https://arxiv.org/abs/2411.15098)。

**核心机制**：复用 VAE 和 DiT 处理条件 token，配合位置与注意力控制，通过少量适配学习条件接口。

**优势／贡献**：不必为每类控制构建完整独立大网络，复用原有 token 处理能力。**局限**：LoRA 学习是功能建立的重要部分，任意拼接条件不等于原骨干已理解其角色。

**启发**：图节点的语义与通道身份需有来源，不能在无训练设置中随意添加“姿态 token”。

### E17. OminiControl2

[原论文](https://arxiv.org/abs/2503.08280)。

**核心机制**：紧凑条件 token 表示与条件特征复用，减少重复条件处理。

**优势／贡献**：条件输入与目标去噪角色不对称，可以在训练后的接口中压缩／缓存。**局限**：LoRA 训练仍存在；条件特征能否缓存取决于具体信息流，不仅因为输入图固定。

**启发**：若保持观测使用独立源分支，也需要说明它是否受到目标状态和时间调制影响。

### E18. ICEdit

[原论文](https://arxiv.org/abs/2504.20690)。

**核心机制**：利用上下文图像布局和条件 token 联合处理，通过适配／LoRA 路线建立编辑能力。

**优势／贡献**：展示通用生成 token 交互可以学习成编辑接口。**局限**：in-context 指推理输入方式，不代表整个方法无训练；部分增强流程还含附加组件。

**启发**：可比较成熟编辑骨干的能力，但不把训练后的编辑先验当作当前原始 FlowEdit 的已有功能。

## 7. E19—E27：学习式语义、位置与残差表示

### E19. RVEDiT

[原论文](https://arxiv.org/abs/2605.24674)。

**核心机制**：将 MLLM 推理信息蒸馏为编辑 token，结合参考注意力对齐和不同深度的信息路由。

**优势／贡献**：显式补充编辑意图和细粒度语义，训练时可以约束条件对齐。**局限**：需要学习及多模态教师；部署时没有 MLLM 不等于训练过程没有额外语义监督。

**启发**：部分语义可辨识性是被训练出来的，不能用无监督相似图替代后声称等价。

### E20. InfiniteYou

[原论文](https://arxiv.org/abs/2503.16418)。

**核心机制**：身份编码与 InfuseNet 等注入模块使 FLUX 使用参考人像的身份信息。

**优势／贡献**：身份目标有专门表示与监督，允许重新构图或风格变化。**局限**：特定身份模块、训练与参考输入不是免费条件；人脸身份证据不直接推广到跨物种熊的全部实例细节。

**启发**：身份保持与几何保持不同，主候选不能仅因姿态更稳就宣称身份完整保留。

### E21. PuLID-FLUX

[作者说明](https://github.com/ToTheBeginning/PuLID/blob/main/docs/pulid_for_flux.md)。

**核心机制**：预训练的身份提取／适配模块把参考人像信息注入 FLUX 图像 token。

**优势／贡献**：新用户推理时无需逐人 LoRA，身份通道比自然语言细致。**局限**：身份模块经过训练，外部参考与提取器仍需要；调高身份强度可影响姿态或编辑灵活性。

**启发**：tuning-free 必须按训练阶段解释，不能据此推出当前零训练观察器已具同样能力。

### E22. PosBridge

[原论文](https://arxiv.org/abs/2508.17302)。

**核心机制**：参考图与目标背景采用 Corner Centered Layout，位置嵌入移植引导主体结构传递；基础与附加 LoRA 版本分开。

**优势／贡献**：位置编码也能帮助身份相关结构传输，不只控制抽象坐标。**局限**：FLUX-Fill、参考对象、分割／填充区域都是前提；布局并未恢复所有三维信息。

**启发**：源—目标关系包含坐标与外观；固定源坐标的观测对无几何编辑更容易解释。

### E23. Appearance Pointers

[原论文](https://arxiv.org/abs/2607.19344)。

**核心机制**：区域对应与聚合网络将文字／图像／mask 编成紧凑 pointer token，指定条件作用到哪里。

**优势／贡献**：直接处理属性归属，避免多个条件只有全局混合。**局限**：网络及 LoRA 需要训练、用户区域显式给定；条件链接错误仍会造成泄漏。

**启发**：语义相关不仅是相关强度，还包含“哪个属性属于哪个实体”的类型关系；当前没有监督时不能假定此类型已知。

### E24. FreeCus

[原论文](https://arxiv.org/abs/2507.15249)。

**核心机制**：pivotal attention sharing、细粒度特征提取和动态 shifting，并借 MLLM 丰富语义；分割区域减少背景干扰。

**优势／贡献**：利用 DiT 原有参考定制能力，减少逐主体学习。**局限**：pivotal 指关键注意力机制／层，不等于一个已知的身份锚点；完整方法含参考、区域与 MLLM。

**启发**：可分析关键层和源信号提取，不在迁移时隐去帮助其成立的额外语义条件。

### E25. TokenVerse

[原论文](https://arxiv.org/abs/2501.12224)。

**核心机制**：在调制空间为描述词学习不同方向／映射，使对象、附件、材质、姿态和光照等概念可以组合。

**优势／贡献**：利用注意力以外的 shift／scale 通道，支持非对象概念。**局限**：逐概念／图像优化需要学习；相似概念或同名标识可混合，不兼容的姿态组合会生成不合理部件。

**启发**：概念分工不能仅靠节点空间位置描述；但当前目标不适合再用未经监督的单一方向承包外观与姿态。

### E26. Mod-Adapter

[原论文](https://arxiv.org/abs/2505.18612)。

**核心机制**：视觉语言交叉注意力和 MoE 预测概念相关文字 token 的调制方向，VLM 引导预训练降低映射学习难度。

**优势／贡献**：把 TokenVerse 类逐概念求解摊销成新概念时的快速推理。**局限**：调制空间对齐并非天然已有，适配器和语义教师需学习；新概念免微调不是全系统无训练。

**启发**：一个准确属性子空间可能需要数据；当前候选选择可证明的光度不变性，承认其范围更窄。

### E27. ResEdit

[作者项目](https://johnberg1.github.io/resedit/)、[正式论文](https://doi.org/10.1111/cgf.70551)。

**核心机制**：额外残差 token 编码主要条件未表达的实例信息，通过梯度反转／对抗约束避免残差重新编码待改条件；有逐图优化和学习式编码器路线。

**优势／贡献**：直接面对“源信息不足”与“强重建阻碍编辑”的冲突，固有属性／光照编辑证据更具体。**局限**：任务骨干和附加学习、逐图成本不可忽略；对抗不保证完全独立，文字编辑证据较初步。

**启发**：应显式建模可放行变化。本候选借鉴其分工思想，以解析成像模型替代部分需要学习的解耦，不能声称同等语义能力。

## 8. Q01—Q09：表征、扰动、寄存器与调制

### Q01. DiTF

[原论文](https://arxiv.org/abs/2505.18584)。

**核心机制**：少数固定通道的巨大激活跨空间共享，利用 AdaLN 相关特征提取和通道处理改善语义对应。

**数学分析**：$h_i=b+s_i,\|b\|\gg\|s_i\|$ 时，$\cos(h_i,h_j)\approx1$，即使 $s_i,s_j$ 所属部件不同。

**优势／贡献**：解释原始 token 余弦为何可能失真，直接改善表征任务。**局限**：特征提取收益不是生成主干删通道无害的证据；同类对应不等于实例身份。

**启发**：本轮关系观测需明确提取点和公共分量，不把未经处理的余弦作为语义真值。

### Q02. HeadHunter

[原论文](https://arxiv.org/abs/2506.10978)。

**核心机制**：分析并控制头级注意力扰动，构造能力较弱的预测作引导；统一可写 $f_{\mathrm{guided}}=f+w(f-f_{\mathrm{weak}})$。

**优势／贡献**：扰动位置和强度具有可操作性，不只统一破坏全部注意力。**局限**：弱分支的差异可能包含非目标因素；额外预测有成本。与编辑方法 HeadRouter 不同。

**启发**：机制干预可帮助校准观测，但“正常减弱模型”的质量方向不自动保持源实例。

### Q03. Token Perturbation Guidance

[原论文](https://arxiv.org/abs/2506.10036)。

**核心机制**：用正交置换 $P$ 改中间 token：$H'=PH$，保留 $\|H\|_F$，破坏空间组合，得到弱预测引导。

**优势／贡献**：不用改变权重或特定无条件训练，就能构造对照。**局限**：范数保留不等于结构保留；完整采样仍需弱分支。原文主体实验是 SD2.1／SDXL，作为邻近前作处理。

**启发**：节点信息量与节点排列都重要，不能只比较分布和范数来判断姿态。

### Q04. STAS

[核验 v2](https://arxiv.org/abs/2603.17825v2)。

**核心机制**：视频 DiT 的首帧／边界 token 在少量通道有大激活，与 VAE 编码不对称和残差更新缩放关联；早期调制这些激活改善质量。

**优势／贡献**：把激活异常追溯到编码器边界条件，干预无需额外完整预测。**局限**：位置层级依赖视频 VAE 和模型；不能推出同一机制解释单图所有漂移。

**启发**：统计相关图里的强节点可能是编码结构产物，先排查机制再赋予对象语义。

### Q05. EMA / Awakening DiTs

[原论文](https://arxiv.org/abs/2607.02968)。

**核心机制**：削弱 MA 维度产生细节不足的反事实预测作 Detail Guidance；MREP 则处理观测特征的共享大方向。

**优势／贡献**：把生成细节作用与表征辨别副作用分开，提供同一信号的两种用途。**局限**：局部引导另有区域选择，弱预测增加成本；改善细节／生成质量不等于保护真实源纹理。

**启发**：不应把“让图更清楚”的观测预处理直接写回生成主干。

### Q06. Registers Matter for Pixel-Space Diffusion Transformers

[原论文](https://arxiv.org/abs/2605.16147)。

**核心机制**：研究显式寄存 token，使用有／无寄存器的预测差进行 Register Guidance，并训练统一支持两分支的模型。

**优势／贡献**：额外全局状态可以组织结构与细节，统一分支比独立模型更对齐。**局限**：收益随像素、latent、RAE 表示不同；寄存器需要模型支持／训练，不是向任意 FLUX 追加几个 token 即可。

**启发**：补充状态有帮助的可能性不等于当前无需监督就能得到语义锚。

### Q07. Text Template Tokens as Implicit Semantic Registers

[原论文](https://arxiv.org/abs/2607.19139)。

**核心机制**：分离提示内容与模板 token，使用注意力分解和定向干预追踪对象语义如何从图像 latent 读回模板位置，并分析头／层功能和剪枝。

**优势／贡献**：输入语义弱的 token 可在中间层承担重要寄存作用，区别相关性与因果消融。**局限**：主要是所测 Qwen 家族；对象类别承诺不等于真实源实例身份。

**启发**：应观测信息在层内的功能，而不是按输入词义预先删除格式 token 或仅按注意力峰值选锚。

### Q08. Guiding Token-Sparse Diffusion Models

[原论文](https://arxiv.org/abs/2601.01608)。

**核心机制**：用不同 token 稀疏程度形成能力差，替代或补充传统条件／无条件差进行引导。

**优势／贡献**：针对稀疏训练模型中 CFG 响应不足，弱分支可低成本。**局限**：模型训练适应稀疏是重要前提；不是任意稠密预训练模型都支持。生成分布质量不能推出源保持。

**启发**：对照分支的能力差必须有明确来源；不能任意破坏 token 后将差值命名为任务方向。

### Q09. Rethinking Global Text Conditioning

[原论文](https://arxiv.org/abs/2602.09268)。

**核心机制**：区分序列文字交互与 pooled CLIP 全局调制，调制引导形如 $m'=m+w[m(p_+)-m(p_-)]$；另有需学习的接口改造。

**优势／贡献**：解释条件不只通过注意力进入图像，调制干预开销可小。**局限**：共享调制同时影响许多位置和因素，可能强化典型构图；去掉 CLIP 的训练设计不能混称免训练。

**启发**：仅约束注意力图仍可漏掉全局调制造成的背景／姿态变化。

## 9. Q10—Q16：位置外推、训练关系与高效架构

### Q10. FiT

[原论文](https://arxiv.org/abs/2402.12376)。

**核心机制**：把图像视为可变长度 token 序列，柔性训练与二维 RoPE，结合外推方法支持不同分辨率／比例。

**优势／贡献**：从训练组织和位置机制降低固定栅格偏置。**局限**：新训练架构本身不可直接归为旧 DiT 的零适配外挂；分辨率正确不表示编辑实例正确。

**启发**：位置关系具有训练分布假设，图尺度和 token 数变化不能被无条件忽略。

### Q11. RIFLEx／UltraViCo／UltraImage 家族

[作者仓库](https://github.com/thu-ml/DiT-Extrapolation)。本条保持原索引家族编号，内部三篇分开解释：

- **[RIFLEx](https://arxiv.org/abs/2502.15894)**：识别影响长度外推的内在 RoPE 频率并降低它，减少视频重复；免训练与进一步微调版本分开。
- **[UltraViCo](https://arxiv.org/abs/2511.20123)**：将重复和质量下降联系到训练窗口外 token 的注意力分散，对窗口外交互作衰减；不只改频率。
- **[UltraImage](https://arxiv.org/abs/2512.04504)**：递归修正主导位置频率周期，并依据注意力熵调整集中程度，兼顾局部细节和全局结构。

**优势／贡献**：频率、位置和注意力归一化共同决定长序列行为。**局限**：外推任务的分散／周期现象不是编辑因果泄漏的统一解释；更集中注意力可能强化错误对应。

**启发**：图关系必须在实际序列尺度和位置编码下解释，不能仅比较固定相似度数值。

### Q12. MDT／MDTv2

[原论文与扩展](https://arxiv.org/abs/2303.14389)。

**核心机制**：训练时隐藏部分 latent token，用非对称结构恢复缺失内容，增强部件间上下文关系；v2 改进结构和训练策略。

**优势／贡献**：关系学习被明确加入生成训练，能够提高学习效率与质量。**局限**：推断缺失内容可能依赖类别典型关系，不保证保留非典型源姿态；训练收益不能搬成推理外挂保证。

**启发**：“关系重要”有训练证据，但推理时固定任意源关系仍需单独证明。

### Q13. MaskDiT

[原论文](https://arxiv.org/abs/2306.09305)。

**核心机制**：只在可见 token 上用大编码器，轻解码器恢复完整 token，并结合去噪／恢复训练。

**优势／贡献**：把高比例训练遮蔽转化为显著计算节省，鼓励上下文理解。**局限**：恢复路径经训练学得；训练加速不等于相同比例推理加速，更不表示无监督精确解耦。

**启发**：信息缺失的恢复是有先验的预测，不是对源事实的无损复制。

### Q14. REPA

[原论文](https://arxiv.org/abs/2410.06940)。

**核心机制**：投影中间噪声特征，对齐外部清晰视觉表征，损失可统一表示为 $\sum_i d(P h_i,z_i^{\mathrm{teacher}})$。

**优势／贡献**：高质量表征帮助扩散／流模型训练，超出单纯去噪监督。**局限**：需要训练和外部教师；更好教师全局语义不保证其局部关系对当前保持因素充分。训练加速数字不能当推理收益。

**启发**：观测与生成学习有联系，但本候选不假装冻结模型已适应新的关系约束。

### Q15. iREPA

[原论文](https://arxiv.org/abs/2512.10794)。

**核心机制**：通过多视觉编码器研究区分全局语义能力与空间 token 结构，并以空间归一化／卷积投影强化关系转移。

**优势／贡献**：对“空间关系为何帮助生成”提供比单一全局分类分数更直接的证据。**局限**：证据属于训练过程，关系准确性和任务兼容仍需定义；其方法不是推理中把源 Gram 固定即可。

**启发**：新观测确应读取空间信息，但必须证明新增信息而非旧全局代理的另一种写法。

### Q16. SANA

[原论文](https://arxiv.org/abs/2410.10629)。

**核心机制**：深压缩 AE 减少 token，线性注意力降低交互成本，结合文本编码和采样／训练设计。

**优势／贡献**：从 token 数和每 token 交互两个方向构造高效生成系统。**局限**：是新训练体系，整体吞吐同时包含多项变化；高压缩也可能损失实例细节。

**启发**：更短表示不必然更适合编辑保持，需在同一源信息可辨识度下讨论效率。

## 10. Q17—Q21：空间锚、罕见语义、上下文与嵌入优化

### Q17. FreeText

[原论文](https://arxiv.org/abs/2601.00535)。

**核心机制**：用目标词和 sink-like token 的图像到文字注意力定位文字区域，拓扑细化后注入噪声／频率对齐的字形 latent。

**优势／贡献**：把“写在哪里”和“写什么”分开，锚点有直接空间用途。**局限**：内部 mask 与显式字形先验是条件；sink 的稳定性不代表对所有对象都有正确定位。

**启发**：有类型的锚比抽象重要性更容易解释，但不能将文字空间锚升级为通用身份保持锚。

### Q18. Rare Text Semantics

[原论文](https://arxiv.org/abs/2510.03886)。

**核心机制**：在联合注意力前扩大文字 token 表示方差，使罕见条件在特征空间更容易被区分和读取。

**优势／贡献**：无需重新训练即可增强目标语义，包含编辑应用。**局限**：方差缩放改变了所有相关路由，可能加强不想要的伴随因素；罕见语义表达与源保持不是同一目标。

**启发**：任务通道可能需要增强，但不能用其更强响应当作姿态漂移已解决的依据。

### Q19. Contextual-Space Repulsion

[原论文](https://arxiv.org/abs/2603.28762)。

**核心机制**：在文字条件已吸收图像结构、布局尚未完全承诺的层间上下文空间施加排斥，提高输出多样性。

**优势／贡献**：干预发生在有结构反馈的条件表示中，而非只扰动初始输入或已固定布局。**局限**：多样性可以合理地改变姿态、背景和构图，与当前保持目标可能相反。

**启发**：语义与图像信息在层间循环流动，所谓“文字节点”不再只代表原始文本。

### Q20. RaTE / MapReduce LoRA

[原论文](https://arxiv.org/abs/2511.20629)。

**核心机制**：学习奖励专用 token embedding，推理组合偏好；整套框架还包括奖励专用 LoRA 的迭代训练／合并。

**优势／贡献**：以不同条件嵌入表达多目标偏好，缓解单奖励优化的冲突。**局限**：奖励仍是代理，组合可有相互影响；不能把整套方法的指标提升都归于 RaTE token，更不能归于零训练处理。

**启发**：保持和目标是不同评价维度，优化其中一个不能掩盖另一个退化。

### Q21. Your Pre-trained Diffusion Model Secretly Knows Restoration

[原论文](https://arxiv.org/abs/2604.04924)。

**核心机制**：直接学习文本编码器输出空间的连续 prompt，用扩散桥对齐训练／推理的恢复轨迹；骨干冻结。

**优势／贡献**：区分自然语言、输入词嵌入与输出连续条件的可达集合，并处理状态分布不匹配。**局限**：仍学习 prompt，恢复任务有配对目标；不能当作无目标真值的语义编辑保持解法。

**启发**：改变观测或控制接口确实可能增加可达能力，但增加能力与辨识正确任务仍是两步。

## 11. 对本研究真正可转移的六项贡献

| 已有贡献 | 可以借鉴 | 不能无条件借用 |
|---|---|---|
| 重要性、次模覆盖、动态刷新 | 选择互补且不过时的观测 | 自动得到身份／姿态锚 |
| 轨迹代理与速度提升 | 表达过程关系、检查动态误差 | 精确预测原场等于语义纠错 |
| Q/K/V 与位置干预 | 分析路由、内容和坐标的不同入口 | 普遍结构／外观解耦 |
| 源条件与直接回填 | 实例信息必须有源参照 | 无内部区域信息也能准确冻结 |
| 表征、寄存器与大通道分析 | 校正相关性观测中的机制伪影 | 删除生成维度必然有利 |
| 残差 token 与调制分工 | 对允许变化和源身份分开建模 | 无学习／无额外信息自动复现其能力 |

**综合结论**：82 条文献没有提供一个现成的“相关性分数即可逐步纠正所有无关编辑”的答案。它们共同支持更具体的研究路线：先使保持观测具备可检验的不变性与辨识性，再把它放入已有受约束修正工具；过程关系和锚点用于补足信息与降低成本，不替代语义定义。
