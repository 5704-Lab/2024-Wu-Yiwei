# 条件响应数值修订与机制先导实验设计

日期：2026-10-06。理论依据：[尺度分离与校正稳定性](条件响应数值修订_尺度分离与校正稳定性_2026-10-06.md)。这是新协议，不回写旧审查的失败状态。

## A. 修订计算审查 R1

### 样例与目的

固定上一轮全部 13 个失败状态，加上按 pair/seed/step 排序的首 13 个双分支均通过状态作为数值控制，共 26 状态、52 FP32 分支。这里按旧数值结果选择诊断样例，因此不是独立验证集，不用其通过率估计全体数据可用率。

原定的三个高精度异常状态均检查源/目标两个分支，共 6 FP64 分支；FP64 使用新 FP32 已保存的相同输出探针，隔离 Jacobian 精度影响。

### 固定实现

batch=1，数学 SDPA，统一正/负条件速度函数。探针及 VJP 输出依次除以共同标量范数，再计算 JVP；保存尺度，使用归一化响应构造投影。源/目标分别对自己的 sequence/pooled 元组求导。M=I、alpha=0.3、rho=1、lambda_s=lambda_u=1、半径 0.1||Delta_0||。

### 新指标及预设门槛

| 指标 | 门槛 |
|---|---:|
| 范数尺度 VJP/JVP 对偶残差 | 1e-6 |
| 正能量恒等式的范数尺度残差 | 1e-6，且实际投影非负 |
| 同接口生成速度与求导前向值相对差 | 1e-7 |
| FP32/FP64 有符号响应余弦 | 至少 0.999 |
| 固定 FP32 半空间的 QP 位移差/半径 | 至多 0.05 |
| 半空间也改用 FP64 的 QP 位移差/半径 | 至多 0.05 |
| QP KKT、舍入后可行性/源距离残差 | 1e-7 |

旧标量对偶残差原单位恢复后继续保存。新门槛在本次运行前冻结，是针对数值问题的新操作性决策；不能将它用来修改旧结果。弱/非有限响应、执行失败、恢复和重试都记录。通过后只允许进入小规模机制先导，不称完成了完整质量门槛。

## B. 机制先导：正负位移能否预测后续变化

### 固定范围

按机制 manifest 首次出现的源图组顺序选择前四个组，每组固定首个目标：bear_grass、boat_silhouette、cat、cat_ginger。种子 0；分辨率 512；T=50、n_max=33、n_min=0、n_avg=1；源/目标 CFG 为 3.5/13.5。只检查中噪声步 33，t 约 0.594801。不是完整阶段 2 的全部时间位置和种子。

校正实验前冻结剩余噪声；所有干预都用统一速度接口继续原 FlowEdit 数学更新式，后续不再校正。每个源图的源分支不依赖编辑状态，可在同一步精确复用，所有目标分支保持 batch=1。

### 候选与方向

基础候选为本步 z_E。五个归一化方向：共同条件对比 a、各自条件目标响应 r_a、源响应 r_s、各向同性 QP 解、固定种子的秩一随机方向。每个有效方向执行正/负同幅位移，幅值为 0.1||Delta_0||。

响应缺失和 QP 解为零记缺失方向，不以随机方向补齐。同一次计算保留实际 FP32 位移，全部样例和不利结果保留。

每图产生五对终点与一个无干预统一接口终点，共 44 个主要终点；另执行官方 batch=4 的相同配置和噪声基线，共 4 个参考终点，单独报告接口变更造成的结果差异。另保存源图 VAE 重构作为查看参照。

### 预测与评价

对每个正/负方向分别记录：一阶工作量 a(q_E)^T d、沿 d 的两个中点查询所给出的有限工作量。用正工作量减负工作量预测正/负终点的排序。有限求积不是精确密度积分，不能称为证书。

独立评价器固定为 Google SigLIP2 base patch16 256，模型及处理器版本保存 SHA；权重冻结，不提供给生成或求导函数。使用归一化图文余弦，报告目标绝对分数与目标减源的偏好分数。对 +/- 终点及对统一基线都报告变化。

预测点积/有限工作量按与相应向量范数乘积的比值，小于 1e-5 记预测不可判定；终点分数绝对差不超过 1e-5 记终点不可判定。保留所有原始值，报告覆盖率和两类分数，不能只挑相对偏好的改善。

### 分析限制与决策

四源图组只做可行性与描述性核对；二十方向记录不视为二十独立样本。报告各源图、各方向符号对应及 Spearman 排序，不凭小样本相关性宣布真实编辑成功。人工可查看全部图像；第二评价器和更大分组复核在正式阶段 2 才执行。

若内部响应与独立评价没有一致优势，不放大权重，也不启动全面质量实验；先检查响应探针与任务是否对齐。若统一接口基线与官方基线差异较大，先报告该混杂并进行接口基线复核。

## C. R1 失败后登记的 R2 与机制入口修订

R1 的正能量恒等式在三个状态、四个分支超阈值，R1 判定保持未通过。新增 R2 协议位于 `experiments/stage1_adaptive/protocol.json`：三个状态完整局部步骤提升至 FP64，其余 23 个通过状态复用原记录；原数值门槛不放宽。R2 还要求原六个 FP64 配对参考通过。

机制先导的新入口是 R2 通过，不是 R1 通过；生成前已冻结该入口。四图先导的整个检查点、局部方向和一阶/有限工作量都使用 FP64，候选及干预潜变量提交为 FP32，之后统一 FP32 续推。实际正负位移是提交后的 FP32 潜变量差，预测在实际共同候选点计算。共同基线也经过相同 FP64 检查点，减少精度布局对因果比较的混杂。

R1 曾有一次并发读取未写完 `.pt` 的执行错误。该错误保留，通过完成标记同步和临时文件原子重命名修复，重试只补缺失参考；不算作数学门槛失败，也没有删除其日志。
