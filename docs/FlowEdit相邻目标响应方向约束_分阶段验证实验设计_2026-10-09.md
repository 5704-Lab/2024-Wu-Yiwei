## 2. 核心假设

| 编号 | 待验证命题 | 不能据此宣称 |
|---|---|---|
| H1 | 混合二阶向量积正确且数值可分辨 | 目标语义正确 |
| H2 | 回映方向能预测并改善实际归一化响应方向 | 源内容必然保持 |
| H3 | 在干净状态、固定辅助时间下，同探针重评比不同探针历史缓存更少受探针变化混杂 | 上一参考方向就是正确语义 |
| H4 | 同预算下，方向修正优于纯缩步或随机扰动 | 任意方向平滑均有效 |
| H5 | 最终编辑不劣化任务完成，同时减少不必要变化 | 有准确非编辑区域真值 |
| H6 | 同总推理成本下存在收益 | 只凭较少采样步数就获得加速 |

按顺序推进。H1 不通过不跑全图；H2 不通过不扩大质量实验；H5 不成立不做减步宣称。

## 3. 固定算法与配置

首轮使用：

1. 原 FlowEdit 预测步；
2. 在固定清晰端 tau_ref=0 下，直接输入上一干净状态 y_k 与当前干净候选 bar y_k+1；
3. 固定目标文本、实际编码坐标、引导参数、归一化输出探针；
4. 在干净状态上计算 b=C_y^T P_u u_ref/||G||；
5. 候选 p 沿 b，范数不超过 R=beta ||d||；
6. 按完整损失 Armijo 条件验收，最多试原候选与一半位移；
7. 更新 y，再正式重构 q；下一步速度重新计算。

梯度范数退化、混合二阶计算失败、候选失败均登记，不丢弃相关源图。

先限定 n_min=0 配对编辑。原始 FlowEdit 与新方法采用相同模型、图像预处理、VAE、时间表、n_avg、n_max、源/目标引导及噪声序列。主基线保留官方实现，单样本数值接口作为另一个控制，不能把其差异归因校正。

首轮原 CFG 参数保持原实验配置，不同时配平 CFG、改提示词或改查询构造。那些调整需要独立消融。

初始工程设置（待独立开发预检冻结，非已验证最优值）：

- 角度启用阈值 15 度；
- beta=0.05；
- Armijo 系数 c=0.1；
- 候选为 p=b/lambda 后满足位移预算；
- active 且 b、R 非退化时，lambda=gamma ||b||/R，初始 gamma=1；
- 只检查比例 1 与 1/2；
- 所有主响应都在 tau_ref=0 求取，先通过端点接口门槛；通过后是否在最后一次编辑更新启用校正按统一登记策略执行，不因生成时间恰为零而换响应定义。

lambda 在该次问题中冻结，不能对其构造过程再求导。候选、完整损失和验收使用同一个 lambda。

数字仅是预登记起点。开发阶段一因素比较 beta={0.02,0.05,0.1}、阈值={5,15,30} 度、gamma={1,4}；围绕初始配置最多六个不同配置，不做全网格。数值容差由阶段 1 独立确定，不能为了让候选通过而放宽。

## 4. 阶段 0：解析数学与闭环验证

### 4.1 解析对象

使用已知函数而不是从代码结果构造真值：

1. phi(y,xi)=xi^T(By+c)，G=By+c，C_y=B；
2. G(y)=(cos y,sin y)，验证旋转例子；
3. G(y)=ell(y)e_1，方向不变但范数变，验证 A_y=0；
4. 非满秩 B、期望方向不可达；
5. 正平行与反平行参考；
6. 梯度零点附近、R=0、b=0；
7. 带固定 padding 的 P，验证 g_xi=P^T g_e；
8. 已知 Lipschitz 常数的非线性例子，验证有限步条件。

通过 closed-form / 高精度独立求解验证：

- 归一化微分 A；
- b 等于实际 F 对状态的梯度；
- 无约束解、预算内解和 KKT 边界解；
- 简单缩放通常不是预算问题精确解；
- 正则损失下降与仅余弦增加的差别；
- 接近反平行时的停滞；
- w/h 的符号及 q 同步；
- 采用 O(h^2) 修正在稳定解析场上的收敛趋势。

### 4.2 门槛

FP64 非退化解析例子，独立公式与自动微分的归一化误差目标 <=1e-9；KKT 残差 <=1e-8。零/退化例子正确跳过而不是除零。解析有限步必须按实际 J 验收。

这验证具体回映、预算和积分性质，不仅验证线性求解器。

## 5. 阶段 1：真实 SD3 混合二阶计算与资源预检

### 5.1 最小队列

开发组四个源图，每图固定一个编辑，原 FlowEdit 两个有效检查时间附近取状态：约 t=0.6 和 t=0.12，共八个点。选择通过源 SHA 去重，具体 pair_id、时间索引和噪声哈希在执行前保存。

先完成一个点的可用性和显存/耗时测量，再跑其余点，不直接启动大队列。此阶段生成原始基线状态，不做完整修正编辑。

### 5.2 必须检查

1. 一阶目标 VJP 的实际编码接口、padding、pooled 与序列尺度；
2. 二阶图保留：g 不 detach，a、u_ref、zeta 冻结；
3. Cw 与 C^T zeta 的对偶性；
4. C 对状态向量的线性组合一致性；
5. b 与直接微分 F 的梯度一致；
6. 归一化方向导数满足 u^T A d 约为零；
7. 状态方向上的独立局部响应检查；
8. 固定同一参考/候选时重复计算的角度噪声；
9. FP32 与局部完整 FP64 对照，不能只将点积换成 FP64；
10. attention 后端的二阶支持、显存峰值和每类调用耗时。

独立数值检查可以对干净潜变量 y 的小位移使用多尺度差分；这不对文本嵌入做 e+eta h 扰动，模型文本梯度始终通过自动微分获得。没有稳定尺度平台时保留失败，不择取单个有利扰动。

真实对偶、线性及直接梯度检查初始门槛为尺度归一化残差 <=1e-5；FP64 定点目标 <=1e-7。门槛属于工程登记，非普遍理论。近零分母另报绝对误差并标为不可辨认，不用比值制造通过。主版本扰动变量是干净 y，辅助时间固定 tau_ref=0；生成轨迹取样时间不作为响应模型时间。

新增首要门槛：清晰端 v(y,0) 与 G(y) 的接口支持、有限性、非退化、二阶支持和精度。它们成立才能进行回映验证；仅“端点可求导”不证明端点响应具有正确语义。

若 FP32 未通过而 FP64 通过，允许局部 FP64 分支，但实际部署候选必须回到正式状态精度重新验收，并记录成本。BF16/FP16 不默认可用于此二阶控制。

### 5.3 通过条件

八点都给出完整状态和通过/失败分类；每个拟用于校正的点必须通过自己的数值门槛。计算后端不支持、显存超限或误差不可分辨时停止扩大，分析原因。不能用通过点的平均值替代失败点。

资源预检需给出一次校正的实际秒数与显存，推算下一阶段最大成本。没有数据前不承诺总 GPU 小时。

## 6. 阶段 2：局部回映与有限方向改进

### 6.1 队列

从 development 选择八个源 SHA，每图一个固定编辑，含动物属性、对象替换、文字、风格或材质等类别；固定两个 seed、四个有效时间档，共最多 64 个状态。图像内容分类只用于覆盖，不构成空间掩码。

四个检查时间采用原时间表最接近 t=0.77、0.60、0.30、0.12 的索引，登记实际 t。只从原始 FlowEdit 状态抽取局部候选，不把一次局部修正后再继续生成混入这一阶段。

### 6.2 同状态控制

| 分支 | 用途 |
|---|---|
| 原始候选 w=0 | 确定原偏转 |
| 简单回映 b 方向 | 最低求解开销的主候选 |
| 同范数随机潜变量方向 | 排除任意扰动效应 |
| 同范数沿 -d 回退 | 排除仅撤销原始编辑的效应 |
| 缓存历史响应参考 | 测量变化探针造成的混杂；固定探针版本单列 |
| Gauss–Newton/KKT | 只在简单回映成立后测试额外求解价值 |

随机向量使用独立 RNG，不影响生成噪声。参考重评与缓存分支必须在相同状态比较。

### 6.3 观测量

- 原始 theta、校正后 theta 和 cos 增量；
- 一阶预测 b^T w、实际 F 增量及完整 J 增量；
- 实际梯度范数比、零/反平行/不可控状态；
- ||w||/||d|| 和有效速度控制比例；
- 两次候选的分别接受率、拒绝原因；
- 硬角度达成率与软目标下降率分开；
- 正式状态舍入后 y 上的响应，以及单独的 q 同步残差；
- 对每个源图等权的汇总，以及每个点明细；
- 总耗时与各自动微分调用次数。

主要门槛：非退化主动状态中，一阶正方向能在登记有限候选中产生可分辨的真实 J 下降；效果应显著优于随机方向，且不能仅由回退原始步长解释。

若主动状态太少，报告“未形成足够校正样本”，不把无需修正的状态计作成功。若局部方向普遍不可控、数值开销不可承受或只回退有效，不进入全图扩大。

开发阶段冻结参数、数值容差及选取规则；不能依据 mechanism 或 heldout 结果回调。

## 7. 阶段 3：完整编辑机制先导

### 7.1 数据与运行

mechanism 的 16 源 SHA，每图选一个编辑，两个固定 seed，共 32 次源图-编辑-随机输入组合。选择规则以源 SHA 分组后按登记哈希排序选一个 pair，不在看到效果后换目标。

主比较：

1. 官方原始 FlowEdit；
2. 同数值接口、相同预取噪声但 w=0；
3. 同接口加方向回映校正；
4. 同位移预算的原始编辑缩步控制；
5. 缓存历史参考（小队列机制消融）。

先稀疏检查四个时间档，再讨论每步执行；每步版本只有在实际成本与机制收益支持后运行。稀疏校正仍用相邻原始预测状态作参考，不能偷偷改为上一次校正时间的状态。

原始采样配置从既有 FlowEdit 配置读取并登记，不自行改 n_max、CFG 或图像尺寸来使新方法有利。因数值接口变化产生的基线差异独立报告。

### 7.2 独立质量评价

评价器不参与校正：

- 人工盲评：目标要求是否完成；额外变化是否增加；伪影是否出现；
- 源实例事实：姿势、构图、对象身份、环境亮度等，只评价任务明确要求保持的事实；
- 固定外部图像语义评价器作为辅助指标，不是准确 oracle；
- 全图 LPIPS/DINO 等距离仅作为描述，不能称为非编辑区域一致性；
- 所有图均单列源图和原始 FlowEdit，避免只展示代理最优案例。

棕熊到黑熊是动物属性实例，但“种类更换”与“仅颜色更换”可能含不同外形要求。标注时根据原始文本登记允许变化，不能将所有外形变化都判为错误。

人工任务完成可采用完成/部分完成/未完成及额外变化等级；报告评审人数、分歧与原始计数，称为“盲评任务完成率”，不称为真实语义 oracle 成功率。

### 7.3 方向检查的自证偏差

校正减少方向偏移是算法直接优化的结果，不能单独作为质量证据。关键问题是方向改善与独立目标完成、源保持、伪影之间是否有正关联。

如果角度改善但编辑明显减弱，判为机制代理与任务不匹配；不要继续通过调大目标 CFG 掩盖这一结果。

## 8. 阶段 4：留出评价与公平成本

仅阶段 3 不显示明显任务损害且具备收益迹象后启动。

heldout 按 37 源 SHA 分组，每图一个冻结选取编辑、两个 seed，共 74 组合。源图与参数选择隔离；若历史已使用该集合选择过当前机制，应明确降级为复核或另取独立集。

确认性主比较为原始 FlowEdit、同接口无校正、方向校正、缩步控制。用源图级配对汇总，seed 和同图重复是组内观测。置信区间按源图重采样；不把时间点或 seed 数当样本量。主要终点与评价规则在运行前冻结。

成功判定需同时具备：

1. 任务完成没有超过预登记容忍幅度的下降；
2. 额外变化/伪影至少一个明确维度改善，且不是简单退回源图；
3. 原始 FlowEdit 强基线与同接口控制都完整保留；
4. 所有失败、跳过、不可分辨点计入运行覆盖。

不预设非劣效界一定为 5 个百分点等任意数字；根据开发数据的评审可靠性、预期效果与所需样本量在留出执行前登记。37 源图不自动提供足够功效；证据不足时报告不确定。

效率需报告采样前向、梯度前向、VJP、混合二阶反传、线性求解、候选重算、精度转换、VAE 与评价等开销。预热后报告中位耗时、尾部耗时、峰值显存；质量评价器不在编辑推理内，应与推理成本分开。

只有同总耗时或同总模型工作量预算仍有质量优势，才研究减少采样步数。不能把二阶反传算作零 NFE。

## 9. 后续消融与跨模型

主机制成立后按具体风险展开：

- 单步回映与 Gauss–Newton/KKT：解的准确性是否抵偿求解成本；
- 同探针重评与历史缓存：状态影响还是探针变化；固定辅助时间不随生成时间变化；
- 干净 y 固定清晰端响应与旧 q 噪声响应：输入噪声和端点接口是否影响回映稳定性；旧版本仅为对照；
- 方向损失与未归一化梯度损失：效果是否来自幅度控制；
- 完整损失验收与仅余弦验收：正则预算是否有效；
- 稀疏与每步控制：成本收益；
- 高/中/低噪声单独启用：不预设高噪声更强；
- O(h) 与 O(h^2) 位移预算：受控编辑与积分误差修订的差异；
- FLUX.1-dev：重新预检编码、打包、二阶算子及 guidance，不直接移植 SD3 门槛。

不把全部消融一次性展开。出现具体剩余风险才增加对应实验。
