# 原生配对关系观测：理论推导与 FlowEdit 联合约束设计

日期：2026-10-30。依据[56 篇逐篇调研](原生配对观测专题_56篇相关工作逐篇内容思想与实现_2026-10-30.md)，承接[用户明确的当前目标](任务相对语义相关性_类别形态许可与源关系保持_方向修订_2026-10-28.md)和[上一轮失败／局部收益证据](当前干净状态联合语义约束_候选观测与反馈修复实验_2026-10-28.md)。

本报告提出研究设计，**不宣称已获得通用自由文本语义解析、可靠姿态观测或真实编辑收益**。文献事实通过编号及原始链接标注；以下共同形式、命题、反例和组合控制器为本项目的推导，部分线性控制代数沿用既有研究，并非全部原创算法。

后续已完成[视觉伺服、最小约束与有限步恢复的深度推导](原生语义观测闭环_视觉伺服最小约束与有限步恢复_深度理论_2026-10-30.md)及[具体实现协议](原生语义观测闭环_具体实现方案与接口协议_2026-10-30.md)。该后续修订本文第 7 节的控制目标：固定每步的 $\|r+Jd\|$ 近端惩罚不自动具有步宽一致性；首版实现改为固定合法容差、按 $e^{-\eta h}$ 收缩越界部分，并在原提议已合格时采用零反馈。本文保留为历史设计，不将旧公式直接视为新的有限步保证。

## 1. 目标与需要改变的建模对象

设源图为 $I_x$，固定源潜变量 $x_0=E(I_x)$，实际干净编辑状态为 $y_k$，当前图为 $I_k=D(y_k)$；$T_s,T_a$ 为源／目标文本，$d_{0,k}$ 为原 FlowEdit 的实际有符号增量。

本次目标是：允许类别转换所需的毛色、耳形、吻形等变化，同时保留未请求改变的源实例朝向、姿态、动作、对象角色和场景关系；发现当前已出现错误时，能够修复而不退回旧类别。

严格区分三个轴：编辑步 $k$、标准加噪探测时刻 $\tau$、网络层 $\ell$。FlowEdit 的编辑查询与以下探测查询也不相同。自动方法不使用真实目标图／区域／姿态真值，不新增训练、LLM、反演或编辑区域掩码。

**本次具体改变：** 从“把文本差或小幅速度响应从一个图像距离中消掉”，改为“在同一观测条件下，利用原生语义查询绑定当前／源的对象与部件，保留其内容和位置响应，直接观测关系偏差”。必要变化不再由一个未经检验的文本线性子空间代表。

## 2. 原生观测的精确定义

### 2.1 共同条件与查询

对每个固定探测配置 $a=(c,\tau,\epsilon,\ell)$，令

$$q_\tau(z;\epsilon)=(1-\tau)z+\tau\epsilon,\qquad
q_x=q_\tau(x_0;\epsilon),\quad q_y=q_\tau(y_k;\epsilon).$$

同一对比较必须使用相同文本序列、池化文本条件、噪声、时刻、图像尺寸和位置编码定义。源与当前分别使用不同条件文本再直接相减，会把文本差异混入图像差异。

先设置共同中性／任务对象提示作为主观测，再单独比较共同源提示、共同目标提示与空提示；每个分支内部仍严格配对。文本不同的分支不逐 token 对齐，只比较各自形成的源相对量。

给定原生联合注意力

$$Q=[Q_I;Q_T],\quad K=[K_I;K_T],\quad V=[V_I;V_T],
\quad O=\operatorname{softmax}(QK^T/\sqrt{d_h})V,$$

同时区分：投影前 $O_I,O_T$；投影后的模块输出；经 gate 加入残差的实际更新；整个 block 后的残差 $H_I,H_T$。它们的尺度与信息不同，不统一命名为 attention output。

文献 02、03、11、13、18、28、29 分别提示输出空间、文本侧交互、投影贡献、AdaLN 位置和 Q/V／QK 的作用。[ConceptAttention](https://arxiv.org/abs/2502.04320)、[Fuse2Match](https://proceedings.neurips.cc/paper_files/paper/2025/hash/159511050630689045bf5593e74b13cc-Abstract-Conference.html)、[DiffTrack](https://arxiv.org/abs/2506.17220)的评价任务不同，不能把其中一种 facet 宣布为普遍最优。

### 2.2 三个主通道与必要对照

$$\Psi_a(z)=\{O_{I,a}(z),\ C_a(z),\ B_a(z)\},$$

其中 $C$ 指文本侧注意力输出，$B$ 指只读概念旁路。Q/K/V、调制后特征与旧 block 残差仅作选择／归因对照，避免把观测位置选择错误当成整个模型无信息。

不直接拼接全部通道求一个总距离。先分别检验哪些通道能测对象绑定、目标类别、局部方向或背景关系，再定义有语义类型的观测。C 若主要反映颜色／风格，就不强行承担姿态保护；O 若不能跨形态对应，也不因其分辨率高就认为可靠。[FLUX.2 绑定实验](https://arxiv.org/abs/2605.24624)是此项分工的直接依据。

### 2.3 共同随机数究竟保证什么

定义配对残差

$$R_a(z,x_0)=\psi(q_\tau(z;\epsilon),c)-\psi(q_\tau(x_0;\epsilon),c).$$

确定性推理且两个输入相同，严格有 $R_a(x_0,x_0)=0$。对 $z=x_0+\delta$，光滑时

$$R_a(x_0+\delta,x_0)
=(1-\tau)J_\psi(q_x,c)\delta+O(\|\delta\|^2).$$

共同噪声移除了恒等输入时由两次不同随机采样产生的假差异。若 $U,V$ 分别为两侧观测，则

$$\operatorname{Var}(U-V)=\operatorname{Var}(U)+\operatorname{Var}(V)-2\operatorname{Cov}(U,V).$$

只有相关性为正时才一般降低差值方差，不能声称任何非线性网络、任何图对都必然降方差。高 $\tau$ 还会减弱实际状态的输入差异；强行除以 $1-\tau$ 会放大噪声和非线性误差。

特别地，$\tau=1$ 时两侧输入恒为同一个 $\epsilon$，任意图对的配对残差都为零。这是图像信息被移除，不是语义被保持。共享噪声还可能制造虚假的空间对应，因此应另设独立噪声与噪声空间置换诊断，检查匹配是否主要跟随噪声纹理；实际方法仍以共同噪声作受控差分。

原 Diffusion Classifier 的配对差分提供方法依据，但不能证明此处所有观测都降方差。[原文](https://arxiv.org/abs/2303.16203) 实验应固定优化用噪声，并用未参与优化的噪声验收，防止只修复某组探测种子的伪残差。

## 3. 为什么只读语义向量仍不足以保护姿态

### 3.1 置换反例

设一个概念 query 为 $b$，只汇聚当前图像 K/V：

$$h(b;K_I,V_I)=\operatorname{softmax}(bK_I^T/\sqrt{d_h})V_I.$$

令 $P$ 为图像 token 置换矩阵，$K'_I=PK_I,V'_I=PV_I$，则

$$\operatorname{softmax}(b(K'_I)^T)V'_I
=\operatorname{softmax}(bK_I^TP^T)PV_I
=\operatorname{softmax}(bK_I^T)V_I.$$

因此，在未显式使用坐标的此种汇聚中，交换部件空间位置也可能不改变向量。实际 SD3 的位置编码会破坏部分精确对称性，但该构造足以否定“概念输出相似就保证几何相似”的一般命题。

DiffSim 的跨图 attention 可对齐变化后的对象；如果只看对齐后的输出，也可能把要纠正的转头当成可接受对应。[DiffSim](https://arxiv.org/abs/2412.14580) 应作为内容／对应基线，不能单独作为保持损失。

### 3.2 把路由造成的位置变化保留下来

对只读查询 $j$，记录对图像 token 的权重，条件归一化为 $\pi_j(p)$；同时记录其对图像部分的总注意力质量 $\alpha_j$。令固定图像坐标为 $r_p$，记录

$$\mu_j=\sum_p\pi_j(p)r_p,\qquad
\Sigma_j=\sum_p\pi_j(p)(r_p-\mu_j)(r_p-\mu_j)^T,$$

$$h_j=\sum_p\pi_j(p)V_I(p).$$

**$\alpha_j$ 不能丢弃：** 若查询实际几乎不读图像，强制将微弱权重归一化成一个尖锐空间分布，会制造虚假的可靠部件定位。

这些是完整空间上的测量权重，不阈值化为区域、不乘速度、不冻结任何空间块。使用正常注意力计算观测，与使用编辑区域掩码控制更新，是不同操作。

仅有质心／协方差仍有保持矩而改变形状的反例，故它们不能完整表示三维朝向。要保留完整响应分布、部件间关系、多层证据和不可见／缺失状态，并单独检验正转、背转、遮挡与视角变化。

## 4. 可实现的只读源锚定关系观测

### 4.1 查询的来源与不反馈条件

按 ConceptAttention 的原权重旁路执行，初始查询来自现有文本编码器，不优化新 embedding，不新增 Q-Former／SAE。原图像及提示分支保持原始运算，不读取新增概念。概念之间的 self-attention 及概念读取图像由旁路独立计算。[原方法](https://arxiv.org/abs/2502.04320)

第一阶段明确给定可核验词组库：任务对象及候选部件，如头、吻、眼、躯干、四肢、场景对象，另有方向／关系的成对假设。词组库是实验协议，不是声称已实现任意文本解析。多 token 查询须记录原始 token 聚合方式，不能把任意短语平均后当成训练过的关系读出。

比较两个旁路：共同初始文本查询随各自图像更新的动态 B；以源图 B 在某层形成的 query 冻结，读取当前 K/V 的源锚定查询。后者可减少当前错误自我改变测量依据，但源 query 也可能偏好旧类别，必须检验合法形态覆盖。不能先验认为冻结源 query 总是更好。

### 4.2 内容、对应和位置共同形成测量

先以相同概念、源部件描述子与双向对应检查确定节点绑定，再分别记录：

- 内容与任务证据：$h_j$、原生 O/B 的概念对比分数、条件兼容证据。
- 空间测量：$\mu_j,\Sigma_j$、完整响应分布、源→当前的对应坐标和位移。
- 关系测量：部件方向、对象相对位置、实例角色与可见性变化。
- 测量状态：$\alpha_j$、多噪声稳定性、双向一致性及候选绑定之间的歧义。

不以低熵或最大匹配差本身充当正确概率；DiffTrack 已指出高信心而低准确的对应可能发生。[原文](https://arxiv.org/abs/2506.17220)

$\alpha_j$ 只检验图像支撑的一部分，也不能保证语义正确。应另设仅作用于旁路的图像 value 清零／错配诊断，检查读出在失去图像内容后是否仍机械重复查询词；原生成分支不参与这些扰动。

重复对象需要保留源位置与实例关系锚，不能仅按“熊”语义最近邻合并成一个节点。若无法分开两只动物，应报告该关系不可辨识，不把二者平均后当保持成功。

### 4.3 用有物理含义的关系容许部分形态变化

例如，以可靠的吻部和头部定位得到

$$u_{nh}(z)=\frac{\mu_{nose}(z)-\mu_{head}(z)}
{\|\mu_{nose}(z)-\mu_{head}(z)\|+\varepsilon}.$$

若局部合法形态只把上述向量乘以正数 $a$，理想无正则归一化下方向不变，故此量比冻结吻长更能允许必要形态。对象间位移可按固定源身体尺度归一化，以减少源间大小差异。

这是有条件的二维关系，不是三维朝向估计定理。遮挡、透视、真正类别形态与查询中心漂移都可能改变该量；眼部次序、头—躯干方向与原生分布证据应共同检验。分母接近零时该方向不可用，不能产生过大的控制梯度。

背景优先保持场景语义、对象角色与布局关系，不把合法对象形变造成的必要遮挡差异当成整片背景错误。

### 4.4 源锚点与标定方式

固定源测量 $F_j(x_0)$，定义

$$r_j(y_k)=\frac{F_j(y_k)-F_j(x_0)}{s_j(x_0)}.$$

$s_j$ 可结合固定源尺度与共同探测的噪声尺度；不能随当前漂移扩大。噪声／光度标定不涵盖类别形态，故合法形态容差还需在开发集锁定、跨新源检验。离线已知合法图只作诊断，不在自动推理中提供每个源的正确终点。

源图 RGB 参照和 VAE 重建源要统一定义，单独量化重建偏差。前述内部源观测始终基于 $x_0$。

## 5. 文本如何决定任务，而不把模型偏好当成许可

### 5.1 任务完成证据与保持证据分开

先研究

$$s_E(y;I_x,T_s,T_a),\qquad r_K(y;x_0,T_s,T_a),$$

前者测目标完成程度，后者只包含本任务中有依据的源关系。$s_E$ 不能只测毛色，也不能只用相对源分数上涨而忽略绝对目标相容性。

在限定的类别／颜色／姿态三类任务中，组合全请求图文证据、原生查询的对象绑定，以及“完整形态／仅颜色”“正确对象／错误对象”等困难负例。已有 SigLIP2 只作为一个通道；原生 B 若无法分清完整形态与改色，就不能把其分数写成可靠类别完成。

一个可直接计算、但需验证的原生概念候选为：在共同的投影前 attention output 空间中，令 $o_p$ 为图像向量，$b_j$ 为概念旁路向量，$\rho_o(p)$ 为源实例锚定的当前空间响应，定义

$$\ell_{j\mid o}(y)=\beta\log\sum_p\rho_o(p)\exp\!\left(\frac{\cos(o_p(y),b_j(y))}{\beta}\right).$$

它在保持完整空间支撑的情况下，将概念证据绑定到同一源实例；$\rho_o$ 只参与测量，不作为更新 mask。对同一对象比较目标／源概念和完整形态／仅改色假设，避免由另一只动物贡献目标证据。动态 $b_j$ 仍可能吸收图像而失去概念区分，故与源冻结查询及无图像支撑对照共同验证。

限定类别协议的完成度先分别计算：完整请求兼容 $s_1$、正确对象的目标概念对比 $s_2$、完整形态相对仅颜色的对比 $s_3$。仅在三者通过独立辨识后，将锁定尺度后的分数取保守合取，如 $s_E=-\beta\log\sum_{i=1}^3\exp(-\tilde s_i/\beta)$；该 soft-min 不大于任一分量，不能靠颜色高分抵消形态失败。词组与负例在协议中预先定义，并不声称能为任意新类别自动构造充分负例。上述公式给出可执行接口，不提供其语义正确性保证。

### 5.2 配对条件兼容辅助量

在本文 RF 时间约定下，已知 $(y,\epsilon)$ 的训练目标为 $u^*=\epsilon-y$，可构造

$$e_c(y)=\mathbb E_{\tau,\epsilon}\|v_\theta(q_\tau(y),\tau,c)-(\epsilon-y)\|^2,$$

$$s_c^{\rm rel}(y)=e_{\varnothing}(y)-e_c(y).$$

同图、同噪声、同时刻比较条件，借鉴文献 25—26 的配对与固有难度校正。**此处是 RF 兼容代理，不声称其等于对数似然、真实后验或编辑必要性。** 跨状态使用仍可能受模型偏好与覆盖影响。

四点交互量

$$\Delta_{c_a,c_s}(y,x_0)=R_{c_a}(y,x_0)-R_{c_s}(y,x_0)$$

可诊断文本如何改变图像观测，但不作为合法变化子空间。类别文本引起模型偏好正面，不等于用户允许转头；空条件也不提供源恢复保证。

### 5.3 不要求所有因素先被二值划为“能改／不能改”

对目标满足集合 $\mathcal F(T)$，定义源关系最小修改问题

$$\min_{y\in\mathcal F(T)}\ \sum_j w_j\rho_j\bigl(F_j(y)-F_j(x_0)\bigr).$$

其含义是：目标要求必须完成，源关系默认尽量保持；若请求明确要求转头，则目标集合要求姿态改变，保持代价只选择必要的最小改变。这样不必将每个关系预先硬标为绝对不变。

但它仍有两个实质前提：$\mathcal F(T)$ 的任务读出可靠；$F_j$ 对合法形态足够稳健。若两者失败，最小化仍可能欠编辑或源回退。**写出集合定义不等于实现了自由文本理解。**

### 5.4 自由文本的具体扩展与未解决接口

第一版只支持预先声明的任务因素和词组，完成能力验证。任意文本版可用源／目标变化片段、完整请求和固定关系词库提出候选查询，再以源绑定和图像证据筛选；片段差或 embedding 相似只用于召回，不作为语义授权证明。

不把“没有姿态词”直接当完整判断，也不因当前已经转头就开放姿态许可。显式任务与保持项冲突时，比较可实现的任务—关系折中和有限候选；若目标证据只偏好某种常见姿态，必须在任务切换／困难负例中暴露该问题。

当前无额外语言读出模型，**任意自由文本的范围编译和类别形态完整性仍是未完成接口**。设计给出了可实现的限定任务版本及扩展入口，不能宣称已有通用自动许可器。若本模型根本不能可靠读出某事实，增加优化强度不会补出该事实。

## 6. 选择性可观测性：理论上何时可能成功

设受控因素 $a$ 为合法形态，$b$ 为未请求姿态，读出为 $F(I(a,b))$。希望在有关范围内满足

$$\|F(I(a,b_0))-F(I(a_0,b_0))\|\le\eta_A,$$

$$\|F(I(a,b))-F(I(a,b_0))\|\ge\gamma_B\|b-b_0\|-\eta_B.$$

由三角不等式，只要 $\gamma_B\|b-b_0\|$ 足够超过合法泄漏和测量噪声，源相对读出才有分离机会。局部形式是

$$J_FU_A\approx0,\qquad \sigma_{\min}(J_FU_B)>0.$$

$U_A,U_B$ 仅在诊断数据中由已知因素定义，**不输入自动算法**。若用投影消除合法方向，关键条件是 $P_A^\perp B$ 仍有秩；坏姿态若在被消掉空间里，保持约束就必然失明。

这解释上一轮文本／速度子空间失败为何不能仅靠权重解决：其合法能量覆盖约为 0.065%—4.621%，且局部错误修正偏向源回退。新方案的理论希望在于先构造更有因素选择性的观测，不是再次宣称文本差已覆盖有限形态。

还有一个不可辨识反例：若所有可用观测和条件分数都只依赖 $a+b$，则 $(a+\delta,b-\delta)$ 与 $(a,b)$ 无法区分；任何基于这些输入的控制器都不能保证正确选择。共同提示、更多同类距离和更精确求解均不改变这一事实。

## 7. 当前错误的恢复控制与任务保护

### 7.1 局部有界子问题

把已验证的源关系堆为 $r=r_K(y_k)$，Jacobian 为 $J$。采用

$$\min_d\quad\frac12\|d-d_0\|_M^2+
\frac\lambda2\|r+Jd\|_W^2,
\qquad g_E^Td\ge m_k,\quad\|d\|_M\le R_k,$$

其中 $M\succ0$，$W\succeq0$，$g_E=\nabla s_E(y_k)$。任务增量下界 $m_k$ 只在该读出可靠、相应阶段适用时设置；已完成任务可要求不显著退步，未完成任务要求可靠推进或短窗口可达证据。

必须保留当前 $r$。仅惩罚 $\|Jd\|$ 会稳定保留已经发生的错误。$W$ 不能直接由 attention mass 给出，也不把不可观测事实写成零残差。

### 7.2 无信赖域激活时的闭式形式

记

$$H=M+\lambda J^TWJ,\qquad
\bar d=H^{-1}(Md_0-\lambda J^TWr).$$

无任务约束时，$\bar d$ 是唯一解。单个任务半空间激活且 $g_E\ne0$ 时，

$$d^*=\bar d+
\frac{(m_k-g_E^T\bar d)_+}{g_E^TH^{-1}g_E}H^{-1}g_E.$$

这是在 $H$ 度量下保护任务的最小调整。若信赖域也激活，必须求完整有界 QP／相应乘子；不能把解直接缩放后声称任务半空间仍满足。若约束不可行，记录冲突，可用显式 slack 诊断，不通过偷偷提高姿态容差来“求解成功”。

先研究直接修正干净 $y$，暂不把 C 内部注入作为主动作，以免观测与动作同时改变而难以归因。内部 C steering 可在观测选择性成立后另作独立消融。

### 7.3 在保护任务时，错误方向是否有局部控制能力

若 $J_E$ 为需保持的任务读出 Jacobian，受限可控 Gramian 为

$$\mathcal G_{K\mid E}=JM^{-1}J^T-
JM^{-1}J_E^T(J_EM^{-1}J_E^T)^\dagger J_EM^{-1}J^T.$$

它衡量在 $J_Ed=0$ 的动作空间内改变保持观测的能力。小特征值说明局部修复困难，不能说明某姿态错误是任务必要的，也不能证明不存在有限绕行路径。这个诊断的前提仍是 $E/K$ 已有真实语义。

### 7.4 有限步验收与积分一致性

优化后重新计算 $D(y_k+d)$ 及新的原生观测，检查真实有限任务证据、关系残差和质量变化。线性化误差记为

$$e_{\rm lin}(d)=\frac{\|F(y_k+d)-F(y_k)-J_Fd\|}{\|J_Fd\|+\varepsilon}.$$

采用小规模回溯或减小信赖域；所有候选共享同一源锚和任务参照。接受后保存修正的 $y_{k+1}$，由原 FlowEdit 方程重新构造下一步查询。单步代理进展不保证终点完成，完整轨迹仍需独立验收。

## 8. 相位如何纳入，并允许必要幅相变化

对图像复滤波 $c_s(y)=h_s*D(y)$，正则化相位速率代理为（远离零响应时逼近真实微分）

$$\dot\phi_s[d]=
\frac{\operatorname{Im}\{\overline{c_s(y)}\,[h_s*(J_D(y)d)]\}}
{|c_s(y)|^2+\varepsilon_\phi^2}.$$

其物理意义是实际潜变量动作经解码后的相位响应；不能用潜变量 FFT 或扩散时间替代。

令 $\mathcal D_k$ 为任务推进、源关系恢复、信赖域共同定义的局部动作集合，则允许相位的集合为

$$\Omega_{\phi,k}=\{\dot\phi[d]:d\in\mathcal D_k\}.$$

合法类别形态引起的相位变化可随可行 $d$ 保留；姿态错误被关系恢复约束限制。这里没有逐相位硬冻结，也没有以无法光度解释作为非法证据。若关系读出失效，相位集合也不会自动获得正确语义；相位先作为诊断与机制一致性检查，后续再研究是否有独立收益。

## 9. 本地实现应如何组织

### 9.1 只读提取接口

1. 固定共同提示及其完整编码，缓存每个 $\tau,\epsilon$ 的源查询。
2. 分别记录 selected block 的 pre/post-AdaLN、原生 Q/K/V、O、模块输出、文本残差；每轮只开必要 facet，避免显存膨胀。
3. `JointTransformerBlock.attn` 的 `[0]`／`[1]` 是图像／文本模块输出；整个 block 的 `[0]` 是完整文本残差，不能混用。末层 `context_pre_only` 的文本残差可为 `None`。
4. 只读 B 在旁路复用原投影、归一化、门控与 MLP，不改变原序列长度或原 attention kernel 的路径。需要概率时只为少量查询单独计算，不显式物化全部 $N^2$ attention。
5. 分别测试数值一致性与梯度连通。原速度保留原后端；JVP/VJP 若要求数学 attention，须单独说明并检查后端变化，防止重演上轮内核混杂。

概念输出空间相似度与实际几何权重来自不同位置，必须记录尺度、softmax 轴和投影顺序。不能把 T5 embedding 与 attention output 因维数接近就直接作语义点积。

### 9.2 首个可实现配置

采用一个共同对象提示、少量低／中噪声时刻、分布于浅／中／深的层；先分别比较 O、C、B，不立刻学习融合。初始候选数量可用 3 层、2 个噪声时刻、2 个优化噪声种子，参数仅为实验起点，不声称最优。

源前向可缓存；当前状态每步的探测开销约与提示数×时刻数×种子数成正比。B 约增加少量 query 的 attention 和旁路 MLP，完整求导可能多次调用 JVP/VJP，不能宣称免费。先测观测，再做短程控制，避免用大量完整轨迹掩盖读出错误。

最先实现方向关系、对象间相对位置、背景概念分布及类别困难负例。对于只有内容证据而没有可信空间绑定的概念，仅报告存在／兼容趋势，不用作局部姿态硬约束。

### 9.3 每步算法

```text
输入：固定源 x0，源／目标文本，当前干净 yk，原 FlowEdit 提议 d0
读取固定探测配置下的源缓存与当前 O/C/B
计算对象绑定、内容／坐标／关系、任务证据与观测歧义
对通过离线选择性检验的关系构造当前源残差 rK
若观测不足：记录未覆盖事实，不把缺失记作保持成功
在任务保护和信赖域内求最小恢复修正
对有限候选重新解码，并用独立探测噪声检验
接受后更新实际干净 y，并按原积分关系同步后续查询
输出：图像与逐步任务／保持／不确定性记录
```

“观测不足”时第一版可保留原提议作为明确的无控制对照，不能把此类样本计为约束成功。若用户目标要求严格保持而事实不可测，当前算法不能提供该保证。

## 10. 必须先完成的证伪实验

### 10.1 状态忠实性与只读性

原查询与挂载只读提取／B 的查询逐步比较速度；恒等源／当前的配对残差应为零。固定干净图换冲突提示，固定提示换干净状态，检查读出跟随实际图还是文本意图。使用未完成、部分完成、正确完成、完成但转头四种起点。

### 10.2 因素选择性

同源做纯改色、类别形态、显式转头三任务；两方向转头、耳／吻形变化、相机换侧、对象面积反平衡、相同类别多实例、遮挡及不同背景。合法形态与错误姿态分开计分，不把源图不变算目标完成。

核心比较为旧 8×8 H、原生 O、文本 C、只读 B、O+C+B，以及 Q/K/V 与 post-AdaLN 对照；所有条件固定，分别报告合法接受、各类错误拒绝、任务困难负例排序与源间泛化。阈值与配置在开发／校准组锁定，最终源和种子独立留出。

### 10.3 修复与完整编辑

先从已正确、欠编辑、局部转头、背景偏移出发做短程修复。设置仅缩步、等幅随机、向源回退、无恢复残差、无任务保护对照；离线合法参考只诊断方向，不进入自动推理。

只有在相近实际编辑完成度下，修复朝向／场景且不撤销必要形态，才扩大完整轨迹。全轨迹独立评价任务、保持和质量，不能仅用被优化的分数自评。上一轮单熊图代理下降而转头仍在，是必须跨过的基线。

置信区间以独立源为聚类单位；同源多状态／多种子不能全部当独立样本。统计方法只评价已定义代理，不能修复错误的语义真值。

## 11. 理论能够保证到哪里

给定光滑可靠观测、正确任务半空间、正定数值尺度及非空可行集，局部子问题可给唯一最小修正解；配对恒等性、置换反例及恢复代数可构造核对。[数学核对脚本](theory_checks/原生配对观测联合反馈_数学核对_2026-10-30.py)和[输出](theory_checks/原生配对观测联合反馈_数学核对_2026-10-30.json)仅检验这些有限维命题，**不验证原模型语义和图像编辑质量**。

若真实关系误差 $r^*$ 与观测残差的差有已知界 $\eta_K$，则 $\|r^*\|\le\|\hat r\|+\eta_K$；若任务分数误差有界 $\eta_E$，可在阈值上保留相应裕度。当前没有通用可信的这两个界，故代理下降不能升级为真实语义保证。

最终建议的主线是：**原生配对测量 → 源实例／部件绑定 → 保留内容与坐标的关系读出 → 有任务保护的当前残差恢复**。最重要的新假设是这些原生通道能提供所需选择性；最重要的停止条件是该选择性在有限合法形态与错误姿态对照中不成立。此时应报告冻结条件下尚未获得可靠观测，而不是继续放大同一代理或暗中引入训练模块。
