## 1. 主结果

![同一真实源图、FlowEdit、SelFix 高保真反演编辑](../experiments/sota_inversion_20261105/outputs/comparison_v1/comparison.png)

从左至右：真实源图、FlowEdit 作者推荐配置、SelFix 高保真反演预算＋官方编辑注入。任务仍为棕熊→黑熊，完整源／目标提示与上一轮一致。

两种方法都使用**同一 FLUX.1-dev、同一 VAE、同一张 1024×1024 原始照片和同一组完整文本条件**。本轮 FlowEdit 也在 FLUX 上重新执行，没有拿旧 SD3 图与 FLUX 图混比。

SelFix 的实际编辑反演通过了运行前登记的源重建门槛：相对未编辑潜变量的 VAE 解码图，PSNR **31.767 dB**、SSIM **0.969658**。重建与主编辑图使用**完全相同的反演潜变量**；重建控制不注入源特征。

对结果的人工视觉检查：

- SelFix 生成清晰的黑色熊外观，保持了侧向朝向的大体关系；没有上一轮的文字、边框、黑白图形或房屋伪影。
- FlowEdit 推荐配置同样生成黑色熊，但顶部原有草地／花朵大面积变成了水面和倒影，头部也更朝向镜头。
- SelFix 保留顶部场景较多，但身体轮廓、足部和局部水流仍有变化，不能宣称完全保留源姿态或所有无关内容。
- 本轮不据单张视觉结果证明完整生物类别形态正确，也不宣称 SelFix 在所有因素上优于 FlowEdit。

## 2. 为什么选这个近期方法

截至 2026-11-05，核查了 SelFix、SlerpFlow、DirectEdit、SteerFlow、FlashIn 等近期路线。原始来源和选择边界保存在[来源清单](../experiments/sota_inversion_20261105/sources.json)。

选择 **[SelFix（2026）](https://arxiv.org/html/2606.17584v1)**：有作者公开代码、FLUX.1-dev 的重建／编辑评测，以轨迹直线性引导固定点选根，并保留官方 Value 特征注入。[官方代码](https://github.com/SeminKim/selfix)已下载，固定到 `c549b2f934c8cde7d3ff46a020dc05422059d435`。

“近期 SOTA 候选”指有公开证据的高保真强基线，不表示存在一个所有任务、计算预算和模型下都公认第一的方法，也不把不同论文的 PSNR 跨预算直接排名。没有把自行改写的普通 ODE 或简单高阶求解器冒称 SOTA。

## 3. 原码复用与权重审计

直接导入作者的 `denoise_selfix`、原生 `Flux` 和单流块注入代码。根选择、调和衰减、解耦动量与 Value replacement 实现未修改。源／目标条件、模型参数和 VAE 均冻结。

本地已有的是 Diffusers 格式的 FLUX 权重。为使用作者的原生模型，将权重布局转换回原生格式，再用已安装 Diffusers 的官方转换函数做往返：**全部 1160 个张量逐元素相等**，原生模型严格加载通过。[审计记录](../experiments/sota_inversion_20261105/outputs/comparison_v1/weight_layout_audit.json)保留布局和文件信息，没有重新训练或替换权重。

VAE 与 CLIP／T5 复用本地相同权重。VAE 编码用 FP32 后验众数，再转原生 packed BF16；Transformer 和文本条件使用 BF16，解码使用 FP32。原始照片不降采样。CLIP／T5 的实际 token 长度已核对，源／目标均未截断，见[文本输入审计](../experiments/sota_inversion_20261105/outputs/text_input_audit.json)。

老 FlowEdit 包装器的尺寸 API 与当前 Diffusers 不兼容，本轮在同一个原生 Flux 模型上实现作者的 n_min=0 速度差更新，使用正确的 4096 个图像 token；未声称对旧包装器做逐元素重放。源查询、目标查询、反向积分符号及 FP32 累加后转回 BF16 的更新方式均与原算法一致。

本地环境为 PyTorch 2.5.1／CUDA 12.4，作者开发环境为 2.7.1／12.6。原码在当前环境完成推理，完整版本见[环境记录](../experiments/sota_inversion_20261105/outputs/environment.json)；本图测量不冒充复现论文全量 benchmark 平均值。

## 4. 配置：保留默认，另加有明确身份的高保真预算

| 方法／配置 | 反演 | 目标生成 | 源／目标 guidance | 单张反演＋编辑 NFE |
|---|---|---|---|---:|
| FlowEdit 推荐 | 无反演 | T=28，n_max=24，n_min=0，n_avg=1 | 1.5／5.5 | 48 |
| FlowEdit 引导强度对照 | 无反演 | 同上 | 1／2 | 48 |
| SelFix 作者默认编辑 | 15 步×4 次固定点，μ=.1，δ=2 | 15 步 | 1／2 | 75 |
| SelFix 高保真预算，主图 | 15 步×10 次固定点，μ=.5，δ=1/8 | 15 步 | 1／2 | 165 |
| SelFix 高保真、更强目标引导 | 与主图复用同一反演 | 15 步 | 1／3.5 | 每图逻辑成本 165；本次额外仅 15 |

两类 SelFix 都使用 α₁=.5、window=1、clone 初始化。目标编辑保留作者设置：第一个反向步、single blocks 0–37、Value replacement。高保真预算将作者的**重建配置用于反演阶段**，再保留官方编辑注入；它与“作者默认编辑”分开标注，没有伪装成原默认。

主图不是同计算预算比较；目标是先建立高质量、高保真的反演编辑参照。FLUX guidance 是蒸馏引导输入，上述 NFE 为单图 Transformer 调用，不是 SD3 四分支 CFG 计数。

不使用空间编辑掩码、外部正确编辑图、新 LLM、额外训练模块或事后图像修补。主图选择运行前指定的高保真预算、guidance=2；默认和更强引导配置全部保留。

## 5. 同一反演潜变量的源重建：先证明基线没有崩溃

![对应实际编辑反演的源重建](../experiments/sota_inversion_20261105/outputs/comparison_v1/reconstruction.png)

源重建使用源提示、guidance=1、**关闭特征注入**。固定筛选条件为相对 VAE 源图 PSNR≥28 dB 且 SSIM≥.90，运行前已记录在协议中。

| 源重建配置 | 相对 VAE 源图 PSNR / SSIM | 相对原始照片 PSNR / SSIM | 预设筛选 |
|---|---|---|---|
| 未编辑潜变量的 VAE 图 | 恒等 / 1.0 | 29.779 / 0.907110 | VAE 参考上限，不是反演结果 |
| SelFix 默认编辑反演 | 26.773 / 0.952727 | 25.150 / 0.869228 | 未满足 28dB；原结果保留 |
| SelFix 高保真反演 | **31.767 / 0.969658** | **27.647 / 0.876926** | **通过** |

这里的“VAE 源图”是将未编辑的实际 packed BF16 源潜变量直接解码。报告两种参考，是为了区分 VAE 共同损失与额外反演误差。**31.767 dB 不能写成相对原始照片的重建精度**。原照片中细毛、花草和水纹的一部分高频信息已经在 VAE 往返中丢失。

指标基于 [0,1] 浮点解码图，SSIM 使用高斯窗口；PNG 用于展示，8bit 量化后单独重算会有微小差异。

源重建过关不等于编辑完全保真，更不等于目标已完整实现。因此继续看真正目标编辑和各因素变化。作者代码 trace 中的 `residuals` 字段也未被当作精确固定点方程残差来认证收敛；本轮使用实际图像重建测量验收。

## 6. 编辑保留能力：结果有取舍，不能只看整图源差

以下是固定源坐标窗口相对 VAE 源图的测量，参考与方法间完全一致。顶部窗口为 y∈[0,220)，底部水面为 y∈[850,1024)，均覆盖完整宽度。窗口只用于离线评价，没有输入模型或控制更新，也不等于已经识别所有背景语义。

| 目标编辑 | 顶部草地 PSNR / SSIM | 底部水面 PSNR / SSIM |
|---|---|---|
| FlowEdit 推荐 | 19.446 / 0.644123 | **22.021 / 0.801934** |
| SelFix 默认 g=2 | 20.435 / 0.692540 | 19.996 / 0.742273 |
| SelFix 高保真 g=2 | **19.992 / 0.744794** | 19.799 / 0.741829 |
| SelFix 高保真 g=3.5 | 13.443 / 0.383042 | 13.989 / 0.465800 |
| FlowEdit guidance 1／2 | 32.739 / 0.976371 | 33.528 / 0.980345 |

主图的 SelFix 在顶部结构 SSIM 上优于 FlowEdit 推荐配置，但底部水面指标不占优；默认 SelFix 的顶部 PSNR 又略高于高保真版本。这些混合结果必须保留，不能只选一个指标宣布全面领先。

![引导强度对照](../experiments/sota_inversion_20261105/outputs/comparison_v1/guidance_controls.png)

FlowEdit guidance=1／2 很接近源图，但视觉上黑色外观变化较弱，不能因源差小就判为更好的编辑。SelFix 提高到 g=3.5 后，背景虚化、腿部状态和水流改变更大；本例中更强引导没有带来更好的整体保持。

整图 PSNR／SSIM也保存在[完整测量](../experiments/sota_inversion_20261105/outputs/comparison_v1/metrics.json)中，但它们混入了合法颜色、形态和外观变化，不被当成“不必要编辑”的唯一评价。本轮没有经过独立校准的完整类别／解剖姿态判别器，不报告未经验证的转头角度或“语义编辑占比”。

## 7. 可以确认什么

1. **高质量反演编辑参照已建立。** 近期原码方法在这张图上得到清晰编辑，对应源反演通过预设重建门槛，上一轮的粗糙数值失真不再主导比较。
2. **不能从普通 ODE 的失败推断反演路线天然较差。** SelFix 在本例确实保留了较多顶部场景；FlowEdit 在其他区域也有自己的保持优势。
3. **更好的反演不自动消除目标编辑耦合。** 高保真源重建之后，目标生成仍可能改变身体轮廓、足部与局部水流；反演精度和编辑内容选择应分别研究。
4. **本例是同主干的质量对照，不是同预算、同完成度或大样本优越性证明。** 若要研究语义约束的独立收益，应在各自达到完整任务进度的条件下，再比较未请求因素改变。
