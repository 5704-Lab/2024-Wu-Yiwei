# 源／目标配对相关性：可观测性与逐步修正实验设计

日期：2026-10-12。依据[修订理论方案](源图源文本与编辑状态目标文本_配对相关性与逐步修正_2026-10-12.md)。本计划尚未执行真实模型验证；已执行的 40 个合成数学案例不是图像实验。

## 1. 要验证的假设

1. 分别分析原图—原描述和干净编辑图像—目标描述，比仅观察目标减源分数更容易识别评分捷径。
2. 条件坐标对齐后的单位残差方向包含足够的源实例信息，能感知此前的姿态、视角和身份偏移。
3. 在相近的实际目标完成度下，降低配对残差代理能够减少这些偏移。
4. 有目标兼容约束与有限回缩的逐步修正，优于直接叠加语义和保持梯度。

四条逐级验证；前一条通过不代表后一条通过。尤其不把匹配分数、残差或全图 SSIM 视为准确的非编辑区域真值。

## 2. 固定边界

输入只有源 RGB、源描述与目标描述，使用现有冻结 SD3 Medium／SigLIP2。无训练、微调、反演、编辑区域或注意力掩码、轮廓参考、目标图、终点匹配。

起始潜变量 x 与源 VAE 重建单独标注；源配对优先用实际原图，而不是默默用 VAE 重建替代。每张编辑对比图必须包含原始 FlowEdit。

## 3. A 阶段：先检查保持量能否看到误差

### 输入与记录

复用四个开发样本及既有 FlowEdit 轨迹；不生成新修正图像。记录原 RGB、源 VAE、所有活动步与终点：

- 各自配对的 cosine 和 logit；另记录当前图像的源 logit，仅作诊断。
- 文本夹角、残差长度、未对齐残差距离、转移后单位残差距离 K。
- 原始完整残差幅度与方向，检验幅度保持是否暗中限制目标分数。
- 源 RGB 与 VAE 的配对偏差、归一化退化和数值有效性。

不把 K(x) 当作 0：源自身配对的参照来自 T_s，而 K(y) 位于 T_a 坐标。

### 输入自身的已知变化

源图和中期图各施加小幅全图明暗、对比度、平移和尺度变化，记录配对量。保持完整图像，不提取编辑区域。此检查只有已知扰动含义，不说明所有真实语义编辑满足同样规律。

逐图展示源／VAE／FlowEdit、条件文字、目标强度与 K 曲线。重点审查已有车辆前后视图、熊步态、猫面部偏移是否在 K 中可见；不要只按平均值判断。

### 进入下一阶段的条件

若在目标强度相近的候选中，明显实例偏移没有被代理识别，停止扩大该保持量；优先研究读出可观测性。没有理想目标图时，人工观察只能提供有限证据。四图上的任何选择都是开发选择，不算留出验证。

## 4. B 阶段：局部方向与有限步

在原始 FlowEdit 的名义候选处求导，覆盖早／中／晚活动步。比较以下候选，保留同一名义增量：

| 候选 | 要排查的问题 |
|---|---|
| 原 FlowEdit | 必需基线 |
| 纯绝对目标梯度 | 分数提高是否仍伴随无关变化 |
| 完整源特征近端 | 单纯缩小源距离是否欠编辑 |
| 未对齐单位残差 | 不同条件坐标直接比较的误差 |
| 对齐后的完整残差 | 残差幅度匹配是否锁定匹配强度 |
| 对齐单位方向、无目标约束 | 保持与目标是否冲突 |
| 对齐单位方向、线性目标约束 | 一阶兼容与二阶目标下降的差别 |
| 对齐单位方向、有限回缩／验收 | 主候选 |

初版 H=μI，μ=1；采用同尺度的 λ 网格 0.1、0.3、1，修正预算不超过名义增量 L2 范数的 0.05、0.10、0.20。这里只选择可行性和稳定性，不按四图最优观感反复调参。

报告 gᵀr、K 的预测／实际下降、绝对目标变化、KKT 残差、修正范数与预算乘子。矩阵自由求解使用 JVP／VJP；预先设定工作量上限并保留未收敛记录。非精确求解不引用精确闭式解的误差界。

有限回缩最多登记的迭代次数后仍失败时返回名义步。浮点评分容差由重复计算与可微预处理检查确定，不用模糊“语义成功阈值”代替。

极点、反向文本、目标梯度退化、零预算和只有零兼容解都应单独测试，不能用伪非零修正满足每步执行要求。

## 5. C 阶段：真实完整编辑

A、B 通过后才执行。开发集使用原四图，相同 SD3、512 分辨率、50 步时间表、后 33 步编辑、CFG=3.5/13.5、n_min=0、n_avg=1、CPU seed=0。锁定一个主参数组合，另保留 λ=0 与旧 CAL。

主比较至少包括：源 RGB、源 VAE、原始 FlowEdit、完整源特征近端、未对齐残差、主配对修正、旧 CAL。分别报告必要属性变化、姿态／视角／身份、背景与伪影；源文本与目标文本完整标注。

每步保存名义候选、修正后状态、两个配对、K、目标兼容条件、回缩系数、求解残差、退回原因、q 同步误差和计时。接受后重算 q，不让旧状态继续进入速度预测。

比较原则是相近的人工判读任务完成度，而不是相同 SigLIP 优化分数。不固定原 FlowEdit 终点，也不把源对照分数下降算作必要目标收益。

## 6. D 阶段：留出与成本

预先选取新输入、至少三个共享随机种子，涵盖属性、配饰和对象替换；保留大幅几何变化任务来检验欠编辑。留出集不调保持强度、文本转移或阈值。

源／目标提示变化、源描述不完整、错误描述和同义描述用于稳定性审查。多描述只作诊断，未经联合秩与可达性检查不同时硬约束。

采用实际图像检查与未用于优化的指标联合评价；同模型换层／换措辞不称为完全独立证据。没有可用真值时不报告精确非编辑区域一致性或成功率。

独占或稳定 GPU 负载下测总时间、模型前向／反向次数、峰值显存与相同任务完成度的质量。没有稳定保持收益前不推进少步实验，也不从合成数学核验推断加速。
