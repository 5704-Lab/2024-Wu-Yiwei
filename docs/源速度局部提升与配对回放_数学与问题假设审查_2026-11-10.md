# 源速度局部提升与配对回放：数学与问题假设审查

日期：2026-11-10。审查对象：[11月9日方法与证明](源速度局部提升与配对回放_理论闭环与方法定义_2026-11-09.md)、[实验设计](源速度局部提升与配对回放_分阶段实验设计_2026-11-09.md)和对应参考代码／计划。核对 [FlowEdit 原文 §4–5](https://arxiv.org/html/2412.08629v2)；本轮只执行 CPU 数学审查与构造反例，没有新增图像模型推理。

**结论：方法包含合理的数值设计，多数命题在写明的条件下正确；但它已转为近似部分反演与源残差锚定，不能按“FlowEdit 内部小修正，已解决无反演随机漂移”定位。** 源轨迹适配假设只得到部分对齐，非编辑内容保持尚无保证。主 Heun 流程还缺少已验证的可逆性／条件数前提，原实验计划的开发门槛也缺少对应作业。

前一轮“理论闭环已完成”的措辞应收窄为：**建立了若干条件性动力学命题和单候选离散参考算子，尚未形成面向真实 FLUX、原 FlowEdit 期望映射与编辑语义的完整保证。** 本次不是把有条件的公式判成错误，而是检查这些条件是否真的支撑所期待的结论。

新增[审查代码](../experiments/source_coupled_replay_20261109/audit_20261110/review_checks.py)的11个核对例全部复现预期，其中多项是反例；“通过”不表示编辑方法已有效。[原始结果](../experiments/source_coupled_replay_20261109/audit_20261110/review_checks.json)。

## 1. 对 FlowEdit 改了什么，是否合理

| 部分 | 原 FlowEdit | 当前方案 | 审查 |
|---|---|---|---|
| 源查询 | q_s=(1−t)x+tε，每步采样／平均 | 先求局部 q_T，再让源分支按模型回放 | 能检验源动力学一致性，但改变了实例耦合 |
| 更新场 | 对随机配对速度差取期望或有限采样 | 同一 q_T 的确定性源／目标两条轨迹 | 不再估计原来的随机期望场；不能仅解释成降方差 |
| 干净编辑变量 | 原本就从 x 初始化 | y=x+(z_a−z_s)，仍从 x 初始化 | 保留直接域状态，不是新实现“从x0开始” |
| 积分器 | 原基线为 Euler | 同一 Euler／Heun 回放 | 匹配积分器合理，但数值方法变化需单独消融 |
| 最终输出 | 原编辑 ODE 的终点 | 原始目标回放减去源重建残差 | 可限制修正幅度；不能单凭源残差证明保姿态 |
| 源适配精度 | 不要求每条随机弦为源 ODE 解 | 用实际源回放残差筛选／细化提升 | 是逆解精度判据，前提包括回放映射良态 |
| 理想极限 | 随机配对平均诱导的编辑映射 | 准确反演诱导的目标回放 | 两个映射一般不同，需修订方法定位 |

这些变动中，实际速度局部提升、有限失败退出、明确成本、匹配离散算子和不使用未校准的径向目标都合理。问题在于它们支持的是另一条候选耦合的可计算性，尚不能推出相对 FlowEdit 更好的任务—保持关系。

## 2. 与最初问题假设的对齐度

### 源实例与随机查询不对应：部分对齐

若研究目标是“固定源图的查询是否遵守源条件动力学”，L1／L2 与源 ODE 对照确实相关。但随机弦本来就不是被要求逐条满足边缘 ODE 的训练轨迹；不能将 v_s(q,t)≠ε−x 直接判为模型不适配。

模型内的 v_c^*=E[ε−X|Q_t,c] 与 FlowEdit 外层 E_ε[v_a−v_s] 是两个不同平均。当前方法删除／替换的是外层随机配对平均，预训练速度的条件均值性质没有改变。因此它没有直接解决或验证“速度均值导致样本特殊性丢失”的假设。[Flow Matching 的条件场／边缘场构造](https://arxiv.org/html/2210.02747)

### 不经过源反演而保留实例：对齐不足

L1=x+Tf_s(x,0) 是一次源前向 Euler 近似；L2 是一次 Heun 近似，逐级 Heun1／2／4／8／16 则逐渐逼近部分反演。它们可以降低完整反演成本，但不能称为严格无任何源逆动力学。

### 非编辑内容少漂移：尚未建立

本方案没有任务选择性的姿态、视角或背景约束。源重建准确控制的是初始点／模型回放误差，目标条件本身仍可能诱导转头、换背景等改变。旧实验也没有做相同 T、相同编辑器下随机查询与源轨迹的完整因果比较，不能用它证明该假设已成立。

## 3. 最关键的结构判断：小源残差的极限是反演配对

记 G_s、G_a 为相同时间范围内的源／目标回放映射，假设 G_s 在相关区域可逆。当前输出为

\[
y=x+G_a(q_T)-G_s(q_T),\qquad r_s=G_s(q_T)-x.
\]

当 r_s→0 且源逆映射连续时，

\[
\boxed{y\longrightarrow G_a(G_s^{-1}(x)).}
\tag{A1}
\]

这是精确或离散反演诱导的编辑结果，取决于 G 的定义。它不是一般意义上的原 FlowEdit 随机期望映射。证明只需 q_T→G_s⁻¹(x)，再代入输出。

原 FlowEdit §4 将反演编辑写成这种直接差分路径，§5 则刻意替换源过程，以改变反演诱导的配对。因此，把源回放逐渐做准，是回到那条配对，而非自动修复 FlowEdit 的原期望场。[原文 §4–5](https://arxiv.org/html/2412.08629v2)

### 精确高斯场上的定量区别

取一维源分布 N(0,1)、目标 N(0,4)，独立标准高斯训练噪声，给定源 x=1，T=.8。该 RF 场为

\[
v_\sigma(q,t)=\frac{t-(1-t)\sigma^2}{(1-t)^2\sigma^2+t^2}\,q.
\]

由于场为线性函数，原 FlowEdit 的噪声期望可精确化为源查询均值 (1−t)x 下的编辑 ODE；以高精度标量 ODE 求解得 y_FE≈1.49607。源反演配对的闭式结果为

\[
y_{inv}=\frac{2\sqrt{(1-T)^2+T^2}}{\sqrt{4(1-T)^2+T^2}}x
\approx1.84391.
\]

两者相差约 .34783。这个例子没有学习误差，明确说明新方案不是原 FlowEdit 的无偏低方差实现。此处不宣称哪个数值在语义上更好；它只判定两种数学对象不同。

## 4. 命题 P1–P8 的逐项数学审查

| 命题 | 审查结论 | 必须保留的条件／不能推出的结论 |
|---|---|---|
| P1 局部提升及 Heun 稠密段 | 正确 | 固定光滑场、有效区域与一致导数界；O(T²)/O(T³) 是 T→0 的局部结论 |
| P2 缺陷 Grönwall 界 | 正确，表述需更严谨 | q̂ 必须绝对连续，或有限分段 C¹ 且连续；仅“连续且几乎处处有导数”不够 |
| P3 配对回放、同条件恒等 | 正确 | 完整条件、积分网格、算子及随机性相同；恒等是原 FlowEdit 已有回归性质 |
| P4 输出修正幅度等于源残差 | 代数恒等式正确 | 只限制输出到原始目标回放的距离，不限制输出到源图或正确编辑的距离 |
| P5 配对敏感度误差界 | 条件性正确 | 源逆存在、逆条件数有效、差映射常数有效；参照是反演配对而非语义真值 |
| P6 Euler 离散逆 | 正确 | hL<1 及全局／有效不变区域；不能直接用于主 Heun 算子 |
| P7 有限退出和399次调用上限 | 计数与有限性正确 | 不保证通过源门、任务成功或逼近原 FlowEdit；自适应总控尚未整体实现 |
| P8 校准后的语义转移 | 条件蕴含正确 | 当前没有满足条件的通用 T̂、C；无法据此宣称实际语义已闭环 |

未发现式(1)、(4)、(8)、(9)、(10)在各自明确前提下的代数错误。问题主要是适用前提和参照对象，而不是这些不等式的形式。

P1 的大小阶不可外推到 T=.9。解析例 f(q)=4q、x=1 中，T=.9 时 L1 误差超过30，L2也超过20；并不违反小时间定理。Heun的单步局部三阶误差，也不能写成多步全局三阶精度。

P2 对当前有限段多项式实现适用，因为它自动绝对连续；文档应把这一条件明确写出。严格机器上界还需外向舍入／数值误差控制，现有浮点“bound”数值只是条件性解析式的计算值。

## 5. 为什么源残差阈值不是实际编辑误差证书

P5 为

\[
\|y-y^*\|\le K_\Delta K_{inv}\|r_s\|.
\]

它没有证明 K_ΔK_inv 小，也没有测得实际 FLUX 的有效统一常数。取 G_s(q)=10⁻⁴q、G_a(q)=q、x=0、候选 q=1：源残差仅10⁻⁴，会通过 .02门；输出却为 .9999，距参照目标0仍接近1。

这不反驳P5，因为正确常数为K_inv=10⁴、K_Δ=.9999，误差界恰为 .9999。它反驳的是“源残差数值很小，所以编辑误差一定很小”的省略推理。

还需区分两种含义：

- 源残差可无条件、直接限制**残差加减修正幅度**，这是P4；
- 源残差能限制**反演参照误差**，还要P5的逆条件数；
- 姿态／背景保持需要另一个语义桥梁，前两项都不足以提供。

因此 .02可以保留为操作容差，不能命名为已认证的语义安全半径或适配证书。

## 6. 主 Heun 流程缺少的条件：ODE 可逆不等于数值步可逆

### 6.1 反例：光滑场下 Heun 可折叠

取 h>0，J 为二维90°旋转矩阵，A=(I+J)/h。对 q'=Aq，精确反向流为 exp(−hA)，行列式 e⁻²>0；Heun反向一步的线性部分却为

\[
R=I-hA+\tfrac12h^2A^2=0.
\tag{A2}
\]

所有初始点都被映到同一点，因此不存在有限逆 Lipschitz 常数。

审查脚本进一步加入光滑时间强迫项，使实际 L1 提升也会触发该反例：源数值残差约2.2e−17，通过 .02门；但相对精确连续源反演所对应的目标，误差约 .04695。该例的精确 ODE 仍可逆。这是解析反例，**不是对实际 FLUX 已发生折叠的判断**。

同条件恒等检查无法发现这种折叠，因为两个分支同时折叠仍会相减成零。原37项检查使用良态仿射场，也没有覆盖这个病态。

### 6.2 可以补上的 Heun 充分条件

写 Ψ_H(q)=q+R_h(q)。若源场在两阶段时间上分别有有效状态 Lipschitz 上界 L₀、L₁，则

\[
\operatorname{Lip}(R_h)
\le c_H=\frac h2\left[L_0+L_1(1+hL_0)\right].
\]

当 c_H<1 时，反三角不等式给出

\[
\|\Psi_H(q)-\Psi_H(p)\|\ge(1-c_H)\|q-p\|.
\tag{A3}
\]

全空间条件下，逆方程 q=z−R_h(q) 是压缩映射，故存在唯一逆；在局部区域还需映射不出域。若 L₀=L₁=L，充分条件为 hL+(hL)²/2<1，即 hL<√3−1≈.732。

这补齐了形式上的 Heun 条件，但实际 FLUX 的有效 L 仍未知。样本 JVP／割线不能冒充统一上界。至少应对**主方法所选的同一 q_T**检查源、目标 Heun24／48／96 回放的网格稳定性；即使该数值检查通过，也只能称经验稳定，而非严格可逆性证书。

## 7. 源残差相减可能直接损害非编辑因素

若原始目标为 a=G_a(q_T)，修正为 y=a−r_s，对光滑目标分数 T 有

\[
T(y)-T(a)=-\nabla T(a)^Tr_s+O(\|r_s\|^2),
\]

没有固定的改善符号。

更直接的可复现例：源点 x=(0,0)、T=.5，源速度 f_s(q,t)=(0,−2εt/T²)，目标速度 f_a(q,t)=(−1/T,0)，ε=.01。L1提升为q_T=0，源回放为(0,.01)，原始目标回放为(1,0)，修正输出却为(1,−.01)。

以第一坐标为请求编辑、第二坐标为保护因素，原始目标保持了第二坐标，残差修正引入了变化。源RMS残差约 .00707，仍通过 .02门；P4恒等式完全成立。这说明需要原始／修正目标消融，不能把相减统一解释为恢复非编辑内容。

## 8. 实现与实验设计的具体缺口

### 主方法开发门槛缺少作业——需修复

v1计划要求主方法在开发集中高T完成至少2/4任务、源门覆盖至少3/4，才进入保留集。但实际队列中 `paired_source_guarded` 只出现在保留确认；开发消融是Euler配对版本，积分器实验也只覆盖两源L1，没有4源主方法自适应Heun24作业。

因此门槛无法按原队列评价，或会被其他方法的结果错误替代。修订草案明确增加：

- 4个开发源在固定 T=.9 的完整主方法作业；
- 4个依赖这些结果的源／目标映射网格稳定性作业，对同一选中 q_T 比较Heun24／48／96。

v1的424作业／44448次上限保留为历史记录；[v2草案](../experiments/source_coupled_replay_20261109/audit_20261110/plan_v2.json)为432作业／48348次上限，新增3900次预算全部单列。尚未执行。

### 参考实现覆盖不等于完整算法已实现

`paired_replay` 实现的是单个给定提升候选的回放与验收；六候选自适应选择仍主要在协议中定义，并未实现完整真实模型总控。399次上限是正确的计划算术，不是实际端到端运行日志。

预算耗尽时，参考代码返回失败但不保留已完成的源回放状态；未来执行器需在外层保留失败上下文。它不影响已证明的恒等式，却关系到“全部失败都可审计”的实验要求。

原始文档、协议、计划、参考代码和旧真实实验产物均未覆盖。审查补充不把旧37项检查写成针对上述缺口的验证。

## 9. 审查后的方法定位与推进建议

**可保留：** 实际速度局部提升作为便宜源动力学近似；缺陷及源循环残差作为数值诊断；匹配积分器与显式失败／成本账本；原始目标和残差修正目标的独立消融。

**需收窄：** 不称严格无反演，不称无偏保留原FlowEdit映射，不称源门已证明非编辑保持，不将同条件恒等作为新质量优势。

**优先验证：** 原计划“只替换 q_s”的查询单因素阶段最符合用户原始假设。固定时间网格、guidance和编辑更新，比较随机重采样、固定随机弦、αx、L1、L2与源ODE参照，在相同目标完成度下观察实际漂移。配对回放分支应作为近似部分反演对照，而不是预先指定的胜出主线。

如果源路径越来越准而编辑仍转头／改背景，应判定为耦合或条件语义问题，不能继续用降低源残差替代解决目标。若严格要求保留无反演随机平均结构，则需要另行设计源条件查询分布与其误差分析；当前确定性回放没有完成这件事。

**最终审查判断：数学上有成立的条件命题，工程设计有合理部分；与原问题假设只部分一致，真实模型保证和非编辑保持尚未闭环。** 可以做小规模可证伪诊断，暂不足以据此直接开展“已证明改进FlowEdit”的大规模确认。
