# 原生配对观测专题：56 篇相关工作的内容、思想与实现

日期：2026-10-30。研究方向调整为：**对固定源图与实际当前干净状态，在相同提示、探测噪声和时刻下，比较原生图像侧注意力输出、文本侧上下文与只读概念表征，建立任务相关的关系观测和反馈。**

本文逐篇分析 56 篇独立论文，版本不重复计数，论文家族不拆分计数。来源为 arXiv 原文、官方会议全文或作者正式项目；已取得全部 56 篇全文，核查范围包括方法核心，部分沿用 10 月 28 日已核读内容并补读有关实现。**方法核查不等于逐页通读、复现或确认作者所有结论。** 来源、检索日期和文本校验摘要见[来源清单](research_sources_20261030/joint_observation_sources.json)。

前 13 篇侧重原生机制；14—30 侧重配对特征、对应及语义读出；31—41 侧重因素与表征；42—56 侧重观测如何用于控制及其条件边界。最后给出综合判断。[理论推导与目标设计](原生配对关系观测_理论推导与FlowEdit联合约束设计_2026-10-30.md)另列，避免把作者已证明内容与本项目新假设混写。

自动方法继续采用冻结原 SD3 Medium、原 VAE 与已有 SigLIP2，不新增训练、LLM、目标参考、反演或编辑区域掩码。以下分割、字典和特征注入工作用于分析机制，不代表整套方法符合这些条件。

## A. 原生多模态注意力与上下文机制

### 01. Scaling Rectified Flow Transformers for High-Resolution Image Synthesis

[原文](https://arxiv.org/abs/2403.03206)，2024-03；SD3／MM-DiT 的架构基础。

**内容与思想：** 图像与文本采用各自权重，通过联合注意力交互；文本并非固定的外部 K/V，内部也随图像更新。

**实现：** VAE 潜变量分块，图像与 CLIP/T5 序列投影到共同维度，拼接 Q/K/V；注意力后拆回两流，各自执行调制和 MLP。池化文本另参与时刻条件调制。

**对本目标：** 是读取图像 O、文本 C 的直接架构依据。提示序列和池化条件必须同时匹配；不能只保持 T5 字符串相同却改变 AdaLN 条件。原 RF 训练目标本身未定义编辑中哪些源事实应保持。

### 02. ConceptAttention: Diffusion Transformers Learn Highly Interpretable Features

[原文](https://arxiv.org/html/2502.04320v2)，2025-02 首发；ICML 2025。

**内容与思想：** 注意力输出向量比原始注意力概率更适合概念定位；可以额外提出概念查询而不改变生成。

**实现：** 复用文本侧投影、调制与 MLP，维护独立概念残差流。概念查询读取图像和概念自身的 K/V，原图像／提示流不读取新增概念；在输出空间比较概念与图像向量。

**对本目标：** 最直接的零训练旁路依据。可保留连续输出及坐标，不生成编辑区域。主要证据是 FLUX／SD3.5 的对象定位；多词关系、朝向与跨形态稳定性需另验。

### 03. Learning to Read the Contextual Tokens in Diffusion Transformers

[原文](https://arxiv.org/html/2610.06844v1)，2026-10-05。

**内容与思想：** 文本侧上下文可包含提示未写明的动作、背景和视角等图像特有信息，空提示下亦可出现。

**实现：** 取多层文本侧 attention output，添加层／时刻信息；训练两层 Q-Former、16 个查询及到冻结 Qwen2.5-7B 的投影，监督回答最终生成图像的问题。

**对本目标：** 支持寻找未编辑事实的内部读出入口。读出器与 LLM 不符合现有边界；监督最终图像也可能读取未来生成意图。主要读出实验为 SD3.5／FLUX.2，不能视为原 SD3 Medium 的现成事实读出器。

### 04. On-the-fly Repulsion in the Contextual Space for Rich Diversity in Diffusion Transformers

[原文](https://arxiv.org/html/2603.28762v2)，2026-03 首发，2026-06 版本。

**内容与思想：** 文本侧上下文比未对齐的图像潜变量更适合做样本间语义干预。

**实现：** 同提示多样本生成中，在 MM 注意力文本输出上计算样本相似与多样性排斥，在线调整内部表征，主要作用于较早生成区间，无额外权重训练。

**对本目标：** 证明该通道能影响生成。排斥可能改变保护事实；全量源吸引也会带回旧类别。论文的同提示 token 对齐，不支持直接相减不同源／目标文本序列。

### 05. Vision-Language Binding in In-Context Image Generation

[原文](https://arxiv.org/abs/2605.24624)，2026-05-23。

**内容与思想：** FLUX.2 编辑中的参考内容可以经文本流间接进入输出，但不同属性采用不同路径。

**实现：** T2I Lens 把编辑运行中的文本激活注入空提示生成；attention knockout 切断指定跨流边；相同指令、不同参考和种子的运行间交换文本激活。

**对本目标：** 原文补读发现：文本交换主要转移颜色与风格，人物身份转移很弱，padding 承载突出。因此 C 不能默认承担所有实例／姿态保持。参考图 token 是该模型输入的一部分，原 SD3 无同等编辑通路；可迁移的是因果审查方式。

### 06. Text Template Tokens Are Implicit Semantic Registers in Diffusion Transformers

[原文](https://arxiv.org/html/2607.19139v2)，2026-07。

**内容与思想：** 模板 token 可经图像流吸收语义，成为后续层使用的寄存器；读提示与维持概念不一定由同一批头承担。

**实现：** 对模板／提示／图像间的路由、激活交换和 head 作用进行干预，定位“提示→图像→模板→后续图像”的间接链路。

**对本目标：** 支持按因果角色选择观测，不支持按 attention mass 选择许可。主要机制证据来自 Qwen-Image 聊天模板，不能照搬到 SD3 的 token 位置；对象身份也不等于任务允许变化与保持因素已分开。

### 07. Padding Tone: A Mechanistic Analysis of Padding Tokens in T2I Models

[原文](https://arxiv.org/abs/2501.06751)，2025-01 首发；NAACL 2025。

**内容与思想：** padding 的作用应区分文本编码阶段和扩散交互阶段。

**实现：** 以空 padding 表征替换提示或 padding 子集；编码阶段用 ITE，扩散阶段逐层、逐步干预用 IDP，比较完整、提示、padding-only 等运行。

**对本目标：** 本轮补读确认其直接讨论 SD3／FLUX 在扩散交互中利用 padding；原 SD3 的上下文观测有原生依据。仍需实测具体承载何种事实，不能从 Qwen 寄存器结论推断 SD3 的完整语义分工。

### 08. Attention Sinks in Diffusion Transformers: A Causal Analysis

[论文与官方 PDF](https://proceedings.mlr.press/v306/wu26ax.html)，ICML 2026。

**内容与思想：** 注意力汇聚、高幅度与推理时语义必要性不是同一个量。

**实现：** 在 SD3 的配对种子生成中动态找每层／头／时刻的高入度 token，分别压制 score 路径或替换 value；与相同预算随机干预比较文本一致性、偏好和感知变化。

**对本目标：** 需要随机与等幅因果对照。输出变化大，或 CLIP 几乎不变，都不足以证明保护了朝向。其干预是分析工具，不能直接当无关语义抑制器。

### 09. Circuit Mechanisms for Spatial Relation Generation in Diffusion Transformers

[原文](https://arxiv.org/html/2601.06338v2)，2026-01 首发；CVPR 2026。

**内容与思想：** 关系计算可能呈现模块化分工，也可能融合在对象表征里，取决于文本编码方式。

**实现：** 从头训练受控两对象 PixArt 风格模型；按已知对象／关系聚合注意力，做 QK、OV、token 和 head 干预。随机编码出现位置标记与对象绘制分工，T5 的关系更融入对象词。

**对本目标：** 应保护关系因素，而非整个对象 token；“未出现姿态词”不能用作充分许可规则。合成场景及头编号不能迁移到原 SD3，少量预训练模型分析也未建立通用关系读出。

### 10. Mechanistic Dissection of Cross-Attention Subspaces in Text-to-Image Diffusion Models

[原文与 PDF](https://ojs.aaai.org/index.php/AAAI/article/view/39046)，AAAI 2026。

**内容与思想：** QK 决定路由，OV 变换承载内容，应把值与输出投影纳入分析。

**实现：** 对各 head 的 $W_VW_O$ 做 SVD，把概念／基础提示的均值文本差投影到谱坐标，按贡献筛选并消除相关分量，检验概念移除。

**对本目标：** 可研究输出坐标与语义响应，不能把最大奇异值等同语义许可。主要为 SD2.1 的静态文本 cross-attention；MM-DiT 中 C 随图像变化。谱方向存在概念重叠，也不是源图特定的姿态恢复方向。

### 11. Mechanistic Interpretability of Text-to-Image Diffusion Models via Cross-Attention Interventions

[原文与 PDF](https://aclanthology.org/2026.findings-acl.1265/)，ACL Findings 2026。

**内容与思想：** 归因应考虑 token 实际注入的投影信号，而不只看概率。

**实现：** 记录 $A,V,W_O$，用 $\|A_{qi}V_iW_O\|$ 构造定位与 head-token 分布；固定种子删除词，计算分布 KL 变化；另放大选定 token 的贡献进行 steering。

**对本目标：** 可借鉴投影后输出与配对扰动。范数会忽略贡献相消；删除词还会改变上下文编码，需明确保留 token 的对齐。高 KL 是敏感性证据，不是某关系必须保持的证明。

### 12. Rare Text Semantics Were Always There in Your Diffusion Transformer

[原文](https://arxiv.org/abs/2510.03886)，2025-10；ToRA。

**内容与思想：** 语义存在但难被生成利用，可能与文本表征局部可分性有关。

**实现：** 每个提示、block、时刻分别对文本表征做 PCA；在主空间扩大 token 间距，在剩余空间用条件／空条件差和旋转做残差对齐，避免直接放大所有方差。

**对本目标：** 观测尺度和局部各向异性值得检查；但主成分并不标注许可类型。方法主动改变生成条件，未建立当前干净状态的源关系观测，也不证明少数主轴覆盖合法形态。

### 13. Unleashing Diffusion Transformers for Visual Correspondence by Modulating Massive Activations

[原文](https://arxiv.org/abs/2505.18584)，2025-05；DiTF。

**内容与思想：** 少数跨空间普遍出现的巨大激活可能掩盖对应信息，提取位置比统一相似度更关键。

**实现：** 比较 pre/post-AdaLN 特征，采用原模型自带 scale／shift 调制后的描述子，再抑制残余异常通道，进行稠密特征匹配。

**对本目标：** 应加入原生调制位置对照，不能把旧 block 残差的失败推广到所有表征。论文的异常通道索引来自 SD3.5／FLUX，不能直接写死在原 Medium；低空间方差也不能证明不含保护事实。

## B. 配对图像特征、对应与语义读出

### 14. Emergent Correspondence from Image Diffusion

[原文](https://arxiv.org/abs/2306.03881)，2023-06；DIFT。

**内容与思想：** 生成任务内部会形成可用于对应的稠密描述子。

**实现：** 对真实图像直接前向加噪，执行一次去噪网络查询，取指定层特征，多个噪声样本平均；通过余弦最近邻找对应，按任务选择层与时刻，无需为真实图反演。

**对本目标：** 直接支持对实际干净状态重加噪观测。本文不把对应准确等同姿态保持；跨姿态对应恰恰允许匹配发生位移，需要把位移另行保留为误差证据。

### 15. Diffusion Hyperfeatures: Searching Through Time and Space for Semantic Correspondence

[原文](https://arxiv.org/abs/2305.14334)，2023-05。

**内容与思想：** 语义信号分散于层与噪声时刻，单层不能代表完整能力。

**实现：** 缓存多层、多步特征，统一分辨率；通过训练的 bottleneck 和层—时刻混合权重融合，以关键点对应的双向损失监督。

**对本目标：** 支持分层分时比较。其聚合器是训练的，真实图路径包含反演；本项目只借鉴轴的选择与未融合对照，不直接使用学习权重。不能把生成轨迹时间与编辑步混同。

### 16. A Tale of Two Features: Stable Diffusion Complements DINO for Zero-Shot Semantic Correspondence

[原文](https://arxiv.org/abs/2305.15347)，2023-05。

**内容与思想：** 生成与判别特征具有互补的空间、纹理及语义偏好。

**实现：** 抽取多尺度 SD 特征做降维／归一化，与 DINO 描述子独立归一化后拼接，再进行对应；SD 提取使用的隐式 captioner 来自相关分割框架。

**对本目标：** 不能期待一个全局空间同时完成全部任务。当前不新增 DINO 或 captioner，只比较已有 O/C/B 的互补性。对应允许形态和姿态差异，匹配后的特征距离不能单独作为姿态约束。

### 17. DiffSim: Taming Diffusion Models for Evaluating Visual Similarity

[原文](https://arxiv.org/abs/2412.14580)，2024-12 首发；ICCV 2025。

**内容与思想：** 通过注意力交叉读取实现隐式对齐，再比较输出，避免要求图像逐位置一致。

**实现：** 对 A 的自注意力输出和 A-query／B-key-value 输出求余弦，反向再算一次得到对称 AAS。DiffSim-S 使用自注意力；DiffSim-C 另用 IP-Adapter Plus 的图像条件。

**对本目标：** 最贴近配对输出比较。可以借鉴 S 分支的旁路运算，C 分支需要额外组件。自由对齐可能隐藏错误转头，必须同时保存对应坐标与位移，不能只最小化 AAS 距离。

### 18. Fuse2Match: Training-Free Fusion of Flow, Diffusion, and Contrastive Models for Zero-Shot Semantic Matching

[官方原文与 PDF](https://proceedings.neurips.cc/paper_files/paper/2025/hash/159511050630689045bf5593e74b13cc-Abstract-Conference.html)，NeurIPS 2025。

**内容与思想：** SD3 的对应信息分散于多个 facet、层和时刻，模型间简单拼接会受尺度和不确定性影响。

**实现：** 用加噪图与类别提示抽取 SD3 Q/V 等 facet，开发集搜索固定配置；按匹配相似度最大值与均值之差计算逐点权重，融合 SD3、SD、DINO。

**对本目标：** 提供原生 SD3 对应证据，要求保留 Q/K/V 对照，不能预设 O 必优。原方法使用额外模型；尖锐匹配也可能错误，权重不是已校准的语义正确概率。

### 19. Diffusion Trajectory Modeling for Semantic Correspondence

[原文](https://arxiv.org/abs/2609.15357)，2026-09-14。

**内容与思想：** 每个 patch 在不同噪声时刻的响应序列可能包含单点特征遗漏的对应线索。

**实现：** 基于 DiTF 调制后的描述子组成时序，采用 Mamba—空间块—Mamba 编码，并用标注关键点和双向 InfoNCE 训练。

**对本目标：** 支持比较噪声响应曲线，不能直接拿训练后的序列网络当零训练读出。可以先保留多时刻观测的向量／统计差异；时序编码是否区分必要形态与错误姿态仍无结论。

### 20. Diffusion Model is Secretly a Training-free Open Vocabulary Semantic Segmenter

[原文](https://arxiv.org/abs/2309.02773)，2023-09；DiffSegmenter。

**内容与思想：** 用 cross-attention 定位语义，再用 self-attention 的空间关系补全。

**实现：** 输入图编码加噪，多层 cross-attention 产生类别分数图，多分辨率加权；self-attention 传播补全，配合提示增强和类别归一化完成分割。

**对本目标：** 可参考语义与关系通道的协同，不使用最终分割作为编辑区域。其类别归一化、背景词与提示设计会影响弱部件读出；对象分割正确仍不足以识别朝向。

### 21. Diffuse, Attend, and Segment: Unsupervised Zero-Shot Segmentation using Stable Diffusion

[原文](https://arxiv.org/abs/2308.12469)，2023-08；DiffSeg。

**内容与思想：** 无标签 self-attention 的空间分布包含对象分组结构。

**实现：** 把多分辨率 self-attention 统一到高分辨率，利用分布相似／KL 进行迭代合并，再去重形成区域，语义命名是后续步骤。

**对本目标：** 启发观测分布之间的关系。无标签分组无法自动判断哪只动物被编辑，也无法决定某部件变形是否必要；最终区域不纳入速度门控。

### 22. What the DAAM: Interpreting Stable Diffusion Using Cross Attention

[原文](https://arxiv.org/abs/2210.04885)，2022-10；ACL 2023。

**内容与思想：** 从词到图像位置的注意力可以形成语义归因，并暴露对象与修饰语纠缠。

**实现：** 收集多层、多时刻 cross-attention，插值至共同空间，聚合 head／子词形成词级图；以生成图人工区域及语法关系检验归因。

**对本目标：** 提供原始概率图基线和属性绑定反例。聚合会丢失层／时刻差异，QK 权重也忽略 value 与输出投影；归因区域不等于允许编辑区域。

### 23. Open-Vocabulary Attention Maps with Token Optimization for Semantic Segmentation in Diffusion Models

[原文](https://arxiv.org/abs/2403.14291)，2024-03；OVAM。

**内容与思想：** 生成提示与归因提示可以分开，避免为观察新概念而改变原生成。

**实现：** 缓存原生成图像 query，另编码 attribution prompt 得到 key，旁路重算注意力；进一步用标注区域优化归因 token，改善定位。

**对本目标：** 只读开放词汇查询是直接启发。原始旁路与有监督 token 优化必须区分；后者不属于当前条件。U-Net 静态文本 key 与 MM-DiT 动态概念流也不能直接等同。

### 24. Open-Vocabulary Panoptic Segmentation with Text-to-Image Diffusion Models

[原文](https://arxiv.org/abs/2303.04803)，2023-03；ODISE。

**内容与思想：** 生成网络特征可为开放词汇实例分组提供视觉基础。

**实现：** 冻结扩散骨干，训练图像→隐式文本 embedding 的 MLP、mask generator 和分类接口，并使用全景区域监督；推理再与文本类别及判别特征结合。

**对本目标：** 提醒冻结骨干不等于整个系统无训练。证明信息可被学习接口利用，不证明当前原生旁路已能分离实例／姿态；不能直接引入其区域模块。

### 25. Your Diffusion Model is Secretly a Zero-Shot Classifier

[原文](https://arxiv.org/abs/2303.16203)，2023-03。

**内容与思想：** 相对条件去噪误差可以作为类别兼容证据，比较差值比估计绝对误差更容易。

**实现：** 在候选文本之间复用同一组噪声与时刻，比较噪声预测误差；配合自适应采样减少查询。

**对本目标：** 是共同随机数、配对差分的直接依据。迁移到 RF 必须使用相应速度目标，不能机械沿用 DDPM 噪声公式；类别兼容也不判断源姿态是否保持。

### 26. Are Diffusion Models Vision-And-Language Reasoners?

[原文](https://arxiv.org/abs/2305.16397)，2023-05；DiffusionITM。

**内容与思想：** 图像自身的去噪难度会混淆跨图像的图文分数。

**实现：** 用条件误差减去同图同噪声的空条件误差，构造图文匹配分数；另有通过困难负例与 LoRA 训练的增强版本。

**对本目标：** 比较源图与当前图时须控制固有难度；只取无需训练的差分思想。空条件是统计对照，不是必然把当前图拉回源图的修复速度；强化版本依赖训练。

### 27. Unsupervised Keypoints from Pretrained Diffusion Models

[原文](https://arxiv.org/abs/2312.00065)，2023-11；CVPR 2024。

**内容与思想：** 可通过定位与几何等变训练，让文本 embedding 成为跨实例稳定的关键点查询。

**实现：** 优化专用 embedding，使 cross-attention 接近局部高斯，并在仿射变换后保持一致；借 token 竞争与局部性筛选稳定优化。

**对本目标：** 为部件关系和方向量提供启发，同时揭示原始词查询未必足够精确。“无监督”仍需要学习 embedding；当前不能直接假设原生 nose／eye 查询就是可靠关键点。

### 28. Emergent Temporal Correspondences from Video Diffusion Transformers

[原文](https://arxiv.org/abs/2506.17220)，2025-06；DiffTrack。

**内容与思想：** 匹配能力、匹配信心和 attention mass 应分别评价。

**实现：** 在视频 DiT 各层／时刻比较 QK 与中间输出描述子，估计帧间对应，以外部 tracker 伪真值分析生成视频；原文观察到 QK 对时间匹配的优势。

**对本目标：** 反对“输出空间总是优于 QK”及“低熵即正确”。视频联合建模不同于两次独立图像探测，不能直接移植；其测量维度与位置偏置诊断可借用。

### 29. Making Training-Free Diffusion Segmentors Scale with the Generative Power

[原文](https://arxiv.org/abs/2603.06178)，2026-03；CVPR 2026。

**内容与思想：** 复杂模型的头／层协作及 token 竞争，使手调注意力平均失效。

**实现：** 将 head 投影后输出与总输出的内积用于头聚合，以特征亲和关系给层加权，再做逐像素 token 分数重标定。

**对本目标：** 提醒保留输出投影及聚合位置。贡献度是对生成更新的贡献，不是保护事实重要性；内积可为负或受相消影响。可作聚合对照，不能自动定义源关系约束权重。

### 30. Layer-wise Instance Binding for Regional and Occlusion Control in Text-to-Image Diffusion Transformers

[原文](https://arxiv.org/abs/2603.05769)，2026-03；LayerBind，CVPR 2026。

**内容与思想：** 实例语义、空间归属和遮挡顺序应联合绑定。

**实现：** 接收分层区域提示、box／mask 和遮挡顺序，构建实例分支，采用共享初始噪声、上下文双向更新、结构化 attention mask 和分支融合。

**对本目标：** 可借鉴实例—关系分工；其关键输入与操作不符合当前无区域掩码条件。不能把结构化布局已给定时的绑定结果外推到任意源图的自动对象关系恢复。

## C. 可解释因素、时序、字典与表征对齐

### 31. D-Scope: Decomposing and Steering Diffusion Transformers with Sparse Autoencoders

[原文](https://arxiv.org/abs/2609.39625)，2026-09-30。

**内容与思想：** 语义检索需要把文本、视觉证据和内部干预方向连接起来。

**实现：** 在 SANA-Sprint／Nitro-1-PixArt 训练 SAE，以高激活 patch 的 SigLIP2 embedding 聚合视觉质心，用目标或对比文本检索相应 decoder 方向，再做 SAM3 区域干预。

**对本目标：** 可借鉴视觉证据审计，不能引入字典或 mask。目标区域收益与区域外保持必须分开；原文逐例强度择优下，对比检索未稳定改善区域外保持，字典重建好也不保证因素覆盖。

### 32. TIDE: Temporal-Aware Sparse Autoencoders for Interpretable Diffusion Transformers in Image Generation

[原文](https://arxiv.org/abs/2503.07050)，2025-03 首发；AAAI 2026。

**内容与思想：** 不同时刻激活分布不同，解释字典应显式知道时刻。

**实现：** 在 PixArt 的指定层提取激活，训练 TopK SAE；用时刻驱动的 scale／shift 调制输入，改善跨噪声层级的重建与因素操作。

**对本目标：** 应分别标定探测噪声轴，不能把所有时刻混成同一距离。需要字典训练；其生成概念层次不是当前编辑完成度，也未提供冻结原 SD3 的姿态读出。

### 33. Emergence and Evolution of Interpretable Concepts in Diffusion Models

[原文](https://arxiv.org/abs/2504.15473)，2025-04 首发，2026 年修订。

**内容与思想：** 可解释因素在层与生成时刻上有不同出现和作用模式。

**实现：** 对 SD1.4 的 block 残差更新，在固定层／时刻训练 TopK SAE；收集高激活样本并做因素干预，比较布局、风格和纹理作用。

**对本目标：** 应测更新量与残差状态的差异，分层分时审查。布局因素与类别形态可能重叠，字典也需要学习；某生成阶段的干预规律不能直接变成 FlowEdit 的固定冻结日程。

### 34. Revelio: Interpreting and Leveraging Semantic Information in Diffusion Models

[原文](https://arxiv.org/abs/2411.16725)，2024-11 首发；ICCV 2025。

**内容与思想：** 扩散特征承载丰富语义，但架构和层位置改变其组织与可读性。

**实现：** 比较 U-Net／DiT 特征，训练 kSAE 与四层卷积的 Diff-C 分类接口；视觉问答等扩展还采用训练的跨模型连接。

**对本目标：** 可读性的证据需区分原特征和学习后的接口。池化丢失实例关系的风险值得检查；不能把专门分类器的精度当作原生零训练 C/B 读出已成立。

### 35. A Hidden Semantic Bottleneck in Conditional Embeddings of Diffusion Transformers

[原文](https://arxiv.org/abs/2602.21596)，2026-02；ICLR 2026。

**内容与思想：** 条件调制向量可能集中于少量高幅坐标，整体余弦极高仍能生成不同语义。

**实现：** 分析 AdaLN 条件向量的幅度、参与率及余弦，剪去低幅分量检验生成影响，跨离散／连续条件比较。

**对本目标：** 指出余弦尺度可能掩盖细小差异；研究对象不是实例图像特征。高幅维度不是 attention head，低方差也不保证不含姿态事实，不据此裁剪保护通道。

### 36. DifFRACT: Diffusion Feature Reconstruction and Attribution for Circuit Tracing

[原文](https://arxiv.org/abs/2606.15796)，2026-06-14。

**内容与思想：** 用可解释的 MLP 替代模型追踪图文流之间的局部特征贡献，并区分归因与真实干预。

**实现：** 为 FLUX 各双流 MLP 训练时刻调制 transcoder；缓存 attention 和归一化量，保留重建误差构造局部替代模型，再展开特征归因图并做 steering。

**对本目标：** 很接近图文联合机制，且有 SD3.5 扩展；但额外训练不符合当前条件。冻结路由后的解释只对应局部替代图，不能当成原网络完整导数，更不能默认其特征就是任务合法因素。

### 37. Mechanistic Interpretability of Diffusion Models: Circuit-Level Analysis and Causal Validation

[原文](https://arxiv.org/abs/2506.17237)，2025-06。

**内容与思想：** 用受控数据和消融研究不同生成阶段的功能分工。

**实现：** 在自建解释增强 U-Net／Transformer 混合架构上，比较合成人脸与 CelebA；以注意力熵、激活统计组合复杂度指标并执行干预。

**对本目标：** 只作为受控因素审查的次级参照。专门架构、组合统计指标及样本范围限制外推；熵或复杂度乘积不能标注语义许可。本设计不依赖该论文的定量结论。

### 38. Representation Alignment for Generation: Training Diffusion Transformers Is Easier Than You Think

[原文](https://arxiv.org/abs/2410.06940)，2024-10；REPA，ICLR 2025。

**内容与思想：** 生成中学习视觉表征困难，可以由已学习的视觉教师辅助。

**实现：** 将含噪状态的中间 hidden feature 经训练投影，与干净图的冻结教师 patch 表征对齐，并联合生成损失训练模型。

**对本目标：** 解释为什么内部表征会有可改善的语义组织，但教师对齐后的能力不能算原 SD3 既有能力。读出原特征与重训生成器是不同实验条件。

### 39. What matters for Representation Alignment: Global Information or Spatial Structure?

[原文](https://arxiv.org/abs/2512.10794)，2025-12；iREPA，ICLR 2026。

**内容与思想：** 对生成有用的表征质量不能只用全局分类判断，空间自相似结构更关键。

**实现：** 比较多种教师与空间统计；以空间中心化／标准化、卷积投影改善训练对齐。

**对本目标：** 应保留坐标关系，避免只用全局池化。项目已经测过中心化关系矩阵而未解决转头，故不能把同一操作重新包装为突破；论文训练收益也不等于冻结推理期语义约束收益。

### 40. Learning Representations to Guide Pixel Diffusion Transformers

[原文](https://arxiv.org/abs/2610.12978)，2026-10-09；RG。

**内容与思想：** 表征形成得好和被生成器有效利用，是两个条件。

**实现：** 训练像素 DiT 的低维瓶颈作为 decoder 条件，用去除表示的分支构造表示诱导预测差，并据此调整 flow-matching 训练目标。

**对本目标：** 必须把“读到姿态错误”与“能修复且不撤销类别”分别验收。其训练目标和架构调整不能直接放到原 SD3 推理；不以较强表征分数推断控制有效。

### 41. Diffusion Models already have a Semantic Latent Space

[原文](https://arxiv.org/abs/2210.10960)，2022-10；Asyrp，ICLR 2023。

**内容与思想：** U-Net 内部 h-space 比初始噪声更适合语义操控，反向过程中的不同项还会抵消干预。

**实现：** 非对称修改干净预测项，保留原方向项；在 bottleneck 学习由时刻和 h 产生编辑方向的小网络，使用 CLIP 方向与重建目标。

**对本目标：** 支持观察与动作空间分开审查。其 h-space 不是 VAE 状态，主要编辑方向需训练，不能作为原 MM-DiT 已有解耦轴或本项目零训练实现。

## D. 内部观测如何影响生成与编辑

### 42. Prompt-to-Prompt Image Editing with Cross Attention Control

[原文](https://arxiv.org/abs/2208.01626)，2022-08。

**内容与思想：** 保持源 cross-attention 的路由，可以限制文本替换后的布局变化。

**实现：** 固定随机性并运行源／目标分支，按词对应和时间调度替换、细化或重加权注意力；可选局部混合。

**对本目标：** 是配对比较与路由控制经典依据。作者也讨论强几何保持可能阻碍大形态变化。本项目不直接复制源注意力或使用局部混合；需要允许新类别形态，并修复当前已发生错误。

### 43. Plug-and-Play Diffusion Features for Text-Driven Image-to-Image Translation

[原文](https://arxiv.org/abs/2211.12572)，2022-11；PnP。

**内容与思想：** 某些中间空间特征及 self-attention 能保留结构，同时改变风格与外观。

**实现：** 真实图 DDIM 反演，缓存源重建的指定层特征和注意力，按时段注入目标生成分支。

**对本目标：** 提供源配对内部量的因果证据；反演与直接源复制不符合本方案边界。源结构包含类别形态，不能默认全部保留；原研究主要 U-Net，也不证明原 SD3 已同样分工。

### 44. MasaCtrl: Tuning-Free Mutual Self-Attention Control for Consistent Image Synthesis and Editing

[原文](https://arxiv.org/abs/2304.08465)，2023-04。

**内容与思想：** 保留当前 query，从源分支读取 K/V，可以在改变姿态时保留内容。

**实现：** 真实图反演后运行源重建与目标分支；目标 self-attention query 读取源 K/V，另有 cross-attention 生成的前背景 mask 消歧版本。

**对本目标：** 说明源读取可以兼容显著姿态变化，因而读取成功不能等同姿态被保护。借鉴只读跨图响应作为诊断，不部署源注入、反演或区域门控。

### 45. Zero-shot Image-to-Image Translation

[原文](https://arxiv.org/abs/2302.03027)，2023-02；Pix2Pix-Zero。

**内容与思想：** 文本变化方向与源 cross-attention 一致性可以共同引导编辑。

**实现：** 由源／目标多句文本的均值差构造方向；真实图反演并记录重建 attention，对目标含噪状态做梯度更新以匹配源图。

**对本目标：** 是可微内部保持项的直接前作，但源 attention 一致性可能阻碍必要形态；多句方向不解决有限变化覆盖。其反演、可选句子生成及整图结构保持条件不能隐去。

### 46. FreeControl: Training-Free Spatial Control of Any Text-to-Image Diffusion Model with Any Condition

[原文](https://arxiv.org/abs/2312.07536)，2023-12。

**内容与思想：** 从多张同概念生成图的特征中找结构坐标，再把结构与外观引导分开。

**实现：** 生成种子图组，按时刻对 self-attention 特征做 PCA；参考图反演后投影到该基；生成时匹配结构坐标，并从无干预兄弟分支提取外观统计。

**对本目标：** 共同条件、跨图校准和外观泄漏是重要议题。需要额外图组与反演，PCA 结构仍混合形态／姿态；不直接作为合法变化消元器。

### 47. Diffusion Self-Guidance for Controllable Image Generation

[原文](https://arxiv.org/abs/2306.00986)，2023-06。

**内容与思想：** 原模型注意力与激活可以构成可微几何／外观测量，无需外部分类器。

**实现：** 用 attention 的质心、质量、阈值形状和区域激活平均表示位置、大小、形状、外观，构造损失对含噪状态求梯度。

**对本目标：** 是“关系测量→推理优化”的重要前作。本文只借鉴无阈值的连续测量思路，不引入 shape mask；其中心和大小不足以检测头朝向，更不能冻结原形状来处理类别编辑。

### 48. SEGA: Instructing Text-to-Image Models using Semantic Guidance

[原文](https://arxiv.org/abs/2301.12247)，2023-01。

**内容与思想：** 多个概念条件相对空条件的预测差可以组合操控生成。

**实现：** 额外查询概念条件，选预测差的高幅坐标，结合方向、强度、动量与时间调度形成稀疏引导。

**对本目标：** 提供多条件预测差的候选动作基线。稀疏方向的经验可组合性不等于语义正交，更不证明源图未请求事实不变；本方案不依赖这种差直接定义许可。

### 49. Self-Rectifying Diffusion Sampling with Perturbed-Attention Guidance

[原文](https://arxiv.org/abs/2403.17377)，2024-03；PAG。

**内容与思想：** 正常预测与破坏注意力后的预测差，可提供自引导信号。

**实现：** 在额外分支把选定 self-attention 路由替为恒等式，比较正常／扰动预测并加权外推，无权重训练。

**对本目标：** 可用于测试某内部路由的作用；扰动差主要反映模型结构偏好，不是源锚定事实。生成质量提升不能推断编辑必要性或既有错误收缩。

### 50. Improving Sample Quality of Diffusion Models Using Self-Attention Guidance

[原文](https://arxiv.org/abs/2210.00939)，2022-10；SAG。

**内容与思想：** 原 self-attention 可以提示哪些内容退化后最影响生成，再用预测差增强这些内容。

**实现：** 基于 attention 构造显著区域，在干净预测上局部模糊并重新加噪，查询退化分支形成指导。

**对本目标：** 有助区分输入扰动、注意力与速度响应；但需要显著区域操作，而且干净预测不是实际当前编辑图。不能作为本项目无区域门控的直接约束。

### 51. Attend-and-Excite: Attention-Based Semantic Guidance for Text-to-Image Diffusion Models

[原文](https://arxiv.org/abs/2301.13826)，2023-01。

**内容与思想：** 用内部注意力反馈缓解目标实体被忽略。

**实现：** 汇总特定尺度 cross-attention，对词图平滑；提升最弱对象 token 的最大局部激活，对含噪状态迭代求梯度，分时刻达到阈值。

**对本目标：** 是零训练代理反馈的经典例子。高注意力峰可能只表示对象碎片，作者也讨论代理漏洞；不能以“熊 token 被关注”判定黑熊形态完成或源姿态正确。

### 52. TokenCompose: Text-to-Image Diffusion with Token-level Supervision

[原文](https://arxiv.org/abs/2312.03626)，2023-12。

**内容与思想：** 仅去噪训练不保证词与正确对象区域绑定，需要显式 token 层监督。

**实现：** 用视觉基础模型产生 noun 的区域伪标签，在扩散训练中加入 token 区域内质量和逐像素 attention 约束。

**对本目标：** 是“原生语义绑定不一定足够”的重要反证。训练所得能力不能算原模型已有；本方案不引入伪 mask 训练，只用错误对象／属性绑定测试审查原生读出。

### 53. Style Aligned Image Generation via Shared Attention

[原文](https://arxiv.org/abs/2312.02133)，2023-12。

**内容与思想：** 注意力共享可以传递风格，但过强共享造成内容泄漏。

**实现：** 当前图像 query 同时读取自己和参考的 K/V，并对当前 Q/K 采用参考统计的 AdaIN，控制共享范围。

**对本目标：** 提醒跨图 attention 并非纯结构算子，颜色、风格、内容可共同转移。诊断旁路应不反馈到生成；全量源 K/V 注入可能撤销正常类别外观。

### 54. FlowEdit: Inversion-Free Text-Based Editing Using Pre-Trained Flow Models

[原文](https://arxiv.org/abs/2412.08629)，2024-12 首发；ICCV 2025。

**内容与思想：** 通过随机源加噪配对的平均速度差，直接构建源到目标的编辑流，减少反演配对的运输成本。

**实现：** 源分支按源图重加噪，目标查询以当前编辑状态加源噪声偏移构造，使用条件速度差积分；原方法是启发式，不保证精确最优输运。

**对本目标：** 编辑查询与“给实际干净 y 标准加噪后的探测查询”必须分开。新观测是额外诊断通道，修正 y 后必须同步构造后续查询；原速度差不直接证明某相位变化必要。

### 55. SDEdit: Guided Image Synthesis and Editing with Stochastic Differential Equations

[原文](https://arxiv.org/abs/2108.01073)，2021-08。

**内容与思想：** 从图像加噪后的中间状态启动生成，噪声强度控制真实感与忠实度权衡。

**实现：** 选择起始时刻，向引导图加入相应高斯噪声，再用预训练逆 SDE 生成。

**对本目标：** 提醒探测噪声不是无害操作：高噪声可能使读出更反映生成先验。本文只运行标准化前向探测，不把重生成结果当当前事实，也不将其作为额外目标参考。

### 56. Qwen-Image Technical Report

[原文](https://arxiv.org/abs/2508.02324)，2025-08。

**内容与思想：** 多模态条件编码与图像生成可在同一基础模型体系中结合。

**实现：** 采用 Qwen2.5-VL 条件编码器、VAE 与 MM-DiT，按任务使用不同系统模板；编辑条件可在编码阶段已经接收图像。

**对本目标：** 解释 Qwen 文本 token 与原 SD3 条件 token 的重要差别：前者可能预先含图像信息。寄存器、模板和编辑能力不能直接迁移；本报告不以该模型替换现有 SD3。

### E.2 五项需要修正的直觉

1. **C 不能当完整源图记忆。** FLUX.2 的参考绑定实验对颜色／风格强，对人物身份弱；不同架构与任务必须分开审查。
2. **O 不能预设全面优于 Q/K。** ConceptAttention 的概念定位与 DiffTrack／Fuse2Match 的对应任务使用不同评价；应保留原生 facet 对照。
3. **对齐能力强不等于保持能力强。** 对应方法通常允许姿态变化，对齐后的高相似可能掩盖错误。必须保留对应产生的坐标变化。
4. **新训练所得表示不能成为冻结能力的证据。** SAE、Q-Former、Mamba、implicit captioner 和监督绑定都有条件差异。
5. **敏感性与编辑许可仍有距离。** 模型偏好、head 贡献、谱幅度和条件差不能自行决定某变化是否应当发生。

### E.3 对本项目的最终研究取向

优先构建**源锚定、共同条件、保留空间关系的多通道观测**：O 观察图像局部更新内容，C 观察全局条件与图像交互，B 提供只读语义查询；Q/K/V 与调制位置用于校准和必要对照。通道分工必须经实验确认，不先验宣布解耦。

目标是获得对合法形态稳健、对未请求关系偏移敏感的读出，再对实际当前残差反馈。相位作为动作经解码后的机制响应，服从任务和源关系共同确定的可行集合。具体构造、可辨识条件、反例、更新公式、自由文本边界与验证顺序见[理论及设计报告](原生配对关系观测_理论推导与FlowEdit联合约束设计_2026-10-30.md)。

本轮没有新增真实图像编辑轨迹，不把文献中的生成或分割收益报告为本项目的编辑收益。
