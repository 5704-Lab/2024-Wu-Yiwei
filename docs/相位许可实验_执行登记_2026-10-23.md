# 相位许可理论：实验执行登记

日期：2026-10-23。用户授权开展实验验证。对应[当前理论](相位任务响应的可辨识建模_机制消元与逐步推理优化_2026-10-23.md)。本轮不修改既有实验结果；新增代码、日志、失败尝试与结果位于 `experiments/phase_permission/`。

## 任务与协议

- 模型：本地冻结 SD3 Medium、VAE、既有 SigLIP2 Base；不下载新权重、不训练、不反演。
- 不使用文本 attention 或分割编辑区域掩码，不引入 LLM／外部参考图。
- 实际 FlowEdit：512，FP32，50 调度步、33 活跃步，seed=0，n_avg=1，n_min=0，源／目标 CFG=3.5/13.5。
- 源锚点：VAE 重建图；数据集原始 RGB 另行展示。
- GPU 0 存在其它用户任务；不终止它们。耗时仅为共享负载下记录。
- 原始 FlowEdit 必须重新运行并核对既有基线；每幅比较必须显示源图与原始 FlowEdit。

## 分阶段验证

1. **已知干预辨识**：8 张真实源图，3 种外观族复杂度，9 种干预，共 216 组。干预包括恒定增益、通道增益、缓变增益、1／2／4 原图像素平移、光度＋平移、族外纹理和恒等。纹理标为未知，不自动认定为错误变化。
2. **真实局部修正**：既有四图轨迹步骤 17、33、47；无外观许可的软相位锚定、许可版本强度 0.3／1，共 36 候选。检查真实 VAE JVP／VJP、有限差分、有限任务进展和真实残差。
3. **完整轨迹**：主要外观任务棕熊、猫头鹰，比较 BASE／PERMIT／RAW_PHASE／NORM_CONTROL；车辆替换和皇冠换帽子作为结构改变的范围外压力测试。所有接受／拒绝和非零修正单独记录。

## 明确实现与理论之间的差别

本次是理论的可执行近似分支，不是完整高维鲁棒锥优化：

- 观测是固定 RGB 颜色投影、128 分辨率、3 频率×4 方向复滤波，源固定置信权重，平滑单位复数嵌入。该嵌入并非严格增益不变。
- 参考族为源图逐 RGB 通道的有界对数增益和偏置，2×2 固定余弦基，共 24 参数；无几何许可。不逐像素任意拟合。
- 使用非线性有界外观拟合，再作局部正则消元。参考每次仍从源图生成，但没有施加外观参数速度界；不宣称连续参数动力学保证。
- 在负结构梯度、任务梯度、基础增量构成的至多三维潜空间子空间求解 Gauss–Newton 二次问题；不是全潜空间精确解。
- 修正半径为原步增量范数的 20%。任务阈值保留本步正的全描述目标 logit 增益的 50%；若原步下降，则允许同等下降；有限验收容差 0.01 logit。
- 候选必须同时通过有限非线性相位残差下降、带修改代价的目标下降、任务阈值和修正半径检查。失败则返回原始提议，明确记录拒绝；没有源管全程保证。
- RAW_PHASE 是无外观许可的**软相位锚定**，不是数学上的相位硬冻结。
- NORM_CONTROL 使用 PERMIT 实际记录的相对步长范数比例重放自身 FlowEdit 场；它控制缩步倾向，不等于匹配完整编辑程度。

## 首轮数值调整

首轮 216 组机制拟合中，部分简单合法外观因参数尺度失衡及非凸初始化未充分求解；真实熊 step33 的许可拟合也达到迭代上限。保存在 `attempt1/`，未删除失败结果。

改为按参数边界归一化的坐标，先拟合全局外观再初始化空间外观族；增大明确记录的内循环上限。修订发生于完整轨迹启动之前，不依据终点图像挑参数。后续仍报告达到迭代上限的比例，不将局部数值解称为全局最优。

## 成功与否的判据

必要相位被机制解释、非法平移仍可检测，是信号机制证据；还需真实编辑有相近任务完成度且源几何更好。只下降优化损失或上升 SigLIP 不算质量成立。

额外观测包括未参与优化的空间梯度方向、局部图像特征及完整图像对照。若与原始 FlowEdit 相比仅减少编辑量、或原始相位锚定同样好，则不能确认“机制许可”有独立价值。
