# 信号系统方向：研究范围与理论问题

阶段定位：本文件保留信号方向的阶段性范围。当前生成式方向见[噪声优化与语义梯度速度校正](生成式无反演编辑_噪声优化调研与语义梯度速度校正_2026-10-05.md)。

日期：2026-10-05。当前研究不再采用“编辑沿概率密度测地线运动即可保护非编辑内容”的假设。仓库保留文献与理论笔记，旧实验结果、实验设计及旧方案已清除。

## 1. 目标与输入

输入为源图 $x$、源文本 $c_s$ 和目标文本 $c_a$。使用冻结预训练扩散／流匹配模型，零训练、免微调、无反演、无外部或内部编辑掩码。目标是目标编辑准确、无关内容稳定、伪影少，并在完整网络调用与时间成本上有收益。

文本不是目标图真值。内部图文分数、速度差、梯度、频带能量和后验方差都是代理，不能给出准确语义成功率或真实非编辑区域一致性。

## 2. 保留的数学出发点

- **高斯观测通道**：在相应假设下建立 score、速度、后验均值和协方差的恒等式；一般流匹配不必是物理加噪过程。
- **非线性时变系统**：用状态转移矩阵解释输入响应与误差到终点的传播，不要求路径为测地线。
- **条件微分**：在各自文本条件附近计算 $D_ev$；输出端 $g=(D_ev)^	op h$ 中的 $h=v\Delta t$ 是固定输出投影向量，不是文本扰动，也不是目标语义损失。
- **频域与采样**：分析跨带耦合、VAE 混叠、SNR 时间错配；频段不等于语义区域。
- **数值与统计误差**：区分积分误差、共享噪声估计方差、模型失配与编解码误差。

## 3. 优先理论问题

| 问题 | 可定义的数学对象 | 需要说明的边界 |
|---|---|---|
| 条件输入能引起哪些变化？ | 各自条件 Jacobian、有限时域响应、伴随与可达 Gramian | 可达性不是正确语义，径向 VJP 会漏掉速度旋转 |
| 哪些扰动会在后续放大？ | 状态转移矩阵、对数范数、有限时域输入输出增益 | 局部线性保证不等于冻结网络全局稳定 |
| 频带控制为何会影响其他内容？ | 投影与 Jacobian 的交换子、解码器局部频率响应 | 高频／低频不能定义伪影／语义 |
| 能否用更少计算达到相近结果？ | 截断误差、随机协方差传播、求导与前向总成本 | 减少步数可能增加方差或被求导成本抵消 |

这些是研究问题，不是已验证方法。下一次设计应先明确可测输入、可控变量、代理输出、误差项及保证条件，再提出具体控制机制。

## 4. 与博士研究主线的连接

与刘昭强教授相关工作的连接点是生成先验下的信号恢复、模型失配与鲁棒性、可证明误差传播，以及任务相关的计算分配。已知观测算子的逆问题可以给出更明确的数据一致性；文本编辑缺少这种观测，应将两种任务的保证条件分开。

## 5. 学术原创性边界

频带增益、近端正则、平行／正交分解、反馈控制、条件 Jacobian、有限时域传播与自适应积分均存在相关工作。未来原创性必须针对完整算法与保证条件开展检索和比较；当前文献笔记不能证明公开方法中绝无相同设计。
