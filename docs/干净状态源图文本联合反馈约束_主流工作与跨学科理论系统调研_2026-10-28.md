# 当前干净状态、源图与文本的联合反馈约束：主流工作与跨学科理论系统调研

调研日期：2026-10-28。研究范围以本日前已公开材料为限；近期预印本与已发表工作分开标注。本文是文献审查与候选理论设计，没有新增完整 SD3 推理实验，也没有确认新的质量收益。

目标依据：[2026-10-28 方向修订](任务相对语义相关性_类别形态许可与源关系保持_方向修订_2026-10-28.md)。逐项来源、阅读深度、依赖及迁移限制见[文献证据表](干净状态联合反馈约束_文献证据表_2026-10-28.md)。此处“方法核读”指核对与本研究有关的方法段、公式或限制，不表示复现或审计了整篇论文及代码。

## 1. 调研后的主要判断

当前方向值得继续，但应将主问题明确为：**从源实例、编辑请求和当前干净状态联合读出任务进度及非预期变化，再作有选择的恢复控制。** 相位、源图距离和速度分解可以提供观测或动作，不能单独承担语义许可。

本轮发现的最有价值连接并非某一个新损失，而是三组已有思想之间的缺口：

1. **上下文编辑与差异评价：** Kontext、Qwen-Image 等将源图与指令联合条件化；DICE、EditReward 进一步判断输出相对源图是否完成指令、是否发生无关改变。这支持三方关系建模，但这些能力依赖训练过的编辑器或额外视觉语言模型。
2. **冻结模型的内部观测与因果干预：** Self-Guidance、DIFT、Stable Flow 说明内部表征具有可利用的结构信息；2026 年的视觉语言绑定分析进一步说明，不能先验认定某类 token 只负责编辑或只负责保持。迁移到 SD3 前需要辨识，而不是仅凭注意力可视化命名语义。
3. **形态／姿态因素与反馈控制：** 动物形态模型、统计干扰参数消元及视觉伺服，可以把“允许类别形态变化”和“恢复未请求姿态”放进同一个局部模型；CBF/CLF 与短时域优化再负责协调推进、保持和修复。控制器的正确性依赖观测的正确性。

在本轮所查范围内，**未找到一个已经证明满足“冻结原 SD3、无额外语义大模型、无反演、无空间编辑掩码”，并能对任意自由文本逐步区分类别形态与未请求姿态变化的现成方法。** 这不是不可能性结论，而是目前不能跳过的研究缺口。

## 2. 必须保留的问题定义

设源干净潜变量为 $x_0$，当前干净编辑潜变量为 $y_k$，原 VAE 解码器为 $D$：

$$I_x=D(x_0),\qquad I_k=D(y_k),\qquad T=(T_s,T_a).$$

用离散步 $k$ 表示编辑进程，另用 $\tau$ 表示模型探测噪声，避免与论文各自的时间方向混淆。$I_k$ 是实际当前干净状态，不是含噪查询，也不是单步外推的干净预测。

希望建立

$$\mathcal O(I_k,I_x,T)=\bigl(p_k,r_k^K,a_k,\Sigma_k\bigr),$$

分别表示目标完成证据、应保持事实的当前偏差、任务相容变化的解释，以及观测不确定性。它必须同时回答：

- 现在还有什么编辑没有完成？
- 哪些现有变化是类别与指令正常要求的？
- 哪些源事实已经被错误改变？
- 哪些变化暂时无法可靠判断？

“棕熊变成黑熊”不能被预先简化为染黑：毛色、毛质和内在头身形态可能需要共同变化；原来的朝向、动作、视角、位置和场景关系通常不应随之改变。**类别词隐含的属性不能因没有逐字出现而被全部冻结；允许形态改变也不要求最大程度重画成类别原型。**

应保持的是任务未授权改变的事实，而不是所有像素或所有几何。必要的遮挡、接触和光照变化也可能影响邻近区域；它们是否允许，需要由具体任务的因果后果判断，不能由固定“背景不动”规则概括。

源图与文本提供固定参照。当前 $I_k$ 用于识别进度和偏差，不能把已经发生的转头解释为新的许可。速度 $v$ 是候选动作及预测工具，不能作为判断动作必要性的唯一证据。

## 3. 主流相关工作的思想及其适用边界

### 3.1 源特征复用：为什么有效，也为什么会压制合法形态

Prompt-to-Prompt 通过跨注意力控制编辑与布局之间的关系；PnP 复用源的空间特征及自注意力；MasaCtrl 使用跨样本的键值来维持内容联系。它们共同利用了文本没有完整描述的源实例信息，而不是只提高目标提示的引导强度。[Prompt-to-Prompt](https://arxiv.org/abs/2208.01626)、[PnP](https://arxiv.org/abs/2211.12572)、[MasaCtrl](https://arxiv.org/abs/2304.08465)。

这些工作对本研究的启示是：**未编辑内容必须有来自图像的参照通路。** 但整层源特征、全部轮廓或注意力形状保持，可能把应改变的旧类别形态一起锁住。MasaCtrl 等还包含内部区域处理；“不需要用户画掩码”不等于满足本项目的无空间编辑掩码条件。

Stable Flow 用干预寻找关键层；ReFlex 区分中间反演中的联合注意力和残差特征。值得迁移的是“通过实验确定哪些内部量适合保持”，而不是“某一层一定是姿态因子”。原方法的反演、特征注入及部分区域融合机制需要逐项剥离。[Stable Flow](https://arxiv.org/abs/2411.14430)、[ReFlex](https://arxiv.org/html/2507.01496)。

### 3.2 Self-Guidance：最直接的冻结模型属性反馈先例

Self-Guidance 从扩散模型内部注意力与激活读出位置、大小、形状和外观，再用能量梯度指导采样；不需要额外模型或训练。其真实图像方案对源图在不同噪声水平前向加噪，提取内部量作为参照。这是“利用已有模型自己提供观测”的直接依据。[Self-Guidance，方法第 3—4 节及真实图像补充](https://arxiv.org/html/2306.00986)。

但其具体观测包括注意力质心、阈值化形状图、形状加权的激活池化。固定形状会排斥必要的类别形态；其 Imagen/U-Net 的结果不证明 SD3 相同读出成立；也没有自动从自由文本和源图识别所有未提及事实。因此应迁移**可组合的属性读出与反馈**，不直接复制其形状保持损失或内部掩码。

### 3.3 源／目标差分、空文本与条件分解

DDS 通过匹配源图和源提示的分支减去共有偏差；FlowEdit 则以耦合源查询与目标查询构造免反演编辑过程。这些差分是模型相对的对照，不能自动识别“黑熊形态”和“黑熊数据分布常见的正脸姿态”。[DDS](https://arxiv.org/abs/2304.07090)、[FlowEdit](https://arxiv.org/html/2412.08629)。

CVC 的方法式 (7)—(10) 进一步加入同一当前查询下的源提示分支，可写成

$$b_{\rm CVC}=\alpha\,[v(q_y,T_s)-v(q_x,T_s)]
+\beta\,[v(q_y,T_a)-v(q_y,T_s)].$$

它提供“状态变化项＋提示变化项”的比较对象。当 $\alpha=\beta$ 时，两项直接合并为条件源／目标差分；分解本身没有增加语义事实。论文进一步使用源先验与后验修正，但其校准目标仍不是本任务所需的形态／姿态关系观测。其“Exact”标题也不能解释成对任意语义保持的严格保证。[CVC，v2，方法第 4 节](https://arxiv.org/html/2512.24015v2)。

对其公式还需保持审慎：论文以位移 $\Delta x$ 与源潜变量的距离定义对齐损失；若要移植，必须先明确状态、位移、观测似然和积分符号的对应，不能仅以 Tweedie 或 Empirical Bayes 的名称证明语义正确。此处未审计官方实现。

CEF 用两状态×两提示的四查询作对称分解，但实际控制借助 CLIPSeg 责任场；DecFlowEdit 用弱引导辅助轨迹提取定位，再用内部软掩码限制原始强引导。它们说明观测与推进可以采用不同探测条件，同时也说明：**精确代数分解和自动定位仍没有完成语义必要性识别。**[CEF，2026-09 预印本](https://arxiv.org/html/2609.33735v1)、[DecFlowEdit，2026-09 预印本](https://arxiv.org/html/2609.34237v1)。

### 3.4 FlowDC：与当前瓶颈特别接近的反例

FlowDC 先用 LLM 将复杂目标拆成逐步增加编辑效果的提示，构造并行轨迹，形成正交方向，再衰减速度在该子空间之外的分量。它与“保留编辑相关方向、压制其他方向”的设想非常接近。[FlowDC，方法第 3 节](https://arxiv.org/html/2512.11395)。

需要重视其自身消融：早期将正交分量完全清零，会使“polar bear”目标无法充分细化。这直接支持一个更谨慎的判断：**当前累计编辑方向的正交补中，仍可能含有必要的后续形态更新。** 正交化得到的是数值基，不是已经辨识出的语义独立因子。其 LLM 提示分解也不符合本项目的当前部署条件。

因此 FlowDC 应作为重要比较基线和消融灵感，而不是将其“正交＝无关”解释升级成我们的理论前提。

### 3.5 轨迹优化：控制已有先例，关键在被控制的量

FlowAlign v4 使用贴近原速度的运行代价和终端源潜变量距离，推导源一致性修正。ITOC 将终端奖励经伴随状态传播到整条轨迹，并迭代更新控制。前者直接贴近 FlowEdit，后者说明非线性终点目标不能总由局部单步梯度可靠替代。[FlowAlign v4，2025-07-27](https://arxiv.org/html/2505.23145v4)、[ITOC v3，ICLR 2026](https://arxiv.org/html/2509.25845v3)。

边界分别是：整体源距离会同时惩罚必要形态；ITOC 的主要初始化使用 DDIM 或时间反向 ODE 反演，并依赖可微奖励。其主要实验使用空条件模型以隔离奖励影响，不是已经解决原 FlowEdit 的源／目标语义耦合。论文观察到的奖励泛化也不是任意奖励下不发生投机的定理。

本研究可以借鉴运行代价、终端目标和局部／长程敏感性的分工，但应替换的是**源相似目标的语义内容**，不能只更换最优控制算法。

### 3.6 训练式主流编辑器：真正提供了什么信息

InstructPix2Pix 将图像和指令联合训练；Emu Edit 把识别、生成和编辑任务联合训练，并用任务嵌入控制类型。这些工作表明，编辑能力可以从源图、请求和目标之间的关系中学习，而不是仅靠文本差向量获得。[InstructPix2Pix](https://arxiv.org/abs/2211.09800)、[Emu Edit](https://arxiv.org/abs/2311.10089)。

Kontext 将参考图像 token 与输出图像 token 拼接，以位置编码区分二者，并训练条件流。Qwen-Image 同时将源图送入视觉语言编码器和 VAE，分别提供语义与重建表征，还引入 I2I 重建任务；Qwen-Image-2.0 使用 Qwen3-VL 条件编码器与联合条件—目标建模。**源信息直接参与解释请求和生成状态**，是比“文本未提到什么就保持什么”更完整的路线。[Kontext](https://arxiv.org/html/2506.15742v2)、[Qwen-Image](https://arxiv.org/html/2508.02324)、[Qwen-Image-2.0，2026-05](https://arxiv.org/abs/2605.10730)。

但这种迁移不能简化成在原 SD3 前向中直接拼接源 token：后者没有相同的参考角色、位置约定和训练分布。可以迁移的是**联合条件与实例参照的设计原则**；在冻结 SD3 中，首先应通过成对观测来研究这些信息是否可读，而不是声称已经获得 Kontext 的条件能力。

OmniGen2、BAGEL 等统一模型也属于理解／生成联合训练路线，应纳入能力背景与离线比较；它们不是当前无需替换模型即可插入的约束项。[OmniGen2](https://arxiv.org/html/2506.18871)、[BAGEL](https://arxiv.org/abs/2505.14683)。

Step1X-Edit 用多模态理解编码与 DiT 解码连接源图和指令；ICEdit 则结合上下文生成、参数高效训练及 VLM 早期筛选。它们补足了主流的理解—生成接口与测试时选择路线，但小规模微调不等于免训练，候选选择也不等于每步恢复。[Step1X-Edit](https://arxiv.org/abs/2504.17761)、[ICEdit，NeurIPS 2025](https://proceedings.nips.cc/paper_files/paper/2025/hash/cb7b55efe349d67ff3ac244aa1ae49d7-Abstract-Conference.html)。

### 3.7 不能预设“文本负责编辑，图像负责保持”

《Vision-Language Binding in In-Context Image Generation》在 FLUX 中用注意力阻断和激活移植发现：颜色、风格等参考属性可先进入文本流，精确人物／场景身份则更依赖图像侧通路，参考内容的绑定还主要发生在 padding token。这是比观察注意力热图更强的机制证据。[该文，第 4 节，2026-05 预印本](https://arxiv.org/html/2605.24624)。

对当前研究的直接影响是：不能将全部文本表征当成纯任务量，也不能将全部源图表征当成纯保持量。复制源文本激活可能带回旧类别属性。该文的模型与条件结构也不同于 SD3，迁移应是**用干预验证通路**，而不是照搬 token 结论。

### 3.8 三方差异评价：最接近所需语义接口，但尚不能直接部署

DICE 先不看指令检测源图与编辑图之间的对象级差异，再结合指令评价每项差异是否相容。这有助于避免“因为请求改变，所以把所有已发生变化都解释为正确”。但其实现是训练的差异检测与相容性 MLLM，并使用区域框，不能直接移植到当前限制下。[DICE / What Changed?，ICCV 2025，第 3 节](https://arxiv.org/html/2505.20405)。

EditReward 以源图、编辑图和指令为输入，采用多维、带不确定性的奖励建模及大量人工偏好。其价值是确认“完成任务”和“保持／质量”需要分别读出；它不是现有 SigLIP 全局匹配分数的同义表达，也不是无需额外模型的解法。[EditReward，ICLR 2026](https://arxiv.org/html/2509.26346)。

这两类观测主要针对最终编辑图。即使允许它们做离线对照，也必须检查对部分完成的干净 $I_k$ 是否可靠；不能把最终输出评价的准确率直接外推到任意中间状态。

2026-06 的 VeriLatent 用单步终点预测与源潜变量的余弦差构造编辑激活区域，再交给 MLLM 选择初始噪声；它含内部区域掩码、额外判别器，且主要做候选筛选。2026-10-23 的 KINESYS 将源保持和参考效果分开反馈，但采用效果参考、额外奖励与测试时微调。这些新工作都没有直接提供我们所需的每步干净状态恢复控制。[VeriLatent](https://arxiv.org/html/2606.15188)、[KINESYS v1](https://arxiv.org/html/2610.33292v1)。

### 3.9 最新条件切换：源条件也不能无差别增强

2026-10-01 的《When Text-to-Image Helps Editing》比较统一编辑器在同一状态下的编辑与纯生成预测，并在有界中间区间切换条件。它支持研究“源条件何时帮助、何时妨碍任务”，但主要实验的目标描述由 VLM 生成，执行的是条件模式切换，而不是逐步读出未请求事实并修复。[该文，第 3—4 节](https://arxiv.org/html/2610.01681)。

它与源特征注入共同提醒：保持通路需要任务与进度条件化。我们需要限制的是不应改变的源关系，不能把保持强度设成越大越好。

## 4. 跨学科理论：每一种具体解决什么

以下迁移均为本研究提出的解释或候选扩展，不把原领域的结论写成已在图像编辑中成立的定理。

### 4.1 生物形态学与关节模型：形态不是姿态

SMAL 把动物的三维体型与关节姿态分别参数化，说明不同物种形态与动作不需要被混成同一组几何坐标。[SMAL / 3D Menagerie，CVPR 2017](https://smal.is.tue.mpg.de/)。

可借用其因素结构，而不额外加载其估计器：

$$I=\mathcal R(a,p,c,b,\ell),$$

其中 $a$ 为内在形态与外观，$p$ 为关节姿态／主体朝向，$c$ 为相机，$b$ 为场景关系，$\ell$ 为光照。类别编辑可改变 $a$，但通常约束 $p,c,b$；明确的姿态编辑则改变相应许可。

这意味着鼻口长度、耳形、毛量变化不能直接计为错误；同时，它们会移动二维关键点和相位，因此也不能要求所有投影点相等。实际可保护的应是经过形态条件化后的朝向、关节关系、接触与场景关系。该因素图只是结构假设；单图和原 SD3 并没有自动提供已分离的这些参数。

### 4.2 视觉伺服：用当前视觉误差修复，而非只抑制新变化

视觉伺服使用当前图像特征误差和交互 Jacobian 计算反馈。其基本结构是 $e=s(I)-s^*$、$\dot e=Jv$；相机控制量在这里替换为编辑潜变量增量。[Chaumette–Hutchinson，2006，原文第 1—2 页](https://web.mit.edu/amcp/OldFiles/drg/Chaumette_Part_I.pdf)。

迁移后，保持参照来自源图，目标不是唯一目标图片，而是满足编辑语义的集合。若当前已发生偏差 $r_k^K$，需要处理

$$r_{k+1}^K\simeq r_k^K+J_k^K d.$$

只压小 $J_k^K d$ 会保留旧错误。使用 $r_k^K+J_k^K d$ 才可能在保住黑熊类别的同时修复朝向。经典视觉伺服自身也有多解、奇异性和局部收敛限制；增加特征数量并不自动解决语义多义性。

### 4.3 运动控制中的最小干预：保护任务事实，允许实现自由度

Todorov–Jordan 的最优反馈控制与 uncontrolled manifold 思想，把稳定任务结果与允许冗余实现变化区分开。[Todorov–Jordan，2002](https://roboti.us/lab/papers/TodorovNatNeurosci02.pdf)、[Scholz–Schöner，1999](https://pubmed.ncbi.nlm.nih.gov/10382616/)。

本任务中的“任务”应包含目标编辑和未请求源事实。因此可以允许多种黑熊毛发／形态实现，但不能将所有“文本未直接提及”的自由度都当成可漂移方向。数学上，允许的是经过验证的联合任务映射的冗余方向，不是与文本向量或累计位移正交的任意方向。

这也解释了为何不应给出唯一规定的像素编辑轨迹：合理目标往往是集合，最小编辑应在集合内保留自由度，并对偏离事实的变化进行干预。

### 4.4 统计学：把合法形态当作干扰参数，再检查姿态是否仍可辨识

在保持问题中，合法形态变化 $a$ 是需要消去的干扰；在完成问题中，它又是目标的一部分。这两个用途不能用同一个全局正交投影同时解决。变量投影提供参数消元方法，Cox–Reid 提供目标与干扰参数局部正交化的统计视角。[Golub–Pereyra，1973](https://epubs.siam.org/doi/10.1137/0710036)、[Cox–Reid，1987](https://rss.onlinelibrary.wiley.com/doi/10.1111/j.2517-6161.1987.tb01422.x)。

设真实可用观测在局部满足

$$z\simeq z_*+A\,\delta a+N\,\delta n+\epsilon,$$

其中 $n$ 是未请求改变的姿态、相机和场景因素。权重 $W\succeq0$ 下，消去形态后关于 $n$ 的有效信息为

$$\mathcal I_{n\mid a}=N^TWN-N^TWA(A^TWA)^\dagger A^TWN.$$

若某个姿态变化的观测效应完全落在形态列空间中，则对应方向的有效信息为零。此时调大保持权重、增加 CG 次数或给矩阵加 ridge，都不能创造新的语义观测；ridge 产生的可逆性不能当作辨识证据。

有用的迁移是：**先测读出能否区分合法形态与错误姿态，再确定控制强度。** 这里的 $A,N$ 必须通过可信因素对照验证；不能把模型文本敏感方向命名为 $A$ 后，就认为它只包含合法形态。

### 4.5 可观测性、系统辨识与主动感知：缺什么信息，就探测什么

非线性可观测性研究多个输出及其动态变化是否足以区分状态。主动感知进一步强调，可以选择能降低歧义的观测条件。[Hermann–Krener，1977](https://www.math.ucdavis.edu/~krener/1-25/10.IEEETAC77.pdf)、[Bajcsy，1988](https://repository.upenn.edu/bitstreams/14686d28-7a8a-4554-beee-991eec61cbdd/download)。

我们知道潜变量 $y_k$，但不知道其语义因素，这是一种**语义状态的不完全观测**。不同噪声探测、层、提示对照可能增加信息；前提是它们对形态与姿态有不同响应。多个高度相关的全局分数不构成充分观测。

当模型响应有歧义时，优先追加一组有针对性的低／中噪声或层间探测，而不是直接放宽许可。多噪声平均只能降低部分随机误差，不能消除所有探测共享的类别—姿态偏见。

### 4.6 因果推断与不变性：相关变化不等于必要变化

反事实图像编辑研究指出，观察分布与语义标签不足以普遍识别个体反事实；不变预测则在明确的环境与干预假设下利用稳定关系识别因果因素。[Pan–Bareinboim，2024](https://arxiv.org/abs/2403.09683)、[Peters 等，2016](https://arxiv.org/abs/1501.01332)。

对我们有用的不是直接套不可能性，而是实验设计：同一类别替换在不同源姿态、相机和场景中，应跟随源的未编辑关系；同一源图换成改色、类别替换、转头三种请求时，许可应改变。真实因素变化比简单更换随机噪声更有辨识价值。

辅助变量非线性 ICA 给出了额外变化能够改善辨识的条件化先例，但依赖建模与学习假设；不能用它证明冻结 SD3 的若干查询已经完成因素分离。[Hyvärinen 等，2019](https://proceedings.mlr.press/v89/hyvarinen19a.html)。

### 4.7 对象持续性与预测误差：保存的是同一实例的角色

认知研究中的 object file 用临时对象表征维持跨时刻的实体联系；预测编码则将观测与解释之间的误差用于更新内部状态。[Kahneman 等，1992](https://pubmed.ncbi.nlm.nih.gov/1582172/)、[Rao–Ballard，1999](https://www.nature.com/articles/nn0199_79)。

候选迁移是为源主体保留持续参照：类别／外观可以改变，但“同一处主体、同一动作与场景关系”的证据仍需比较。对象对应必须允许类别变化，不能简单用源类别相似度认定身份；也不能把当前错误图作为新实例参照。

这里借用的是结构化误差与实例持续性的思想，不声称 DiT 等价于生物视觉，也不需要引入无法检验的“自由能”解释。

### 4.8 CBF/CLF 与 MPC：协调保持、完成及恢复

CBF 将集合保持写成控制不等式，CLF 表达性能进展，两者可合并到 QP；MPC 则用有限预测和重新规划处理非线性及中间权衡。[Ames 等，2016/2017](https://arxiv.org/abs/1609.06408)、[Rawlings–Mayne–Diehl，MPC 教材](https://sites.engineering.ucsb.edu/~jbraw/mpc/)。

迁移方向是用任务相对的保持集合替代固定 RGB 管，用完成证据替代单一 CLIP 增益，并基于当前残差作恢复。标准集合不变性主要讨论初始在集合内的情况；已在集合外的编辑状态需要显式恢复条件。语义误差、模型失配和有限步非线性也都需要检查。

不能要求所有中间图都严格增加某个终点分类分数：必要形态过渡可能短暂降低该分数。短时域预测可以缓解局部近视，但两步 rollout 并不证明全局可达；若观测错误，它只会更有效率地优化错误目标。

### 4.9 图像形成与 Metamorphosis：用共同机制解释幅相，而非冻结相位

Metamorphosis 将几何输运与模板变化放在一个变分框架中；成像方程则说明材质、几何、可见性和光照共同决定像素。[Holm–Trouvé–Younes，2008](https://arxiv.org/html/0806.0870v1)、[Kajiya，1986](https://www.cs.princeton.edu/courses/archive/fall06/cos526/papers/kajiya86.pdf)。

可考虑

$$\dot I=-\nabla I\cdot(u_a+u_p)+g_a,$$

其中 $u_a$ 是任务允许的内在形态变化，$u_p$ 表示姿态等其他几何作用，$g_a$ 表示与任务相容的外观变化。类别编辑不能把 $u_a$ 一并设零；若姿态已经错误，也不能仅要求未来 $u_p=0$，而应恢复相应源关系。

设复滤波响应 $c_j=H_j I$，共同图像更新产生

$$\dot c_j=H_j\dot I,\qquad
\dot\phi_j^{\varepsilon}=\frac{\operatorname{Im}(\bar c_j\dot c_j)}{|c_j|^2+\varepsilon^2}.$$

这说明应由同一合法机制共同解释幅度和相位，而不是为二者独立放宽预算。相位与小运动的联系提供结构线索，但并不将相位变成姿态标签。[Wadhwa 等，2013](https://dspace.mit.edu/entities/publication/f76897bb-81f7-48df-8a05-63447f8c95b9)。

**自由的 $g_a$ 可以解释重画，自由的形变也可以解释转头。** 因此该分解只有在语义许可已约束机制后才有辨别力。现有纯光度族只适用于明确改色等子任务，不足以支撑一般类别形态许可。IntrinsicEdit 也显示，本征通道仍存在跨通道耦合，物理命名并不自动带来语义解耦。[IntrinsicEdit](https://arxiv.org/html/2505.08889v2)。

## 5. 建议形成的候选方法

### 5.1 第一层：联合观测，而不是一次性许可

每步从同一固定源参照出发，分别估计：目标缺口 $p_k$、保持残差 $r_k^K$、合法因素解释 $a_k$、不确定性 $\Sigma_k$。可以保留历史用于平滑，但历史不能替代当前 $I_k$，更不能替换固定源事实。

为了避免先看到指令就忽略错误，可借鉴 DICE 的信息顺序：

1. 在相同探测条件下读取 $I_x$ 与 $I_k$ 的差异及关系变化。
2. 用 $T$ 和源实例语境解释这些变化：直接请求、合理耦合、未授权、尚不确定。
3. 单独检查未完成的目标，防止“没有差异”被判成完美保持。

这是逻辑分工，不要求新建 MLLM，也不要求输出区域框。全图关系观测不是空间编辑掩码；后者以区域权重直接门控速度，本方案不允许通过改名引入这种门控。

### 5.2 在现有 SD3 上可实施的观测实验入口

先使用原 SD3 的内部多层图像／文本激活及已有 SigLIP2 patch 表征，保留空间与 token 关系，不只读取全局余弦分数。DIFT 和 Self-Guidance 是依据，但不同模型的表征可读性必须重新验证。[DIFT](https://arxiv.org/abs/2306.03881)。

对标准化探测，使用相同 $\tau,\epsilon,c$：

$$\tilde q_y=(1-\tau)y_k+\tau\epsilon,\qquad
\tilde q_x=(1-\tau)x_0+\tau\epsilon,$$

$$z_k^{\ell,\tau,c}=F_\ell(\tilde q_y,\tau,c),\qquad
z_x^{\ell,\tau,c}=F_\ell(\tilde q_x,\tau,c),\quad c\in\{T_s,T_a,\varnothing\}.$$

这里仍以当前干净 $y_k$ 为观测对象，加噪只是冻结模型读取它的方式。源、目标和空条件是比较视角，不分别被认定为保持真值、编辑真值与自然恢复真值。

必须区分 FlowEdit 实际查询：

$$q_y=q_x+y_k-x_0.$$

其状态偏移系数为 1，而标准探测中的系数为 $1-\tau$。不能把已有四分支直接当作同条件的源／当前干净语义观测。新增探测需报告 NFE、批大小、显存与梯度成本；固定源侧的标准探测可缓存。直接解码与 SigLIP 观测则应计 VAE／视觉编码成本。

候选读出按风险从低到高分三层检验：

- **未池化的成对关系：** patch 特征、位置关系、跨图对应残差。保留源实例信息；需要防止固定网格距离把合法形态当错误。
- **任务条件关系：** 比较同一图像在源／目标提示下的内部关系响应及其交互。它提供条件差异证据，但条件敏感性不等于必要性。
- **经干预验证的读出：** 在离线已知形态／姿态对照上，以层／头消融和激活移植检查哪些量确实影响相关关系。迁移的是验证程序，不先指定“某头负责姿态”。

对未提及背景事实，不应要求自动生成完整自然语言描述；可以保留非池化视觉参照及其关系变化。但若读出无法区分类别形态与姿态，它仍不具备自由文本约束能力。差分更多、维数更高只是候选新增信息，必须通过对照证明。

一个可以直接编码、同时适合被否定的候选观测是：对每组标准探测提取 patch 激活矩阵 $H_{\ell,c}(I)$，形成位置索引保持的关系矩阵

$$G_{\ell,c}(I)_{ij}=\operatorname{cos}\bigl(H_{\ell,c}(I)_i,H_{\ell,c}(I)_j\bigr),$$

并同时保留跨图对应信息和提示—状态交互

$$\Xi_\ell=\bigl[F_\ell(\tilde q_y,T_a)-F_\ell(\tilde q_y,T_s)\bigr]
-\bigl[F_\ell(\tilde q_x,T_a)-F_\ell(\tilde q_x,T_s)\bigr].$$

用源／当前关系差、对应残差和 $\Xi_\ell$ 联合构成向量观测，而不立即压成一个全局分数。它相对旧全局投影的实际增量是保留位置及多关系信息；相对 CEF 式分解的增量必须由内部关系对照证明，不能由交互式本身宣称。

这仍只是候选传感器：关系矩阵可能混合形态与姿态，$\Xi_\ell$ 仅表示任务条件敏感性的状态差，不直接等于完成度。跨图匹配也不能任意重排位置来把转头、复制对象解释为正确对应。首先比较这些量对合法形态／错误朝向的响应分布，再决定是否进入保持能量。若它们在两类变化上不可分，该候选就应被淘汰。

离线标签可以用于这种辨识诊断与超参数留出验证；若进一步用标签拟合新的语义分类器／读出网络，则已增加训练，必须登记为条件放宽，不能继续称为原部署条件下的免训练方法。

### 5.3 第二层：对合法变化做有限解释，同时保留目标证据

理想的保持能量可写成

$$E_K(y;I_x,T)=\min_{a\in\mathcal A(T,I_x)}
\frac12\|z(y)-\mathcal H(a,n_x)\|_W^2+\rho(a;T,I_x).$$

$n_x$ 是源图中本次不允许变化的关系；$a$ 包含本任务允许的类别形态与外观。当前 $y$ 参与拟合，因此它不是静态源／文本许可。

这个公式具有明确边界：$\mathcal H$、$n_x$ 和 $\mathcal A$ 目前不是已知可靠接口。若把 $\mathcal A$ 放成所有能解释当前图的形变，错误会被全部消去；若只含颜色，合法类别形态会被误罚。**这是一项需要辨识的观测模型，不是写下最小化符号就已经可执行。**

最先可检验的是局部版本：在可信因素对照上评估 $A,N$，再对合法因素做有限消元。完成度仍使用保留下来的类别／形态证据，不能在消元之后仅用残差宣称目标已完成。允许集合的语义范围由源图和任务固定，局部系数可以随当前状态估计；已发生偏差不能扩大集合。

若仅用 SD3 文本响应估计 $A$，应作为带污染的基线：它可能将类别共现的正脸偏好纳入合法变化。离线形态正例和姿态反例正是用来否定这种假设，而不是给算法提供推理时真值。

### 5.4 第三层：基于当前残差的最小反馈修正

定义 $b_k$ 为按实际积分方向得到的原 FlowEdit 干净状态速度，$h_k>0$ 为步长，$d_0=h_kb_k$。一种局部候选为

$$\min_{d,\;s_E\ge0,\;s_K\ge0}\;
\frac12\|d-d_0\|_M^2+
\frac{\lambda_K}{2}\|r_k^K+J_k^K d\|_W^2+
\lambda_E s_E^2+\lambda_S s_K^2,$$

配合经过校准的任务进展软约束

$$\nabla L_T(y_k)^T d\le -h_k\gamma_k[L_T(y_k)-L_*]_++s_E,$$

以及保持／恢复软约束

$$\nabla h_K(y_k)^T d\ge-\alpha_k h_K(y_k)-s_K,
\qquad h_K(y)=\epsilon_K^2-\|r^K(y)\|_W^2.$$

再加局部信赖域 $\|d\|_M\le\Delta_k$；保留这个二次域时是凸二次约束子问题，改用盒约束时可保持 QP 形式。目标已完成时，任务项应允许在合格集合中活动，而不是持续提高类别分数直到变成原型图。早期形态过渡若导致单步进展条件失真，应降低该局部条件的优先级或改用短预测，不能以违反代理单调性直接判错。

当 $h_K<0$ 时，上式在无松弛、局部预测可信且可行的条件下要求向集合恢复；它不等价于已经获得全程语义保证。若观测不可靠，应标明不确定并追加辨识探测，不能将其包装成硬约束。

从线性化解到实际应用还有两步：

1. 实际解码 $D(y_k+d)$，重新执行同一三方观测，检查有限变化有没有撤销目标、产生其他偏移。
2. 接受后同步 FlowEdit 的当前状态和派生目标查询；拒绝时缩小信赖域／修改候选，不用错误的旧查询继续积分。

若低维速度字典中根本没有“保持目标而恢复朝向”的动作，分支重加权也无法解决。应通过观测×动作对照区分读出失败与动作空间不足，再决定是否需要全潜变量 JVP/VJP 修正。空文本反馈只是候选动作，不能默认具有源收缩性。

### 5.5 第四层：共同幅相机制作为二级检验

仅在目标与保持关系已具有基本辨别力后，用同一个形态／外观解释检验 RGB、复响应及相位。重点观察“语义读出认为合法，但共同机制无法解释”的矛盾，而不是再将全部不符合纯光度的变化删除。

在未知形态任务中，机制解释不充分可以表示模型覆盖不足，不能自动表示编辑错误。相位证据应与语义不确定性一起报告。已有纯光度实验可继续作为改色对照，其成功不能证明一般类别编辑有效。

## 6. 哪些看似合理的路线应降级

| 路线 | 目前为什么不足 | 可保留的用途 |
|---|---|---|
| 与文本差向量正交就保持 | 文本表征与姿态、背景可能纠缠；全局投影还可能退化为源相似 | 低成本基线与代数退化检查 |
| 与累计编辑位移正交就抑制 | 方向会随进程变化，累计位移也可能含错误 | FlowDC 式比较及部分幅度控制 |
| 空文本／同提示分支就是恢复场 | 不具有普遍源收缩保证，且模型先验可能带共现偏好 | 候选动作、共享偏差诊断 |
| 固定全部源轮廓／相位 | 类别形态会引起合法轮廓与相位变化 | 明确不改形态子任务的控制 |
| 简单提高源条件强度 | 可能带回旧类别、造成欠编辑 | 源条件调度基线 |
| 多随机种子一致或循环可逆就正确 | 多个分支可共享偏差，错误编辑也可逆 | 稳定性／一致性诊断 |
| 给 $A^TWA$ 加 ridge 就可辨识 | 数值稳定不创造因素信息 | 稳定求解，另报未正则化信息 |
| 更深的 MPC／更多 CG 就能解决 | 错误观测仍被更精确优化 | 观测通过后再改善控制 |

## 7. 下一阶段实验：先验证新增信息，再运行长轨迹

### 7.1 固定源、任务和模型时刻，替换当前干净状态

必须至少包含以下状态，且自动方法只能看到源图、文本与当前图／潜变量：

| 当前状态 | 应读出的信息 | 需要的反馈 |
|---|---|---|
| 未编辑／编辑不足，姿态正确 | 目标未完成，保持关系正确 | 继续必要编辑 |
| 类别形态合理，姿态正确 | 目标完成或接近完成 | 减少多余重绘 |
| 类别正确，朝向错误 | 目标完成，保持关系偏移 | 保留类别并修复朝向 |
| 只有颜色变化，目标要求类别形态 | 颜色完成但目标仍不足 | 继续相关形态 |
| 合法形态变化但二维轮廓不同 | 变化可相容，不能仅按几何差拒绝 | 允许正常完成 |
| 主体正确，背景／另一对象错误 | 非目标源事实发生改变 | 修复相应关系 |

增加同一源的三种文本：“仅毛色染黑”“变成黑熊”“转为正面”。必要时用明确受控的类别／姿态任务补充，而不预设每张棕熊图都必须大幅改变头形。

这一阶段首先检查观察量是否有新增辨别信息。即使完整算法尚不能实现，也可否定错误读出，避免继续在同一失效代理上优化。

### 7.2 关键消融与失败归因

| 对照 | 可以回答的问题 |
|---|---|
| 全局分数 vs 未池化关系 vs 任务条件关系 | 新方法是否真正增加源关系信息 |
| 只用源／文本 vs 加入当前干净状态 | 是否识别了当前进度与已有错误 |
| 原始差异 vs 合法形态消元后差异 | 是否减少了对正常类别变化的误罚 |
| 只约束 $Jd$ vs 约束 $r+Jd$ | 能否主动恢复旧错误 |
| 原始分支动作 vs 较宽潜变量动作 | 是否存在动作表达瓶颈 |
| 真实观测 vs 离线真值观测 | 失败主要来自读出还是控制 |
| 无相位 vs 共同复响应 | 相位是否提供额外信息，还是重复图像距离 |
| 相同 NFE／时间下的原 FlowEdit、条件差分与候选法 | 收益是否超过计算量增加本身 |

离线真值仅用于归因，不能输入部署算法。已有两鸟纯改色渲染器不能充当合法类别形态的充分正例；应加入独立的内在形态与关节／相机因素，并保留自然图人工判断。多个扰动来自同一源时，统计单位应以源为簇，不能把所有扰动当独立样本扩大证据。

### 7.3 进入完整推理的条件

先在留出的源与类别上证明：读出允许正常形态、识别无关姿态／背景、能区分完成与未完成。随后检查修正动作能保住已完成类别而降低既有错误，并作真实有限步解码验收。最后再运行完整轨迹，分别报告目标完成、未请求关系保持和图像质量，以及 NFE、显存和耗时。

阈值只在开发源上选择，留出集不用于反复调整。评价不能仅复用被优化的 SigLIP 分数；人工三项判断与受控因素误差应独立保留。若读出仍分不清合法形态与错误姿态，应回到观测与辨识，不把欠编辑称作更好保持。

## 8. 当前证据与新的研究主张之间的界线

已有真实实验表明，保持条件响应强度或满足某个源几何代理，并不足以避免转头；硬源管又可能欠编辑。已有共同机制实验只在纯改色子任务中验证了部分覆盖与数值可执行性，仍不能区分所有错误对象变化。详见[条件／空文本实验](条件空文本联合约束_实验结果与自适应调整_2026-10-25.md)与[共同机制实验](共同编辑机制_覆盖可辨识性与潜空间可执行性_实验探索_2026-10-25.md)。

本轮新增的是文献证据、问题结构和可证伪的候选方法，不是新图像收益。最值得先做的技术增量是：**保留空间／实例关系的三方观测，配合合法形态消元的辨识检验。** 视觉伺服式恢复是接下来的控制接口；短时域优化和幅相共同机制在观测通过后再加入。

这一顺序的研究价值在于能明确失败归因：究竟看不出错误、把正常形态误认为错误、没有恢复动作，还是有限步非线性破坏了预测。只有这几件事被分别验证，联合约束才可能超越整体源相似与文本响应重加权。
