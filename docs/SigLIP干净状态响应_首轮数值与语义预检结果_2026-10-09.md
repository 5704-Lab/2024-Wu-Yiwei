# SigLIP 干净状态响应：首轮数值与语义预检结果

日期：2026-10-09。已完成解析检查、真实可微链路、局部方向导数与同幅度对照。尚未执行新方法的完整编辑轨迹、留出验证或减步实验。

## 1. 实验范围与复现

冻结 SD3 Medium VAE 和 SigLIP2 Base patch16 256。使用原 FlowEdit 的四个开发编辑对：棕熊→黑熊、棕色猫头鹰→白色猫头鹰、黄色旧式面包车→现代SUV、猫的皇冠→高帽。每对检查原轨迹第33、47步，共8状态，独立源图只有4张，不能当作8个独立任务。

响应输入是干净编辑状态 y；通过可微 VAE 解码、裁剪、抗混叠双线性缩放和固定归一化进入 SigLIP。目标文本采用完整原始描述，均未截断。参数冻结不等于关闭状态自动微分。

第33步复用原始缓存；第47步从原始第43步恢复同一随机序列与原始积分。四对恢复后的最终潜变量与原缓存相对误差均为0。所有对比图包含原 FlowEdit 局部状态和最终结果。新方法列只是单点局部预览，不是完整编辑结果。

代码与记录：[实验目录](../experiments/siglip_state_response/README.md)。解析18项均通过，见 [stage0.json](../experiments/siglip_state_response/outputs/stage0.json)。

## 2. 数学定义得到哪些支持

固定目标文本，令匹配logit为 ell(y)，目标分数为 log-sigmoid(ell)。其状态梯度为 sigmoid(-ell)乘以grad ell，因此归一化方向与logit梯度相同。真实链路已经直接检查该因子关系；不是沿用旧速度输出VJP。

方向指标 F(y)=u_ref点乘归一化grad ell(y)。方向校正使用其状态梯度，即归一化梯度的方向Hessian回映。原生抗混叠缩放在当前环境支持二阶自动微分，无需替换成另一条近似链。

熊第33步的FP64复核：手工logit与模型官方输出差约1.42e-14；两条HVP表达式误差约1.95e-15。独立中心差分检查目标分数的一阶导数，扰动缩小时相对误差降至约3.26e-10。独立检查F的方向导数，相对误差从2.32e-3下降至约2.28e-9。后者的小扰动区间没有裁剪活跃集变化。详见 [方向独立检查](../experiments/siglip_state_response/outputs/direction_independent_fp64.json)。这支持局部导数实现，不证明全局目标或有限步有效性。

FP32熊第33步手工/官方logit差约3.81e-6。可微张量预处理与PIL路径存在约0.0297的logit差，不能混用它们验收小修正；差异包括量化与预处理。张量线性缩放算子与原生缩放的像素差约1.79e-7，但本实验仍用原生实现。

## 4. 理论缺陷与边界

1. **局部共同上升不保证有限步共同上升。** 目标与方向梯度夹角不是唯一决定因素。熊47在单位梯度点积约-0.0457时仍失败，说明曲率、裁剪或其他有限步非线性需要实际验收。该失败原因尚未单独定位，不能断言是裁剪造成。
2. **裁剪限制光滑性。** 解码图像经过clamp，分数连续且分段光滑；其梯度方向在边界可不连续。熊33较大差分扰动已有一个像素活跃集变化，小扰动没有变化且导数收敛。理论二阶推导仅适用于局部光滑区域与非退化梯度；跨边界只能依赖实际验收，不存在统一的二阶保证。
3. **方向稳定不是源内容保持。** 固定目标的前一步梯度也可能指向亮度或风格捷径。稳定地追踪错误代理方向仍可能引起额外编辑。当前没有证据说明F增量等价于背景或姿态保护。
4. **sigmoid分数不是正确编辑概率。** 使用logit避免数值饱和并保持相同梯度方向，但不会增加模型任务辨识能力。
5. **积分闭环与任务正确性独立。** 接受w后同步y、q以及有效速度的符号已经解析验证；这保证算法状态一致，不保证修正属于必要编辑方向。

## 5. 语义代理的实际问题

只对源解码图做全局亮度变化，没有执行物体语义编辑：熊亮度乘1.3，黑熊目标logit比原亮度高约0.2756；猫亮度乘0.7，高帽目标logit高约0.7587。源条件仍占优。因此这些检查证明目标分数对非目标因素敏感，但没有证明真正的梯度优化必然利用该捷径，也没有证明SigLIP完全无法识别任务。

原FlowEdit最终熊与猫的目标logit明显高于源图；SUV例最终目标logit约-2.71，与源图约-2.79接近，而图像中车辆已明显变化。这进一步说明完整句子分数无法单独量化编辑完成度。

人工查看预览：局部G/D变化很小；原FlowEdit最终熊的形态和姿态、猫的脸部外观也发生变化。没有掩码或真值时，这些只能作为定性观察，不产生准确非编辑区域指标。

## 6. 结论与下一阶段

继续保留新响应定义：它具有明确标量梯度意义，真实一阶、二阶链路已经得到局部数值支持。保留方向模块为待验证候选，而非已经解决源保持的约束。

当前不扩大完整编辑质量和加速实验。下一轮先固定小型任务辨识集：目标属性变化、纯亮度变化、姿态／背景变化分别作为正负对照；完整目标描述与任务短语必须分开登记。使用独立评价或盲评验证必要编辑、额外变化，再决定是否加入独立源保持约束。单纯依靠同一个SigLIP优化并评价构成循环证据。

随后针对熊47定位有限步失败：检查活跃集、方向曲率、实际状态舍入，若继续用回溯需事先注册最大次数与数值裕量，不能按结果无限缩步。必须比较同修正范数和同总耗时两种G/D对照。

FP64熊预检整套约73秒，独立方向审计约129秒；包括加载与多次诊断，不能当作单步推理耗时。FP64 VAE GPU峰值约47.61GB，工程成本很高；尚无任何减步或加速证据。
