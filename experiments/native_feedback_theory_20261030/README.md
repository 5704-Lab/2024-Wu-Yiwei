# 原生语义闭环的理论计算参考

日期：2026-10-30。对应[深度理论](../../docs/原生语义观测闭环_视觉伺服最小约束与有限步恢复_深度理论_2026-10-30.md)和[实现协议](../../docs/原生语义观测闭环_具体实现方案与接口协议_2026-10-30.md)。

`controller_reference.py` 接受已定义的标量事实、Jacobian、任务梯度与容差，求解步宽一致的集合恢复问题。它不读取图像，不解析文本，不估计容差，不宣称提供可靠语义。它用于低维构造核对，正式高维推理需使用原生观测和矩阵自由求导。

`design_protocol.yaml` 是待验证实现的起始协议。尚未创建或运行完整 SD3 原生 O/C/B 编辑实验。

后续[设计审查](../../docs/原生闭环设计审查_缺陷反例修正与实现解释_2026-10-30.md)修复弱方向等式求解、任务孤立参数及数值验收缺失。[修复前后记录](audit_20261030/)与历史构造结果分开保存。更新后的输出只提供显式数值容差内的局部候选，不提供图像或语义认证。

运行数学核对：

```bash
.venv/bin/python docs/theory_checks/原生闭环_集合恢复步宽一致性与联合控制_数学核对_2026-10-30.py
```

运行审查反例与回归（不覆盖历史核对输出）：

```bash
.venv/bin/python docs/theory_checks/原生闭环设计审查_反例与回归_2026-10-30.py
```

使用项目环境已有 NumPy、CVXPY 和 CLARABEL；不安装新组件，不加载 GPU 模型。输出与理论检查脚本同名的 JSON，只能作为代数与局部优化核对。
