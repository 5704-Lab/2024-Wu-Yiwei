# 清晰端速度文本梯度的定义审查

该条目是解析审查，不是实际 SD3 已经满足理想分布的结论。

设独立高斯噪声 epsilon 与 (X,c) 独立，RF 训练路径 Q_t=(1-t)X+t epsilon，速度目标 epsilon-X。总体最优速度为 E[epsilon-X | Q_t=q,c]。

在 t=0，Q_0=X，所以 v*(y,0,c)=-y，成立于相应条件分布几乎处处。若条件族在共同邻域有正的平滑密度、速度有一致的可微版本，则该端点速度不依赖条件，文本导数为零。

因此，直接把学习到的 v(y,0,c) 的非零文本梯度当作语义响应，没有总体最优 RF 的必然支持。它可能来自模型端点近似误差，或在目标条件支持之外的外推。对于奇异数据流形、不同条件支持或非一致极限，不能把这个论证无条件推广为所有实际模型的零梯度定理。

在正时间、规则密度条件下：

v*(y,t,c)=-y/(1-t)-t/(1-t) score_t(y,c).

故目标文本导数包含 t/(1-t) 因子。固定 y、采用小正辅助时间与归一化梯度，可以研究一个不同于精确端点的响应；输入仍可保持干净 y，但响应含平滑密度及时间尺度依赖，需独立审查。

将梯度简单乘 (1-t)/t 不会改变归一化方向，也不能自动修复方向定义；t=0 的零梯度不能这样直接恢复。

探针 a=-v(bar y)/||v(bar y)|| 冻结时，在候选点得到的是速度能量的条件导数（按常数缩放）；它不是目标图像语义完成梯度。上一状态使用同一探针时，则为对该固定投影的响应。方向连续性与语义准确性之间仍需独立质量证据。
