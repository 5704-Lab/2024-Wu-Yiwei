## 实现

`reference.py` 提供 NumPy／CPU 参考算子：实际源速度 L1、Heun L2、稠密段、条件性缺陷界、源／目标匹配回放、源循环门和固定点离散逆参照。输出为 `x + (target - source_reconstruction)`；源门失败时不执行目标，成功候选也不自动标为语义成功。

`verify.py` 用精确仿射 ODE、矩阵指数和反例核对局部误差阶、任意提升下的同条件恒等、源残差到配对编辑误差的界、有限预算与失败身份。结果：[37/37](outputs/math_checks.json)。低维界的常数已知，不借此认证实际 FLUX 的统一稳定性常数。

```bash
.venv/bin/python experiments/source_coupled_replay_20261109/verify.py
.venv/bin/python experiments/source_coupled_replay_20261109/build_plan.py
```

`build_plan.py` 只读现有基准元数据和图像哈希，生成4开发源、12按源隔离的保留源、424个条件性计划作业；全部执行的最大前向调用数44448。最小核对前缀为14个作业、最多2230次前向。真实阶段按关卡推进，不默认执行全部队列。

主方法源门为 .02 latent RMS。L1/Euler24 版本最多49次调用；逐级提升／Heun24主版本最多399次，所有失败源尝试都计入。计划不假称匹配总成本，也不以高PSNR代替完整任务。

## 保证边界

可证明内容是冻结流／离散算子及所登记的源循环残差，源逆算子和差映射的误差界需有效常数。语义目标与非编辑保持由独立评审／校准检验。现有基准存在历史暴露，不能称全新未见数据。

任务草稿已对完整提示作许可区分，例如蝴蝶右移属于请求，类别形态变化不能直接当作姿态漂移。未来生成前仍需查看源图、校准难例并冻结评分表。没有在线语义 oracle，也没有实现真实FLUX批处理执行器。
