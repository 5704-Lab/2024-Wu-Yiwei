## 算子与证明对应

| 参考算子 | 对应报告 | 可验证结论／前提 |
|---|---|---|
| `clean_field` | T1–T2 | q=αy，同点源／目标速度差按 α²/t 重标度；密度解释要求理想独立高斯 RF |
| `radial_potential`、`value_gradient` | T3–T4 | 固定中点求积的实际标量与完整输入梯度；源、尺度、节点在运行中固定 |
| `defect_certificate` | T5 | 调用方提供有效的统一 L、M，才产生条件性路径界；不能自动认证神经网络 |
| `propagated_edit_bound` | T6 | 同一 Euler 网格下，两种源查询误差的编辑传播上界 |
| `entropy_noise_weights` | T7 | 有限正先验下 Gibbs 唯一解；明确改变经验测度 |
| `guarded_step` | T8 | 求有二次保持上界的凸问题；检查候选残差与变分不等式，不能仅信求解器状态 |
| `finite_accept` | T8 实际值门 | 重算有限目标及约束，只接受可行且目标增加的候选；数值误差界由调用方提供 |

`guarded_step` 返回 `candidate_requires_finite_check` 只是候选。必须通过 `finite_accept` 才提交；求解失败、小步或无进展均不得报告任务完成。低维运行额外要求任务目标达到登记门槛。

## 验证内容与结果

- 多峰 Gaussian mixture 上 T1 速度／score 恒等式，最大误差约 2.86e−13。
- 热半群、平滑偏差、网络误差放大与尺度权衡。
- 保守／非保守／纯旋转场、径向积分与完整梯度；有限差分梯度误差约 1.98e−11，错误 detach 的梯度偏差约 0.243。
- 中点求积细化时约四倍误差收缩。初次 32 节点误差略高于 1e−4 门槛，改用 64 节点精度检查后通过，未放宽阈值。
- 源 ODE 缺陷证书、能量界、节点间尖峰反例及编辑误差传播。
- 熵最优选择、方向凸包没有可行推进的反例、有限非线性保持与评价误差边界。
- 任务与保持冲突、局部切向不等于有限保持、动态更换目标不具有共同单调性。
- 潜变量密度的平滑不等于图像空间低通；高维小均值分量也可能有较大 KL。

示例中非编辑坐标的允许变化为 0.05，代理任务门槛为 0.82。受约束终点约为 `[0.999999, 0.050000]`，满足已登记约束及代理完成门槛；无约束轨迹的第二坐标趋向 0.8。该例的任务和保持量是已知构造函数，不能解释为已经解决熊头姿态识别。

## 尚未覆盖

没有实现真实 FLUX 梯度接入、显存／时间基准、神经网络全域 Lipschitz 认证、语义保持读出校准或随机留出探针审计。也未声称所有约束问题都能继续推进。主报告明确列出这些转移条件；本目录只核对已经给出数学定义的算子与反例。
