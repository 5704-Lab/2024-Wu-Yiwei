# 普适保证边界与对称平均的数学核对

对应[理论、证明及限制](../../docs/FlowEdit普适改进的可解性边界与保均值降噪_2026-11-10.md)。

运行：`python experiments/flowedit_universal_limits_20261110/verify.py`。

- `reference.py`：固定当前状态的原 FlowEdit 查询与正负配对参考算子，不连接模型。
- `verify.py`：17项核对；精确高斯RF的期望映射使用64／96阶积分与4096步RK4独立交叉计算，另含有限对称分布精确计算、解析高斯矩和构造反例。
- `verification.json`：本轮执行的原始数值记录。

这里的“通过”表示公式恒等式或反例按预期复现，不能统计为语义成功、真实模型收益或无条件编辑方案成立。参考实现没有修改官方编辑器或旧协议，不涉及源反演、GPU 推理及末段普通去噪。
