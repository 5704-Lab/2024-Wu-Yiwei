# 三项结构偏差的解析核对

对应[定理、证明、反例及适用范围](../../docs/FlowEdit三项结构偏差_随机源替换目标查询与速度差_严格推导_2026-11-11.md)。

运行：`python experiments/flowedit_structural_errors_20261111/verify.py`。

18项核对覆盖条件耦合距离、均值锚点偏差、高斯热核平滑、查询平移与Jacobian积分、后验协方差传输、共享噪声方差界、条件转换后的目标ODE缺陷、混合交互项与完整高斯终点反例。另有替换查询但速度误差为零的对照，避免将潜在误差宣称为必然。

数值使用解析高斯矩与确定性Gauss–Hermite／Legendre积分，完整终点另用4096步RK4交叉核对。`verification.json`保存原始记录。没有加载生成模型、运行GPU或修改既有实验产物；这些检查不能证明真实FLUX图像收益，也不能代替正文的数学证明。
